# Bloom

> supports educators in creating engaging, adaptive lesson plans and assessments using real-time student performance data and AI-driven insights.

## Problem
Remote workers struggle to recommend their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Guided onboarding with ready-made templates
- Integrations with Slack, Google, and Stripe
- Audit log of every change
- AI-assisted recommendations and summaries
- Offline-first with background sync

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
