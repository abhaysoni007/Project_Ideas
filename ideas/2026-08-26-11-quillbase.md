# QuillBase

> A service that turns your bank statements into a plain-English monthly spending story.

## Problem
Remote workers struggle to schedule their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Guided onboarding with ready-made templates
- Email and push notifications
- Integrations with Slack, Google, and Stripe
- Responsive dashboard with light and dark mode
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** SQLite
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
