# MintGrid

> A dashboard that turns raw job applications into actionable IoT & hardware insights.

## Problem
Gamers struggle to organize their sensor data without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- One-click export to CSV and PDF
- Guided onboarding with ready-made templates
- Email and push notifications
- Offline-first with background sync
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** Supabase
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
