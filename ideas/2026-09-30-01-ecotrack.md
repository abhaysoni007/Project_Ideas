# EcoTrack
> **Track, Reduce, Thrive – Your Family’s Carbon Footprint Companion**

## Problem  
Household carbon emissions are often invisible, making it hard for families to know where they can cut waste.  
Many existing tools are generic and lack actionable, personalized guidance for everyday living.

## Target Users  
- Eco‑conscious families looking to lower their environmental impact  
- Parents who want to teach children about sustainability  
- Households planning to meet household energy‑saving goals  
- Community groups aiming to benchmark collective footprints  

## Key Features  
- **Real‑time footprint tracking** via integration with utility APIs and manual input  
- **Personalized reduction tips** generated by a lightweight ML model  
- **Family dashboards** with goal setting and progress visualizations  
- **Carbon‑offset marketplace** linking users to verified offset projects  
- **Gamified challenges** to encourage sustainable habits  
- **Smart notifications** nudging users to act when thresholds are crossed  
- **Data export & reporting** for sharing with schools or local councils

## Architecture  
EcoTrack follows a micro‑service architecture: a mobile front‑end communicates with a Node.js API gateway that orchestrates calls to the data service, the recommendation service, and third‑party utilities APIs. PostgreSQL stores user profiles, consumption data, and tip history, while Redis handles session caching and rate limits. The AI service runs in its own container, exposing a lightweight gRPC endpoint that the API gateway queries to retrieve personalized tips. All services are deployed on AWS EKS, with CI/CD pipelines ensuring rapid, safe releases.
