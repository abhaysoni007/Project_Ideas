# NovaStack

> A dashboard that turns raw sensor data into actionable sustainability insights.

## Problem
Open-source maintainers struggle to benchmark their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Email/OAuth sign-in with role-based access control
- Usage analytics and an admin panel
- Team workspaces with granular permissions
- Real-time updates over WebSockets
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
