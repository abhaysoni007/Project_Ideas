# LumenPilot

> A Slack/Discord bot that helps developers translate customer feedback without leaving chat.

## Problem
Students struggle to track their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- AI-assisted recommendations and summaries
- Offline-first with background sync
- Audit log of every change
- One-click export to CSV and PDF
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** React Native
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
