# Echoify

> A mobile app that gamifies git commits to keep freelancers engaged.

## Problem
Teachers struggle to organize their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Team workspaces with granular permissions
- AI-assisted recommendations and summaries
- Integrations with Slack, Google, and Stripe
- Responsive dashboard with light and dark mode
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
