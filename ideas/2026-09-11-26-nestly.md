# Nestly

> A self-hosted read-later app that strips ads and estimates reading time.

## Problem
Parents struggle to schedule their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- One-click export to CSV and PDF
- Responsive dashboard with light and dark mode
- Guided onboarding with ready-made templates
- Email and push notifications
- Full-text search with smart filters

## Tech Stack
- **Frontend:** React Native
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
