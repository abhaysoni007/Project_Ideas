# HabitHub

> offers a habit tracking and coaching app that uses AI-driven insights and behavioral science to help individuals build positive habits, break negative ones, and achieve

## Problem
Founders struggle to personalize their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Email and push notifications
- Offline-first with background sync
- Email/OAuth sign-in with role-based access control
- Team workspaces with granular permissions
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React client talks to a Node.js + Express API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
