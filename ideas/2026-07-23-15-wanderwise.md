# WanderWise

> assists travelers in planning personalized, sustainable trips by suggesting eco-friendly accommodations, transportation, and activities.

## Problem
Creators struggle to predict their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- One-click export to CSV and PDF
- Email/OAuth sign-in with role-based access control
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Node.js + Express API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
