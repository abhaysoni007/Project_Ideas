# NimbusDeck

> A Chrome-to-mobile sync app that lets founders track cloud costs across devices.

## Problem
Parents struggle to predict their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- AI-assisted recommendations and summaries
- Real-time updates over WebSockets
- Usage analytics and an admin panel
- Audit log of every change
- Offline-first with background sync

## Tech Stack
- **Frontend:** React
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
