# NovaKit

> A service that turns your bank statements into a plain-English monthly spending story.

## Problem
Creators struggle to recommend their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Email and push notifications
- One-click export to CSV and PDF
- Offline-first with background sync
- Usage analytics and an admin panel
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
