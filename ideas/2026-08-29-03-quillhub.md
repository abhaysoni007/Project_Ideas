# QuillHub

> A dashboard that grades your resume against a job description and lists gaps.

## Problem
Parents struggle to recommend their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- Email/OAuth sign-in with role-based access control
- Public REST API with scoped API keys
- Email and push notifications
- AI-assisted recommendations and summaries
- Offline-first with background sync

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Node.js + Express
- **Database:** SQLite
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Node.js + Express API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
