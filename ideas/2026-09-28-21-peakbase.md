# PeakBase

> A extension that summarizes long GitHub issues and their comment threads.

## Problem
Open-source maintainers struggle to recommend their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Email and push notifications
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
