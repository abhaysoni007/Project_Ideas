# BeaconBase  
> Generate realistic test data from your schema with a single command

## Problem  
Creating high‑fidelity test datasets that mirror production data is time‑consuming and error‑prone. Manual scripting or third‑party tools often require extensive configuration, lack schema awareness, or generate synthetic data that fails validation.

## Target Users  
- QA engineers looking for quick, realistic data seeds  
- Backend developers needing sample data for local development  
- DevOps teams managing CI pipelines that require fresh test data  
- Data scientists testing ETL pipelines with realistic relational data  

## Key Features  
- One‑command schema discovery and data generation  
- Automatic foreign‑key and unique constraint handling  
- Configurable data volume and distribution (normal, lognormal, custom)  
- Export to CSV, JSON, or direct database import (PostgreSQL, MySQL, SQLite)  
- Built‑in data anonymization for sensitive fields  
- Plugin architecture for custom generators (e.g., addresses, emails)  
- CI/CD integration via Docker and GitHub Actions templates  

## Tech Stack  
- **Frontend**: None (CLI‑only)  
- **Backend**:  
  - Rust (actix‑web for API, sqlx for database abstraction)  
  - Command‑line interface built with clap  
- **Database**: PostgreSQL (primary), MySQL, SQLite support via sqlx  
- **Infra/DevOps**:  
  - Docker for reproducible builds  
  - GitHub Actions for CI/CD workflows  
  - Terraform for optional cloud deployment (AWS RDS, S3 for artifacts)  
- **AI/ML** (optional):  
  - OpenAI GPT‑4 API for natural‑language schema description and data pattern hints  
  - HuggingFace transformers for local anonymization models  

## Architecture  
BeaconBase is a modular CLI tool that parses a target database’s schema through sqlx’s introspection APIs. It constructs an in‑memory dependency graph to respect foreign‑key relationships, then spawns parallel generators per table, applying configurable statistical distributions or AI‑generated patterns. Generated rows are streamed directly to the chosen output format or inserted into a new database instance, ensuring minimal memory footprint. A plugin system allows users to extend data generators or integrate with custom business logic.

## Roadmap  
- **v1** – Core CLI, schema discovery, deterministic data generation for PostgreSQL, CSV/JSON export, Docker image.  
- **v2** – Support for MySQL/SQlite, foreign‑key resolution, CI/CD templates, data anonymization, plugin API.  
- **v3** – AI‑enhanced generators, real‑time preview UI, cloud‑native deployment scripts, multi‑tenant data generation.
