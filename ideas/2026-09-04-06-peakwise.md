# PeakWise

> A weekly-digest service that automates customer feedback and emails remote workers a summary.

## Problem
Freelancers struggle to detect their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Freelancers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Email and push notifications
- One-click export to CSV and PDF
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
