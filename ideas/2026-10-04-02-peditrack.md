# PediTrack
> AI‑powered video analytics that monitors kids’ nighttime sleep for parents & pediatricians

## Problem  
Many families and pediatricians lack objective data on how children sleep, leading to sub‑optimal interventions. Current solutions are either intrusive hardware or manual video reviews, which are time‑consuming and error‑prone.

## Target Users  
- Parents seeking evidence‑based sleep insights  
- Pediatricians managing sleep disorders  
- Child‑sleep clinics and research teams  

## Key Features  
- Continuous, low‑light video capture with privacy‑preserving face‑blur  
- Automated motion & breathing detection, generating sleep stage heatmaps  
- Real‑time alerts for apnea or restlessness events  
- Weekly health reports with actionable recommendations  
- Secure web & mobile dashboards for caregivers and clinicians  
- Integration with Apple Health / Google Fit for holistic metrics  
- GDPR/EU‑GDPR compliant data handling and anonymization  

## Tech Stack  
- **Frontend**: React (Next.js), TypeScript, Tailwind CSS, Recharts  
- **Backend**: Node.js (Express), TypeScript, NestJS for modularity  
- **Database**: PostgreSQL (primary), Redis for caching, PostgreSQL JSONB for event logs  
- **Infra/DevOps**: Docker, Kubernetes (EKS), Terraform, CI/CD with GitHub Actions, Helm charts  
- **AI/ML**: TensorFlow Lite on-device inference, OpenCV for preprocessing, YOLOv8 for motion detection, custom LSTM model for breathing rhythm analysis  

## Architecture  
PediTrack uses a client‑side edge device (e.g., Raspberry Pi 4 with camera) that streams encrypted video to a secure S3 bucket. The backend ingests streams via a WebSocket gateway, preprocesses frames with OpenCV, and runs lightweight YOLOv8 + LSTM models locally to extract sleep events. Aggregated data is persisted in PostgreSQL and served through a REST/GraphQL API to the Next.js dashboards, which visualize insights and trigger alerts via WebSocket.

## Roadmap  
- **v1** – Hardware prototype, basic motion detection, web dashboard, GDPR compliance, beta release to 50 families  
- **v2** – Add breathing rhythm model, sleep stage classification, mobile app, API for clinicians, HIPAA compliance testing  
- **v3** – Cloud‑scale inference, integration with wearables, AI‑driven personalized coaching, full open‑source SDK for clinics
