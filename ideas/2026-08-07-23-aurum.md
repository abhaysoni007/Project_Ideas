# Aurum

> offers a digital platform for wealth management and investment advising, using AI

## Problem
Teachers struggle to track their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Offline-first with background sync
- Public REST API with scoped API keys
- Email/OAuth sign-in with role-based access control
- AI-assisted recommendations and summaries
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
