# SageMate

> A cybersecurity app that uses AI to translate workout plans for teachers.

## Problem
Gamers struggle to visualize their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Usage analytics and an admin panel
- Email/OAuth sign-in with role-based access control
- Full-text search with smart filters
- AI-assisted recommendations and summaries
- Audit log of every change

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
