# Symphony

> Symphony is a collaborative project management tool that uses AI-powered task automation, team collaboration, and workflow optimization to help teams work more efficiently.

## Problem
Gamers struggle to schedule their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Full-text search with smart filters
- Integrations with Slack, Google, and Stripe
- Email and push notifications
- Responsive dashboard with light and dark mode
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
