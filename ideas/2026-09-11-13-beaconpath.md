# BeaconPath

> A service that turns your bank statements into a plain-English monthly spending story.

## Problem
Students struggle to audit their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Email/OAuth sign-in with role-based access control
- AI-assisted recommendations and summaries
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
