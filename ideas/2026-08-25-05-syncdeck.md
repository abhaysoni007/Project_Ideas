# SyncDeck

> A VS Code extension that helps founders schedule podcast highlights inside the editor.

## Problem
Open-source maintainers struggle to benchmark their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Offline-first with background sync
- Public REST API with scoped API keys
- One-click export to CSV and PDF
- Audit log of every change
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
