# QuillPath

> A CLI tool that automates code reviews in creator economy workflows.

## Problem
Founders struggle to visualize their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Integrations with Slack, Google, and Stripe
- Audit log of every change
- Public REST API with scoped API keys
- One-click export to CSV and PDF
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
