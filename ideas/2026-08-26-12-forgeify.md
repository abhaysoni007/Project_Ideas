# Forgeify

> A no-code builder for gamers to personalize API logs without writing code.

## Problem
Designers struggle to track their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Offline-first with background sync
- Usage analytics and an admin panel
- AI-assisted recommendations and summaries
- Email/OAuth sign-in with role-based access control
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Node.js + Express
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Node.js + Express API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
