# IdeaDeck
> Gamify your cloud bill—turn costs into points, rewards, and growth for creators.

## Problem
Creators struggle to manage cloud spend while staying motivated to build. Traditional dashboards are data‑heavy, and cost overruns quickly drain budgets, stalling projects and discouraging experimentation.

## Target Users
- Indie game developers on mobile and web platforms  
- Freelance app developers and designers  
- Small studios with limited dev‑ops resources  
- Cloud‑first teams using AWS, GCP, or Azure

## Key Features
- **Dynamic cost leaderboard** that visualizes spend vs. peers in real time.  
- **Points & badges** for hitting budget thresholds, optimizing usage, and deploying safely.  
- **Auto‑scaling recommendations** with actionable insights to reduce waste.  
- **Budget lock‑in** via one‑click approval workflow and alerts.  
- **Marketplace rewards** where points can be redeemed for credits, tools, or partner services.  
- **Historical trend graphs** with forecast models to anticipate future bills.  
- **Multilingual support** for global creator communities.

## Tech Stack
- **Frontend**: React Native (Expo) + TypeScript, Redux Toolkit  
- **Backend**: Node.js (NestJS) + TypeScript, GraphQL (Apollo Server)  
- **Database**: PostgreSQL (TimescaleDB extension for time‑series)  
- **Infra/DevOps**: Docker, Kubernetes (EKS on AWS), Terraform, GitHub Actions CI/CD  
- **AI/ML**: Python (FastAPI) for spend‑forecasting model, using Prophet and scikit‑learn  
- **Cloud Provider**: AWS (Lambda, S3, CloudWatch, SNS/SQS)  

## Architecture
IdeaDeck follows a modular micro‑service pattern. The mobile client consumes a GraphQL API that aggregates data from a cost‑analysis service, a recommendation engine, and a rewards ledger. Data ingestion pulls raw billing logs from cloud APIs into a PostgreSQL data lake; a scheduled ETL job normalizes and stores time‑series metrics. AI/ML micro‑service runs nightly to generate spend forecasts and optimization suggestions, exposing them via REST endpoints that the GraphQL layer proxies. All services run in containers orchestrated by EKS, with secrets managed by AWS Secrets Manager and CI/CD pipelines automating rollouts.

## Roadmap
- **v1** – Core dashboard, cost leaderboard, budget alerts, and basic point system.  
- **v2** – Auto‑scaling recommendations, marketplace rewards, multi‑cloud support.  
- **v3** – Advanced forecasting, gamified challenges, community leaderboards, and AI‑driven cost‑optimization assistant.
