# NimbusHub

> A extension that summarizes long GitHub issues and their comment threads.

## Problem
Gamers struggle to audit their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Full-text search with smart filters
- Offline-first with background sync
- AI-assisted recommendations and summaries
- Email and push notifications
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
