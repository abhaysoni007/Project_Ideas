# VaultPath  
> Capture, organize, and personalize your research meeting notes right inside VS Code

## Problem  
Researchers often juggle multiple meeting notes scattered across email, PDFs, and notebooks, leading to fragmented information and wasted time searching for relevant insights. Existing tools force users to leave the coding environment, breaking workflow continuity.

## Target Users  
- Ph.D. students and postdocs  
- Academic researchers with active collaborations  
- Research teams needing structured meeting logs  
- Data scientists who document experiments in code editors  

## Key Features  
- Inline note editor with markdown support and syntax highlighting  
- Automatic tagging of participants, action items, and research topics  
- AI‑powered summarization and keyword extraction via OpenAI API  
- Cross‑workspace sync using GitHub Gists or local SQLite store  
- Searchable note history with faceted filters (date, tag, project)  
- Integration with VS Code’s task runner to link notes to code snippets  
- Export to PDF or Word for sharing with collaborators  

## Tech Stack  
**Frontend**  
- TypeScript  
- React + Vite for the Webview UI  
- VS Code Webview API  

**Backend**  
- Node.js 20 (extension host)  
- VS Code Extension API (v1.90+)  

**Database**  
- SQLite (via `better-sqlite3`) for local note storage  
- Optional: GitHub Gist API for cloud sync  

**Infra/DevOps**  
- GitHub Actions for CI/CD (lint, test, build, publish)  
- Docker for local development environment  
- Release management via `vsce`  

**AI/ML**  
- OpenAI GPT‑4 API for summarization and keyword extraction  
- LangChain or custom wrappers for prompt management  

## Architecture  
VaultPath runs as a VS Code extension composed of a background extension host and a Webview panel. The host manages storage, AI calls, and synchronization, exposing a JSON-RPC interface to the Webview. The UI, built with React, communicates through the VS Code messaging system, rendering markdown notes and handling user interactions. Notes are persisted locally in an SQLite database and optionally pushed to a GitHub Gist for cross‑workspace access. AI summarization requests are routed through a lightweight serverless function that proxies calls to the OpenAI API, keeping credentials secure.

## Roadmap  
- **v1** – Core note capture, markdown editor, local SQLite storage, basic tagging.  
- **v2** – AI summarization, searchable history, GitHub Gist sync, task runner integration.  
- **v3** – Real‑time collaboration, project‑wide metadata dashboards, mobile-friendly Webview, offline-first sync.
