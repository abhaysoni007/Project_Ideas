# CodeCraft

> offers a platform for developers and programmers to learn and master new coding skills through interactive tutorials and project-based learning.

## Problem
Gamers struggle to track their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Audit log of every change
- Email/OAuth sign-in with role-based access control
- Guided onboarding with ready-made templates
- Offline-first with background sync
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Next.js
- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a FastAPI (Python) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
