# HomeShelf

> The future of flexible living—modular furniture that adapts to your space.

## Problem
Urban renters often struggle to optimize limited square footage without committing to permanent furniture. Existing solutions are either bulky, expensive, or lack smart integration, making it hard to reorganize quickly or rent with confidence.  

## Target Users
- Young professionals living in apartments or shared housing  
- Millennial and Gen‑Z renters seeking cost‑effective, space‑saving solutions  
- Real‑estate agencies offering furniture bundles to attract tenants  
- Small‑business owners needing flexible office setups  
- Tech‑savvy households wanting smart home integration  

## Key Features
- Modular, snap‑together storage units that can be reconfigured on demand  
- Subscription management with auto‑delivery and pickup logistics  
- Smart IoT sensors to track inventory, occupancy, and usage patterns  
- Mobile app with AR preview for visualizing layouts before ordering  
- Integration with major e‑commerce platforms for seamless ordering  
- Eco‑friendly materials and a trade‑in program for used modules  
- Real‑time space optimization analytics to suggest rearrangements  

## Tech Stack
- **Frontend**  
  - React + Next.js (SSR for SEO)  
  - TypeScript for type safety  
  - Tailwind CSS for rapid UI styling  
- **Backend**  
  - NestJS (Node.js) with GraphQL API layer  
  - JWT + OAuth 2.0 for secure auth  
- **Database**  
  - PostgreSQL for relational data (users, subscriptions)  
  - Redis for caching session data and real‑time events  
- **Infra/DevOps**  
  - Docker + Kubernetes (managed on GKE) for scalability  
  - GitHub Actions for CI/CD pipelines  
  - Terraform for IaC and infrastructure drift protection  
- **AI/ML**  
  - TensorFlow.js for on‑device AR layout suggestions  
  - Python microservice (Flask) using scikit‑learn for usage pattern analytics  

## Architecture
HomeShelf is built as a microservices ecosystem: a Next.js front‑end communicates with a NestJS GraphQL gateway that orchestrates services for user management, inventory, subscription billing (Stripe integration), IoT device communication (MQTT broker), and analytics. The PostgreSQL cluster stores transactional data while Redis handles fast‑path caching. Docker containers are deployed to GKE with rolling updates, and Terraform manages all cloud resources.  

## Roadmap
- **v1**: Core subscription flow, modular unit catalog, basic AR preview, and IoT sensor integration.  
- **v2**: AI‑driven space optimization engine, marketplace for secondary used modules, and multi‑tenant support for property managers.  
- **v3**: Full smart‑home ecosystem integration (home assistants), dynamic pricing model, and international expansion with localized UI/UX.
