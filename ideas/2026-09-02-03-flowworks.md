# FlowWorks

> A self-hosted tool that lets teachers automate travel itineraries with full data privacy.

## Problem
Startups struggle to detect their workout plans without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Integrations with Slack, Google, and Stripe
- Real-time updates over WebSockets
- Usage analytics and an admin panel
- Email/OAuth sign-in with role-based access control
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** MySQL
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React client talks to a Node.js + Express API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
