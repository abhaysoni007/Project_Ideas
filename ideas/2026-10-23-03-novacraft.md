# NovaCraft
> Turn your terminal moments into motion.

## Problem
Developers and educators often record terminal sessions to share code walkthroughs, debugging sessions, or tutorials. Existing formats like asciinema or raw logs are hard to embed in visual media and lack polished animation. There's no lightweight, shareable format that preserves terminal aesthetics and can be embedded directly in web pages.

## Target Users
- Developers wanting to showcase code demos on blogs or documentation
- Educators creating interactive teaching materials
- Technical writers looking for engaging terminal illustrations
- DevOps teams documenting workflows

## Key Features
- Record live terminal sessions and export them as animated SVGs
- Preserve cursor, colors, and formatting for a true terminal look
- Auto‑compress SVG size with optional LZ4 or gzip backend
- Generate short, shareable URLs via a lightweight HTTP previewer
- CLI flags for frame rate, width, and theme selection
- Export to asciicast JSON for compatibility with other tools
- Optional integration with GitHub Gist for instant sharing

## Tech Stack
- **Frontend**  
  - SvelteKit (preview web app)  
  - D3.js for SVG rendering (if needed)
- **Backend**  
  - Go 1.22 (CLI binary)  
  - `github.com/mattn/go-runewidth` for terminal width handling  
  - `github.com/mattn/go-sixel` for Sixel decoding (optional)
- **Database**  
  - None (local file storage; optional S3 bucket for uploads)
- **Infra/DevOps**  
  - Docker for reproducible builds  
  - GitHub Actions for CI/CD  
  - Terraform for optional S3 bucket provisioning
- **AI/ML**  
  - None (future extension: AI summarization of session text)

## Architecture
NovaCraft is a single‑binary CLI written in Go that captures terminal input/output streams, parses them into a timeline of frames, and serializes each frame to an SVG element. The frames are stitched into a single SVG animation using SMIL or CSS animation. An optional lightweight SvelteKit previewer serves the SVG and generates short URLs, optionally uploading the SVG to an S3 bucket for public access.

## Roadmap
- **v1**: Core CLI that records and exports static and animated SVGs with basic theming and compression.  
- **v2**: Add frame‑rate control, optional S3 upload, and a simple HTTP preview server.  
- **v3**: Web previewer with live sharing, analytics, and optional AI‑driven session summarization.
