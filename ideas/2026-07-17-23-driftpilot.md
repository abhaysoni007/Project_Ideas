# DriftPilot

> A dashboard that turns raw recipes into actionable social insights.

## Problem
Designers struggle to audit their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- Team workspaces with granular permissions
- Audit log of every change
- Real-time updates over WebSockets
- Full-text search with smart filters
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Go (Gin)
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Go (Gin) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
