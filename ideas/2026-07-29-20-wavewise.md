# WaveWise

> offers a surf and weather forecasting platform for surfers, beachgoers, and coastal communities to stay informed and safe

## Problem
Parents struggle to predict their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Audit log of every change
- Public REST API with scoped API keys
- One-click export to CSV and PDF
- Usage analytics and an admin panel
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
