# LumenDesk  
> Turn your bank data into a clear, narrative spending summary.  

## Problem (2‑3 sentences)  
Most people stare at dense bank statements or spreadsheets, yet still struggle to see where money goes month‑by‑month.  
The lack of an intuitive, story‑driven view forces users to manually sift through line items, leading to missed insights and poor budgeting decisions.  

## Target Users (bulleted)  
- Individuals who want a quick, human‑readable financial recap.  
- Freelancers and small‑business owners who track cash flow but lack accounting expertise.  
- Financial advisors seeking a simple way to explain client spending patterns.  

## Key Features (5‑7 bullets)  
- **Automated Statement Ingestion** – upload PDFs, CSVs, or connect via Plaid to pull transaction data.  
- **Plain‑English Monthly Narrative** – GPT‑4 driven natural‑language summaries of spending trends.  
- **Visual Timeline & Heatmaps** – see spikes and recurring expenses at a glance.  
- **Custom Category Mapping** – users can label merchants or tags for personalized analysis.  
- **Export & Share** – PDF or Markdown exports that can be emailed or integrated into reports.  
- **Data‑Privacy First** – end‑to‑end encryption, no retention of raw bank data after processing.  

## Tech Stack  
- **Frontend**  
  - React 18 + TypeScript  
  - Tailwind CSS for rapid styling  
  - Vite for fast dev builds  
- **Backend**  
  - FastAPI (Python 3.12) for REST + WebSocket endpoints  
  - AsyncIO + SQLAlchemy ORM  
- **Database**  
  - PostgreSQL 16 + TimescaleDB for time‑series transaction data  
- **Infra/DevOps**  
  - Docker + Docker Compose for local dev  
  - Kubernetes (EKS on AWS) for production scaling  
  - GitHub Actions CI/CD with Helm charts  
  - CloudWatch & Grafana for observability  
- **AI/ML**  
  - OpenAI GPT‑4 for natural‑language generation  
  - spaCy for entity extraction and category mapping  
  - LangChain to orchestrate prompt chaining and context management  

## Architecture (a short paragraph)  
LumenDesk is built as a micro‑service ecosystem. The **Ingestion Service** pulls and parses statements, emitting events to a Kafka topic. The **NLP Service** consumes these events, runs spaCy for entity extraction, then feeds the cleaned data to GPT‑4 via LangChain to generate the monthly narrative. The **API Gateway** (FastAPI) exposes authenticated endpoints for the React UI, which consumes the narrative and visualizations. All services communicate over HTTPS, and data persists in a single PostgreSQL/TimescaleDB instance with strict RBAC. The system is containerized and orchestrated by Kubernetes, with CI/CD pipelines ensuring zero‑downtime deployments.  

## Roadmap (v1, v2, v3 bullets)  
- **v1** – Core ingestion, GPT‑4 narrative generation, basic React dashboard, secure authentication (OAuth2).  
- **v2** – Advanced analytics (trend heatmaps, recurring expense detection), custom category mapping, multi‑currency support, PDF export.  
- **v3** – Real‑time alerts for overspending, integration with QuickBooks / Xero, AI‑driven budget recommendations, enterprise API for B2B use.
