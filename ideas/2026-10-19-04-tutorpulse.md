# TutorPulse
> Personalised micro‑learning that adapts in real time

## Problem  
High‑school STEM students often struggle to stay engaged and to target weak concepts efficiently. Traditional static quizzes do not reflect a learner’s current mastery or progress, leading to wasted practice time and frustration.

## Target Users  
- 14‑18 year‑old high‑school students in STEM courses  
- Classroom teachers looking for data‑driven assessment tools  
- Parents wanting to monitor and support their child’s learning  

## Key Features  
- Adaptive quiz generator that tailors questions to recent performance  
- Instant feedback with explanatory video snippets for each answer  
- Gamified streaks and badges to boost motivation  
- Real‑time analytics dashboard for teachers and parents  
- Context‑aware hints that surface just before a student gives up  
- Mobile‑first design for on‑the‑go study sessions  
- Secure, GDPR‑compliant data storage and transfer  

## Tech Stack  
- **Frontend**: React Native (iOS/Android), TypeScript, Expo  
- **Backend**: Node.js with NestJS, GraphQL API  
- **Database**: PostgreSQL (primary), Redis for caching  
- **Infra/DevOps**: Docker, Kubernetes on AWS EKS, CI/CD with GitHub Actions  
- **AI/ML**: TensorFlow‑Lite for on‑device inference, Python micro‑services with scikit‑learn for model training, AWS SageMaker for large‑scale training  

## Architecture  
TutorPulse follows a server‑less micro‑service pattern: the mobile app communicates with a GraphQL gateway that orchestrates stateless NestJS services. These services access a PostgreSQL database for user and content data, and a Redis cache for rapid quiz selection. Machine‑learning inference runs on‑device with TensorFlow‑Lite for immediate feedback, while a separate training pipeline on SageMaker periodically updates the adaptive models, pushing new weights to the devices via OTA updates.

## Roadmap  
- **v1** – Core adaptive quiz engine, basic analytics, iOS/Android app, teacher dashboard  
- **v2** – Video hint library, gamification elements, parental portal, performance dashboards, CI/CD pipeline  
- **v3** – AI‑driven content recommendation, multi‑language support, offline mode, integration with school LMSs (e.g., Google Classroom)
