# Vaultly

> A habit tracker that pairs you with an accountability buddy who has the same goal.

## Problem
Gamers struggle to organize their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Responsive dashboard with light and dark mode
- Email and push notifications
- Offline-first with background sync
- Usage analytics and an admin panel
- Full-text search with smart filters

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
