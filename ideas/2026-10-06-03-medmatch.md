# MedMatch
> Matching rural patients to the right specialists, fast and AI‑powered

## Problem
In many rural communities, patients struggle to find specialized care because local clinics lack specialists and referral systems are fragmented. Patients often wait weeks or travel long distances, leading to delayed treatment and poorer outcomes. Existing triage tools are either too generic or require extensive clinician input, which is scarce in underserved areas.

## Target Users
- Rural patients with limited access to specialized healthcare  
- Primary care providers and community health workers  
- Telemedicine coordinators in regional health networks  
- Health system administrators seeking efficient referral pathways  

## Key Features
- AI‑driven symptom triage that maps symptoms to specialist categories  
- Real‑time availability lookup for nearby providers  
- Secure patient profile and medical history storage  
- Push notifications for appointment confirmations and reminders  
- In‑app teleconsultation scheduling and video call integration  
- Analytics dashboard for referral patterns and wait times  
- Multilingual support (English, Spanish, Native languages)

## Tech Stack
- **Frontend**: React Native (cross‑platform mobile), Redux Toolkit, React Navigation  
- **Backend**: Node.js with Express, TypeScript, JWT auth  
- **Database**: PostgreSQL (relational) + Redis (caching)  
- **Infra/DevOps**: Docker, Kubernetes (EKS on AWS), Terraform, GitHub Actions CI/CD, CloudWatch  
- **AI/ML**: Hugging Face Transformers (clinical BERT) fine‑tuned on MedlinePlus, OpenAI GPT‑4 API for natural language understanding, Dockerized inference microservice  

## Architecture
MedMatch follows a micro‑service architecture where the mobile client communicates with a secure REST API gateway. The API gateway routes requests to specialized services: a triage service that runs a fine‑tuned clinical BERT model for symptom mapping, an availability service that queries a PostgreSQL database for provider slots, and a telehealth service that integrates with Twilio Video. All services are containerized and deployed on Amazon EKS, with CI/CD pipelines managed by GitHub Actions. Data is encrypted at rest and in transit, and user authentication is handled via JWT issued by Cognito.

## Roadmap
- **v1**: Core triage + provider lookup + patient profile; MVP for Android/iOS; basic analytics dashboard  
- **v2**: Telehealth scheduling, video consultation, multilingual UI, automated reminders  
- **v3**: AI‑driven predictive analytics for wait times, integration with regional EHRs, multi‑region deployment
