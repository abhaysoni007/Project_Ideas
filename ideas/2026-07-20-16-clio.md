# Clio

> offers a historical research and archive platform for academics, researchers, and students to access and analyze primary sources, documents, and artifacts from ancient civilizations and historical events.

## Problem
Open-source maintainers struggle to track their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Full-text search with smart filters
- Email and push notifications
- Usage analytics and an admin panel
- Public REST API with scoped API keys
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
