# Lumina

> enables educators to create and share interactive, augmented reality-based lesson plans and educational content

## Problem
Remote workers struggle to visualize their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Email and push notifications
- AI-assisted recommendations and summaries
- Audit log of every change
- Responsive dashboard with light and dark mode
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
