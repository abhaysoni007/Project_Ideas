# SnapKit

> A browser extension that shows the carbon footprint of each website you visit.

## Problem
Parents struggle to schedule their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Usage analytics and an admin panel
- AI-assisted recommendations and summaries
- Real-time updates over WebSockets
- Offline-first with background sync
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
