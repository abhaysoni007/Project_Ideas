# HomeHaven

> provides a platform for homeowners to find, review, and book trusted, pre-screened home maintenance and repair services.

## Problem
Open-source maintainers struggle to automate their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Audit log of every change
- Full-text search with smart filters
- Team workspaces with granular permissions
- Guided onboarding with ready-made templates
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
