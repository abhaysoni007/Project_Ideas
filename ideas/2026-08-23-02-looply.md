# Looply

> A CLI that turns terminal session recordings into shareable animated SVGs.

## Problem
Startups struggle to cluster their sensor data without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Public REST API with scoped API keys
- AI-assisted recommendations and summaries
- Team workspaces with granular permissions
- Integrations with Slack, Google, and Stripe
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
