# Greenify

> assists households and businesses in reducing their energy consumption and carbon footprint through a smart home automation and energy monitoring system

## Problem
Remote workers struggle to organize their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Responsive dashboard with light and dark mode
- Public REST API with scoped API keys
- Real-time updates over WebSockets
- One-click export to CSV and PDF
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
