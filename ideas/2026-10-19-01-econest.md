# EcoNest
> Smart hub that learns your routines to cut energy costs and carbon footprint.

## Problem
Energy waste in homes accounts for a significant portion of unnecessary consumption and emissions. Residents lack intuitive tools that adapt to their daily habits, leading to over‑use of heating, cooling, and appliances. Existing smart systems require manual scheduling, which is time‑consuming and often ignored.

## Target Users
- Eco‑conscious homeowners looking to reduce utility bills  
- Tech‑savvy families who want automated energy management  
- New smart‑home adopters seeking an easy‑to‑set‑up hub  
- Renters interested in short‑term energy savings  

## Key Features
- Automatic routine learning from occupancy sensors and device usage  
- Real‑time energy optimization for HVAC, lighting, and appliances  
- Voice & mobile app control with intuitive dashboards  
- Predictive maintenance alerts for appliances and HVAC systems  
- Carbon‑footprint dashboard with monthly savings reports  
- Seamless integration with existing Zigbee, Z-Wave, and Wi‑Fi devices  
- Local edge processing for privacy‑first data handling  

## Tech Stack
- **Frontend**: React 18 + TypeScript + Vite + TailwindCSS  
- **Backend**: NestJS (Node.js) + TypeScript + Fastify for micro‑services  
- **Database**: PostgreSQL 15 + Prisma ORM  
- **Infra/DevOps**: Docker + Kubernetes (GKE) + Terraform + GitHub Actions CI/CD  
- **AI/ML**: Python 3.11 + scikit‑learn for routine clustering; TensorFlow Lite for on‑device inference; MQTT broker (Mosquitto) for real‑time sensor data  

## Architecture
EcoNest follows a modular, event‑driven micro‑service architecture. Sensor data is ingested via MQTT, processed by a real‑time service that applies clustering algorithms to detect routines, and stored in PostgreSQL. The optimization engine runs as a separate service, generating HVAC and appliance schedules that are pushed to devices via a Zigbee gateway. A secure REST API exposes dashboards to the React frontend, while edge inference on the gateway ensures quick local responses for critical controls.

## Roadmap
- **v1** – Core hub with sensor ingestion, routine detection, and basic HVAC scheduling  
- **v2** – Expand device ecosystem (Z-Wave, Wi‑Fi), add mobile app, and implement carbon‑footprint analytics  
- **v3** – Introduce advanced ML models for predictive maintenance, community energy‑sharing features, and global multi‑tenant deployment with GDPR compliance
