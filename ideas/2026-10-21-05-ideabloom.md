# IdeaBloom  
> “Grow ideas, one translated headline at a time”

## Problem  
Freelancers often consume international news and market updates while working, but language barriers can slow research and decision‑making. Manually copying articles to a translator wastes time and disrupts workflow. A lightweight, in‑browser solution that instantly translates news feeds is missing.

## Target Users  
- Freelance writers covering global topics  
- Remote consultants needing quick access to international reports  
- Digital nomads who browse news on the go  
- Small business owners monitoring foreign markets  
- Language‑learning freelancers seeking contextual practice  

## Key Features  
- Inline headline translation with a single click  
- Automatic detection of language and context‑aware translation using GPT‑4o  
- Customizable translation presets (formal, casual, industry‑specific)  
- Dark‑mode and night‑time reading support  
- Bookmark and save translated articles locally  
- Extension settings panel for API key management and usage limits  
- Privacy‑first design: no user data stored on external servers  

## Tech Stack  
**Frontend**  
- Chrome/Firefox Extension APIs  
- React 18 + TypeScript  
- Styled‑Components for theme support  

**Backend**  
- Node.js 20 + Express  
- FastAPI for optional micro‑service endpoints  

**Database**  
- SQLite for local storage of bookmarks  
- Optional PostgreSQL on Heroku for advanced analytics  

**Infra/DevOps**  
- GitHub Actions CI/CD  
- Docker for containerized build  
- Render / Fly.io for hosting the optional API  

**AI/ML**  
- OpenAI GPT‑4o for translation  
- OpenAI embeddings for content summarization  

## Architecture  
IdeaBloom operates as a Chrome/Firefox extension that injects a minimal React UI into the browser. When a user clicks the translate button, the extension captures the headline text and forwards it to a lightweight Node.js backend hosted on Render. The backend calls GPT‑4o for translation, then returns the result to the extension which renders it inline. Bookmarks and settings are stored locally in SQLite, ensuring all user data stays on the device.

## Roadmap  
**v1** – Core extension with headline translation, preset management, and local storage.  
**v2** – Add article summarization, dark‑mode support, and analytics dashboard.  
**v3** – Cross‑platform mobile companion app, multi‑language UI, and community translation plug‑in.
