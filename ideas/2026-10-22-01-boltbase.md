# BoltBase
> From podcast snippets to travel roadmaps, in one click.

## Problem  
Podcasters often uncover hidden travel gems in long audio streams, but converting those moments into actionable itineraries is time‑consuming and error‑prone. Travel writers and planners need a fast way to harvest, tag, and visualize these insights without manual transcription or data entry.

## Target Users  
- Independent travel podcasters  
- Content creators curating travel guides  
- Tour operators looking for fresh destination ideas  
- Digital nomads seeking quick trip plans  
- Travel agencies automating itinerary generation  

## Key Features  
- Automatic transcription and highlight detection from raw podcast audio  
- AI‑generated tags (places, activities, budgets) attached to each highlight  
- Interactive map overlay linking highlights to geographic points  
- Exportable itinerary cards (PDF, CSV, Google Calendar)  
- Collaborative dashboard with comment threads and version history  
- Real‑time sync across devices via WebSocket  
- Customizable filters (time, tag, sentiment) for deep dives  

## Tech Stack  
- **Frontend**: React 18 + Next.js 14, TypeScript, Tailwind CSS, Vercel for hosting  
- **Backend**: Python 3.12 + FastAPI, asyncio, Gunicorn, Uvicorn  
- **Database**: PostgreSQL 15 (primary), Redis 7 for caching & pub/sub  
- **Infra/DevOps**: Docker, Docker Compose, Kubernetes (EKS), Terraform, GitHub Actions CI/CD, Prometheus + Grafana monitoring  
- **AI/ML**: OpenAI Whisper for speech‑to‑text, LangChain for semantic parsing, OpenAI GPT‑4 for summarization and itinerary generation, Pinecone for vector storage of embeddings  

## Architecture  
Audio files are uploaded to an S3 bucket, triggering a Lambda (or Cloud Function) that streams the clip to Whisper for transcription. The FastAPI service receives the text, runs a LangChain pipeline to extract entities and sentiment, and stores highlights with metadata in PostgreSQL. Vector embeddings of the text are indexed in Pinecone, enabling semantic search across highlights. The React dashboard consumes a GraphQL API built on FastAPI, presenting highlights on an interactive map and allowing users to build itineraries. Real‑time collaboration is achieved with WebSocket connections managed by FastAPI’s WebSocket support, while Redis handles pub/sub for instant updates. All components are containerized and orchestrated via Kubernetes, with CI/CD pipelines ensuring automated testing and deployment.  

## Roadmap  
- **v1**: Core ingestion, transcription, and static dashboard with map display.  
- **v2**: AI‑driven itinerary generation, collaborative editing, and export functionality.  
- **v3**: Real‑time audio streaming, mobile app (React Native), and personalized recommendation engine.
