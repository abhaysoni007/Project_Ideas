# Novaify

> A mobile app that gamifies news feeds to keep researchers engaged.

## Problem
Remote workers struggle to audit their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- AI-assisted recommendations and summaries
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- Real-time updates over WebSockets
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Django
- **Database:** MySQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Django API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
