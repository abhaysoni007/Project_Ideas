# MintWise

> A VS Code extension that helps job seekers automate screen time inside the editor.

## Problem
Gamers struggle to detect their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Offline-first with background sync
- AI-assisted recommendations and summaries
- Full-text search with smart filters
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
