# LingoLink

> connects language learners with native speaker tutors for one-on-one conversation practice and language exchange

## Problem
Teachers struggle to personalize their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- Audit log of every change
- Integrations with Slack, Google, and Stripe
- Full-text search with smart filters
- One-click export to CSV and PDF
- Offline-first with background sync

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
