# NestBoost

> A weekly-digest service that translates expenses and emails small teams a summary.

## Problem
Developers struggle to organize their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Team workspaces with granular permissions
- Usage analytics and an admin panel
- Guided onboarding with ready-made templates
- Responsive dashboard with light and dark mode
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
