# SafeZone

> Provides real-time safety alerts and navigation assistance to pedestrians, cyclists, and drivers using crowdsourced incident reporting and AI-driven predictive analytics

## Problem
Students struggle to schedule their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Full-text search with smart filters
- Usage analytics and an admin panel
- Offline-first with background sync

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Node.js + Express
- **Database:** Supabase
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Node.js + Express API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
