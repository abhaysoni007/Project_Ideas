# NestMate  
> **Power Up Your Dorm, One Choice at a Time**

## Problem  
Students often forget how their everyday habits affect campus energy consumption, leading to high bills and environmental impact. Existing utilities dashboards are dry and lack incentives, so engagement remains low.

## Target Users  
- College students living in dorms or shared apartments  
- Sustainability‑focused student organizations  
- Dormitory staff monitoring communal energy usage  

## Key Features  
- **Energy Score Dashboard** – visualize personal and room‑level consumption in real time  
- **Challenge Mode** – compete with roommates or classmates to hit weekly power‑saving goals  
- **Reward System** – unlock badges, campus perks, and carbon‑offset credits  
- **Smart Suggestions** – AI‑driven tips tailored to usage patterns (e.g., “Turn off lights after 10 pm”)  
- **Community Leaderboard** – compare departments, view top energy‑saving teams  
- **Gamified Quizzes** – short, interactive lessons that earn points and unlock achievements  
- **Offline Mode** – data syncs once connectivity is restored, ensuring continuous gameplay  

## Tech Stack  
- **Frontend**  
  - React Native (Expo) for cross‑platform mobile UI  
  - Redux Toolkit for state management  
  - TypeScript for type safety  
- **Backend**  
  - Node.js + Express.js  
  - NestJS for structured architecture  
  - GraphQL (Apollo Server) for efficient data queries  
- **Database**  
  - PostgreSQL (Heroku Postgres) for relational data  
  - Redis for caching leaderboard and real‑time metrics  
- **Infra/DevOps**  
  - Docker Compose for local dev, Kubernetes on Google Cloud Run for production  
  - GitHub Actions CI/CD pipelines with automated tests and container builds  
  - Terraform for IaC (Google Cloud resources)  
- **AI/ML**  
  - Python + scikit‑learn for consumption pattern clustering  
  - TensorFlow Lite models embedded in mobile app for on‑device suggestion generation  

## Architecture  
NestMate follows a micro‑service oriented architecture where the mobile client communicates with a GraphQL API that orchestrates calls to the user, usage, challenge, and reward services. The usage service ingests real‑time data from campus smart meters via MQTT, stores it in PostgreSQL, and pushes updates to Redis for instant leaderboard calculations. AI/ML inference runs offline on the device, reducing latency and preserving user privacy. All services are containerized and managed through Kubernetes, with autoscaling based on request load.

## Roadmap  
- **v1** – Core mobile app, real‑time energy dashboard, basic challenge mechanics, backend API, and unit/integration tests.  
- **v2** – AI‑driven suggestions, reward redemption integration with campus stores, multi‑device sync, and performance optimization.  
- **v3** – Advanced analytics dashboard for dorm staff, community events scheduling, cross‑campus leaderboard, and full end‑to‑end CI/CD pipeline automation.
