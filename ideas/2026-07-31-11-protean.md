# Protean

> Protean is a career development platform that uses AI-driven skills assessments, personalized coaching, and job market analytics to help professionals navigate career transitions and stay competitive.

## Problem
Students struggle to visualize their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- One-click export to CSV and PDF
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
