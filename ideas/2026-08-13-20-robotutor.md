# RoboTutor

> offers an AI-powered educational platform for students to learn programming concepts and develop coding skills through interactive tutorials and games.

## Problem
Students struggle to visualize their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Public REST API with scoped API keys
- One-click export to CSV and PDF
- Full-text search with smart filters
- Audit log of every change
- Email and push notifications

## Tech Stack
- **Frontend:** React Native
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
