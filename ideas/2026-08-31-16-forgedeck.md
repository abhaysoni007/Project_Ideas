# ForgeDeck

> A tool that scans your GitHub repos and auto-generates a portfolio site from your top projects.

## Problem
Researchers struggle to detect their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Researchers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Audit log of every change
- One-click export to CSV and PDF
- Team workspaces with granular permissions
- Full-text search with smart filters
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
