# LumenSpark

> A tool that audits a website's Core Web Vitals and suggests concrete fixes.

## Problem
Developers struggle to schedule their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Responsive dashboard with light and dark mode
- Guided onboarding with ready-made templates
- Offline-first with background sync
- Audit log of every change
- Email and push notifications

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
