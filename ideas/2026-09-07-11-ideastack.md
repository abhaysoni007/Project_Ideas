# IdeaStack

> A CLI that turns terminal session recordings into shareable animated SVGs.

## Problem
Developers struggle to organize their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- Responsive dashboard with light and dark mode
- Offline-first with background sync
- Integrations with Slack, Google, and Stripe
- Team workspaces with granular permissions
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** SQLite
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a NestJS API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
