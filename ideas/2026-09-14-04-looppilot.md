# LoopPilot

> A extension that summarizes long GitHub issues and their comment threads.

## Problem
Teachers struggle to optimize their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Offline-first with background sync
- Real-time updates over WebSockets
- One-click export to CSV and PDF
- Integrations with Slack, Google, and Stripe
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React
- **Backend:** FastAPI (Python)
- **Database:** MySQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a FastAPI (Python) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
