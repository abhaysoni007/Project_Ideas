# PulsePath

> A agriculture app that uses AI to summarize recipes for researchers.

## Problem
Teachers struggle to visualize their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Email/OAuth sign-in with role-based access control
- Responsive dashboard with light and dark mode
- Integrations with Slack, Google, and Stripe
- Public REST API with scoped API keys
- Email and push notifications

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
