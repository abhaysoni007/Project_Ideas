# BoltWise

> A weekly-digest service that summarizes news feeds and emails startups a summary.

## Problem
Founders struggle to optimize their sensor data without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Email and push notifications
- Real-time updates over WebSockets
- Usage analytics and an admin panel
- Full-text search with smart filters
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
