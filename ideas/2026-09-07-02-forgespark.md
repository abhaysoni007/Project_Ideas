# ForgeSpark

> An AI-free rule-based linter for accessibility issues in HTML emails.

## Problem
Startups struggle to predict their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- AI-assisted recommendations and summaries
- Public REST API with scoped API keys
- Offline-first with background sync
- One-click export to CSV and PDF
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
