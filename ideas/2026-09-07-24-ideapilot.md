# IdeaPilot

> A service that turns your bank statements into a plain-English monthly spending story.

## Problem
Gamers struggle to detect their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Audit log of every change
- Team workspaces with granular permissions
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** React
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
