# TerraVerde

> enables farmers and agricultural producers to monitor and manage their crops and soil health through a precision agriculture and IoT sensor platform.

## Problem
Teachers struggle to translate their invoices without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Guided onboarding with ready-made templates
- Full-text search with smart filters
- Audit log of every change
- AI-assisted recommendations and summaries
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** MySQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
