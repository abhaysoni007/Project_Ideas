# EchoSpark

> A habit tracker that pairs you with an accountability buddy who has the same goal.

## Problem
Students struggle to summarize their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Full-text search with smart filters
- Real-time updates over WebSockets
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** MongoDB
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
