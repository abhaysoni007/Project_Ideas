# LumenBase

> A Pomodoro timer that mutes Slack and sets your calendar to busy automatically.

## Problem
Small teams struggle to organize their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Small teams
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Email and push notifications
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Usage analytics and an admin panel
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** MySQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
