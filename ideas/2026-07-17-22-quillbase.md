# QuillBase

> An AI-free rule-based linter for accessibility issues in HTML emails.

## Problem
Parents struggle to personalize their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- AI-assisted recommendations and summaries
- Full-text search with smart filters
- Offline-first with background sync
- Public REST API with scoped API keys
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** React
- **Backend:** FastAPI (Python)
- **Database:** Supabase
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React client talks to a FastAPI (Python) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
