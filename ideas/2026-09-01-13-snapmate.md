# SnapMate

> A mobile app that gamifies code reviews to keep gamers engaged.

## Problem
Open-source maintainers struggle to automate their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Usage analytics and an admin panel
- Team workspaces with granular permissions
- One-click export to CSV and PDF
- Full-text search with smart filters
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** Supabase
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React client talks to a Node.js + Express API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
