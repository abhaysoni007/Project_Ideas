# EchoPath

> A mobile app that gamifies reading lists to keep parents engaged.

## Problem
Remote workers struggle to organize their invoices without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Team workspaces with granular permissions
- One-click export to CSV and PDF
- Email and push notifications
- Responsive dashboard with light and dark mode
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
