# MediSync
> Your personalized tele‑mental‑health partner for chronic anxiety

## Problem
People with chronic anxiety often struggle to find therapists whose approach and personality truly resonate with them, leading to low engagement and sub‑optimal outcomes. Existing tele‑health platforms match patients purely on availability or specialty, ignoring nuanced fit.

## Target Users
- Adults (18‑65) diagnosed with chronic anxiety disorders  
- Individuals seeking remote therapy due to mobility or stigma concerns  
- People who have tried traditional therapy and found it unhelpful  
- Clinicians wanting a data‑driven tool to optimize patient‑therapist matching  

## Key Features
- AI‑driven personality profiling from brief intake questionnaires  
- Smart matching algorithm that scores therapist compatibility on empathy, communication style, and therapeutic modality  
- Secure video‑chat, messaging, and session scheduling built into the platform  
- Real‑time analytics dashboard for therapists to track client progress and engagement  
- Automated reminders, session summaries, and self‑help resources tailored to the patient’s profile  
- HIPAA‑compliant data storage and end‑to‑end encryption for all communications  

## Tech Stack
**Frontend**  
- React 18 with TypeScript  
- Next.js for server‑side rendering and API routing  
- Tailwind CSS for rapid UI styling  

**Backend**  
- Node.js (Express) with TypeScript  
- RESTful API endpoints and WebSocket support (Socket.io)  

**Database**  
- PostgreSQL (primary relational store)  
- Redis for session caching and real‑time queueing  

**Infra/DevOps**  
- Docker for containerization  
- Kubernetes on AWS EKS for orchestration  
- Terraform for IaC  
- CI/CD with GitHub Actions (unit, integration, security scans)  

**AI/ML**  
- Python 3.10 microservice (FastAPI) for personality NLP pipeline  
- Hugging Face transformer (e.g., `distilbert-base-uncased`) fine‑tuned on therapy‑related text  
- Scoring engine in Rust for high‑performance matching at scale  

## Architecture
MediSync follows a modular micro‑service architecture. The React/Next.js frontend communicates with a Node/Express API gateway, which orchestrates calls to the AI micro‑service for profile scoring and to the PostgreSQL database for persistent storage. Real‑time interactions (video, chat) use Socket.io over secure WebSockets, while background jobs (reminders, analytics) are handled via Redis queues processed by worker pods in Kubernetes. All services run in Docker containers managed by EKS, with Terraform provisioning the infrastructure and GitHub Actions driving CI/CD pipelines.

## Roadmap
- **v1**: MVP – secure video‑chat, basic intake questionnaire, AI personality scoring, therapist dashboard, HIPAA compliance.  
- **v2**: Advanced matching (therapist specialty, session length), self‑help content library, mobile web PWA, analytics API.  
- **v3**: AI‑guided therapy notes, multi‑modal communication (voice, text), integration with EMR systems, internationalization.
