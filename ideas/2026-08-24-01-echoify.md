# Echoify

> A habit tracker that pairs you with an accountability buddy who has the same goal.

## Problem
Teachers struggle to schedule their workout plans without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Email and push notifications
- Team workspaces with granular permissions
- Integrations with Slack, Google, and Stripe
- Full-text search with smart filters
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
