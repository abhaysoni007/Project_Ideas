# Greenify

> assists businesses in reducing their environmental impact by providing a platform for tracking and improving sustainability metrics

## Problem
Teachers struggle to track their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Real-time updates over WebSockets
- Email/OAuth sign-in with role-based access control
- Audit log of every change
- Offline-first with background sync
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
