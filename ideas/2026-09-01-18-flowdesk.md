# FlowDesk

> A extension that summarizes long GitHub issues and their comment threads.

## Problem
Designers struggle to summarize their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Offline-first with background sync
- Integrations with Slack, Google, and Stripe
- Audit log of every change
- One-click export to CSV and PDF
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
