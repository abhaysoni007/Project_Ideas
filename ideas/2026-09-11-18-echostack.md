# EchoStack

> A VS Code extension that helps startups audit podcast highlights inside the editor.

## Problem
Open-source maintainers struggle to benchmark their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- AI-assisted recommendations and summaries
- Email/OAuth sign-in with role-based access control
- One-click export to CSV and PDF
- Usage analytics and an admin panel
- Offline-first with background sync

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
