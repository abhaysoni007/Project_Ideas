# MindMosaic  
> Your campus companion for calm and focus.

## Problem  
College students face mounting academic pressure, irregular study schedules, and limited access to affordable mental‑health support. Traditional counseling centers are often overburdened, leading to long wait times and a stigma around seeking help. Students need an always‑available, personalized resource that helps them manage stress and build healthy study habits in real time.

## Target Users  
- Undergraduate and graduate students aged 18‑24  
- Students enrolled in large universities or community colleges  
- Individuals seeking self‑help tools rather than formal therapy  
- Users comfortable with mobile and web apps  

## Key Features  
- AI‑powered conversational coach that offers CBT‑inspired coping techniques  
- Daily mood & study habit tracker with visual dashboards  
- Personalized study plan generator based on upcoming assignments and test dates  
- Context‑aware reminders and micro‑interventions via push notifications  
- Secure, GDPR‑/HIPAA‑compliant data storage with end‑to‑end encryption  
- Gamified progress rewards to encourage consistent usage  
- Optional integration with campus calendars and learning management systems  

## Tech Stack  
**Frontend**  
- React + TypeScript (web)  
- React Native + Expo (mobile)  

**Backend**  
- Node.js + Express + TypeScript  
- REST API with OpenAPI spec  

**Database**  
- PostgreSQL (primary data)  
- Redis (caching, session store)  

**Infra/DevOps**  
- Docker Compose for local dev, Kubernetes for production  
- GitHub Actions for CI/CD pipelines  
- Terraform + AWS (ECR, ECS Fargate, RDS, CloudWatch, S3)  

**AI/ML**  
- OpenAI GPT‑4 (Chat Completion API)  
- LangChain for prompt orchestration and memory management  
- LangSmith for debugging and monitoring conversational flows  

## Architecture  
MindMosaic follows a modular micro‑service architecture. The front‑end applications communicate with the API Gateway, which routes requests to stateless Node.js services: `auth-service`, `chat-service`, `analytics-service`, and `study-planner-service`. Data is persisted in a PostgreSQL cluster with read replicas for scalability, while Redis handles session tokens and real‑time user state. AI interactions are abstracted behind a dedicated `ai-service` that wraps the OpenAI API via LangChain, ensuring consistent prompt templates and context windows. All services are containerized and orchestrated on AWS Fargate, with Terraform managing infrastructure and GitHub Actions handling continuous integration and deployment.

## Roadmap  
- **v1** – Core chatbot, user authentication, mood/study tracking, basic analytics dashboard, push notifications  
- **v2** – Sentiment‑aware coaching, adaptive study plans, calendar sync, multi‑platform data sync, improved security audit  
- **v3** – Offline conversational mode, multilingual support, advanced gamification, institutional API, full compliance with FERPA and GDPR
