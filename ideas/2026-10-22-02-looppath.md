# LoopPath  
> Summarize GitHub Issues in a Snap  

## Problem  
GitHub issues and comment threads can quickly become unwieldy, making it hard to grasp key points and decisions at a glance. Developers and product managers waste valuable time scrolling through lengthy discussions. A concise, automated summary would streamline review and decision‑making.

## Target Users  
- Developers managing large backlogs  
- Product managers reviewing feature discussions  
- Open‑source maintainers needing quick overviews  
- QA engineers tracking issue resolution  

## Key Features  
- Automatic summarization of issue titles, bodies, and comment threads  
- Sentiment and decision tagging for comments  
- Contextual highlights of key decisions and blockers  
- Chrome extension that injects a sidebar into GitHub issue pages  
- Export summaries to Markdown or Slack channels  
- Customizable summary length (short, medium, long)  
- Real‑time updates when new comments arrive  

## Tech Stack  
**Frontend**  
- React + TypeScript  
- Redux Toolkit for global state  
- Tailwind CSS for styling  

**Backend**  
- Node.js + Express (TypeScript)  
- GitHub OAuth for authentication  

**Database**  
- PostgreSQL for persistent storage  
- Redis for caching summaries and rate limits  

**Infra/DevOps**  
- Docker + Docker Compose for local dev  
- Fly.io (or Render) for production deployment  
- GitHub Actions for CI/CD pipeline  
- Sentry for error monitoring  

**AI/ML**  
- OpenAI GPT‑4 Turbo via the OpenAI API  
- LangChain for prompt orchestration and chain management  
- Pinecone (optional) for semantic vector storage if fine‑tuning later  

## Architecture  
LoopPath operates as a Chrome extension that injects a sidebar into GitHub issue pages. The extension calls a lightweight backend API to fetch or generate summaries. The backend stores issue metadata in PostgreSQL, caches results in Redis, and interfaces with OpenAI’s GPT‑4 Turbo through a LangChain pipeline. Authentication is handled via GitHub OAuth. Docker containers facilitate local development, while Fly.io hosts the production service. GitHub Actions automates testing, building, and deployment, with Sentry capturing runtime errors.

## Roadmap  
- **v1** – Core Chrome extension, backend API, GPT‑4 summarization, Markdown export  
- **v2** – Slack integration, comment sentiment tagging, UI polish and accessibility  
- **v3** – Serverless deployment, optional fine‑tuning of the model, support for GitHub Enterprise and self‑hosted runners
