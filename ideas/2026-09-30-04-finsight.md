# FinSight
> Invest smarter, sustainably.

## Problem
Institutional investors lack a unified platform that delivers real‑time ESG insights alongside traditional market data. Existing solutions are fragmented, delay‑prone, and often require manual reconciliation of disparate data feeds, hampering timely sustainability decisions.

## Target Users
- Portfolio managers at asset‑management firms  
- Risk analysts in institutional investment banks  
- ESG compliance officers in pension funds and sovereign wealth funds  
- Wealth‑management teams focused on sustainable investing  

## Key Features
- Real‑time aggregation of ESG scores from multiple data providers (MSCI, Sustainalytics, Bloomberg ESG)  
- Live portfolio‑level sustainability dashboards with trend analytics  
- Custom risk‑weighting engine that integrates ESG scores into factor models  
- Automated alerts for ESG materiality events (scandals, regulatory changes)  
- API gateway for seamless ingestion into existing portfolio analytics platforms  
- Data provenance and audit trail for compliance reporting  
- Interactive data exploration with drill‑downs to company‑level disclosures  

## Tech Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS, Vite, Recoil for state management  
- **Backend**: NestJS (Node.js 20), TypeScript, GraphQL, Redis cache, WebSockets for live updates  
- **Database**: PostgreSQL 15 (normalized core data), TimescaleDB for time‑series ESG metrics, Supabase Auth  
- **Infra/DevOps**: Docker, Kubernetes (Amazon EKS), Helm, Terraform, GitHub Actions CI/CD, Prometheus + Grafana for monitoring  
- **AI/ML**: Python 3.11, FastAPI, Scikit‑learn for feature engineering, PyTorch for predictive ESG impact models, SageMaker for model deployment  

## Architecture
FinSight ingests ESG feeds via secure HTTPS connectors into a Kafka cluster, where micro‑services consume and normalise the data in real time. A stream‑processing layer (Kafka Streams) enriches metrics, applies custom weighting, and writes snapshots to TimescaleDB. The NestJS GraphQL API serves portfolio‑level queries, while a WebSocket channel pushes live updates to the React frontend. All services run in a containerised Kubernetes environment with GitHub Actions orchestrating CI/CD pipelines. AI/ML pipelines run in SageMaker to generate predictive ESG impact scores that feed back into the analytics engine.

## Roadmap
- **v1**: Core data ingestion, real‑time ESG dashboard, API gateway, basic risk‑weighting engine  
- **v2**: Advanced analytics (factor‑model integration, predictive scoring), user‑customisable alerts, audit trail, compliance reporting templates  
- **v3**: AI‑driven recommendation engine, collaborative portfolio editing, multi‑tenant SaaS deployment, open‑source SDK for third‑party integrations
