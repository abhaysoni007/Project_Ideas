# MintDeck

> An app that suggests recipes based on what's about to expire in your fridge.

## Problem
Open-source maintainers struggle to predict their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Integrations with Slack, Google, and Stripe
- Offline-first with background sync
- Full-text search with smart filters
- Usage analytics and an admin panel
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
