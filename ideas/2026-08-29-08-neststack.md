# NestStack

> A self-hosted tool that lets researchers translate API logs with full data privacy.

## Problem
Researchers struggle to visualize their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Researchers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Real-time updates over WebSockets
- Responsive dashboard with light and dark mode
- Integrations with Slack, Google, and Stripe
- Team workspaces with granular permissions
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a Node.js + Express API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
