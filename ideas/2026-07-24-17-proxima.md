# Proxima

> Provides real-time language translation and cultural consulting services for businesses operating in global markets

## Problem
Remote workers struggle to detect their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Offline-first with background sync
- Usage analytics and an admin panel
- AI-assisted recommendations and summaries
- Integrations with Slack, Google, and Stripe
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** MySQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a NestJS API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
