# VaultMate

> A browser extension that helps open-source maintainers automate daily habits while they browse.

## Problem
Open-source maintainers struggle to translate their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Public REST API with scoped API keys
- Guided onboarding with ready-made templates
- Responsive dashboard with light and dark mode
- Email/OAuth sign-in with role-based access control
- Email and push notifications

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Node.js + Express
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Node.js + Express API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
