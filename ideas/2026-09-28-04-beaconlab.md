# BeaconLab

> A CLI that detects unused dependencies across a monorepo and opens cleanup PRs.

## Problem
Parents struggle to translate their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Team workspaces with granular permissions
- Guided onboarding with ready-made templates
- Email and push notifications
- Audit log of every change
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
