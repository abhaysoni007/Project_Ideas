# DineDig

> connects foodies with local restaurants, chefs, and food trucks, allowing users to discover new cuisines, make reservations, and order food online.

## Problem
Remote workers struggle to predict their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- One-click export to CSV and PDF
- Real-time updates over WebSockets
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
