# ByteWise

> A browser extension that shows the carbon footprint of each website you visit.

## Problem
Startups struggle to cluster their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Responsive dashboard with light and dark mode
- Audit log of every change
- Integrations with Slack, Google, and Stripe
- Team workspaces with granular permissions
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
