# IdeaDesk

> A Chrome-to-mobile sync app that lets developers audit energy usage across devices.

## Problem
Gamers struggle to detect their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Responsive dashboard with light and dark mode
- Real-time updates over WebSockets
- Email and push notifications
- Usage analytics and an admin panel
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
