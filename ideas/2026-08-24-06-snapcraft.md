# SnapCraft

> A browser extension that helps remote workers benchmark podcast highlights while they browse.

## Problem
Gamers struggle to organize their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Responsive dashboard with light and dark mode
- Public REST API with scoped API keys
- Usage analytics and an admin panel
- Team workspaces with granular permissions
- Email and push notifications

## Tech Stack
- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a NestJS API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
