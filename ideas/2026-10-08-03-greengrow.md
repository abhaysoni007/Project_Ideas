# GreenGrow
> Smart hydroponics for the city garden

## Problem  
Urban dwellers lack space, time, and expertise to grow fresh vegetables indoors.  
Traditional hydroponic systems demand constant manual monitoring of light, temperature, and nutrient levels, leading to inconsistent yields and wasted resources.  

## Target Users  
- City residents with balcony or small apartment spaces  
- Tech‑savvy home growers looking for low‑maintenance solutions  
- Eco‑conscious consumers wanting fresh, pesticide‑free produce  
- Students and hobbyists experimenting with IoT and ML  
- Small cafés or restaurants seeking on‑site fresh produce  

## Key Features  
- Real‑time sensor monitoring (light, temperature, humidity, EC, pH) via ESP32 modules  
- AI‑driven climate and nutrient optimization that adjusts LED lighting, fan speed, and dosing pumps automatically  
- Mobile app (iOS & Android) with push alerts, remote control, and visual dashboards  
- Data analytics & trend reports to help users improve yields over time  
- Modular kit design for easy expansion (add more trays, grow lights, or sensors)  
- Energy‑efficient hardware and low‑power firmware for extended battery life  
- Community sharing platform to compare recipes, growth schedules, and tips  

## Tech Stack  

**Frontend**  
- Flutter (Dart) – cross‑platform mobile app  

**Backend**  
- Python FastAPI – RESTful API for device control and data ingestion  
- MQTT broker (AWS IoT Core) – lightweight pub/sub between sensors and cloud  

**Database**  
- PostgreSQL with TimescaleDB extension – time‑series storage of sensor data  

**Infra/DevOps**  
- Docker & Docker Compose – containerization of services  
- Kubernetes (AWS EKS) – orchestrate microservices at scale  
- GitHub Actions – CI/CD pipeline for automated builds, tests, and deployments  
- AWS S3 – static asset storage and OTA firmware updates  

**AI/ML**  
- TensorFlow Lite – lightweight inference on ESP32 for on‑device decision‑making  
- Python scikit‑learn/PyTorch – cloud‑based model training for advanced climate optimization  

## Architecture  
Sensors mounted on each grow tray run ESP32 firmware that collects environmental data and publishes via MQTT to AWS IoT Core. An MQTT bridge forwards messages to a FastAPI service that stores data in TimescaleDB and feeds it to the ML inference engine. The inference engine, running TensorFlow Lite on the edge and periodically updated via OTA, generates control signals (light intensity, fan speed, nutrient pump rates) sent back to the hardware. Users interact through a Flutter mobile app that consumes the FastAPI endpoints, displays dashboards, and allows manual overrides. Continuous integration pipelines build firmware, run tests, and deploy Docker containers to AWS EKS, ensuring rapid feature rollouts.

## Roadmap  

**v1 – Core MVP**  
- Hardware prototype with ESP32, LED strip, water pump, basic sensors  
- Mobile app skeleton with device pairing and live sensor display  
- Rule‑based control logic (threshold alerts, manual overrides)  

**v2 – AI & Automation**  
- Train and deploy initial ML model for climate and nutrient optimization  
- Implement automated dosing and lighting adjustments  
- Introduce data analytics dashboards and trend reports  
- Expand firmware to support OTA updates and edge inference  

**v3 – Ecosystem & Scale**  
- Integrate with smart home assistants (Alexa, Google Home)  
- Open API for third‑party developers and community extensions  
- Modular kit expansions (additional trays, grow lights, CO₂ injection)  
- Global deployment with multi‑region AWS infrastructure and localized firmware  
- Community platform for sharing recipes, schedules, and performance tips
