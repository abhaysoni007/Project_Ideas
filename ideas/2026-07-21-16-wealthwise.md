# WealthWise

> offers a personalized, AI-driven investment advisory platform, providing affordable, data-driven portfolio management and financial planning for individuals.

## Problem
Small teams struggle to schedule their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Small teams
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Audit log of every change
- Full-text search with smart filters
- AI-assisted recommendations and summaries
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
