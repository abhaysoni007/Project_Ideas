# IdeaBloom

> A extension that summarizes long GitHub issues and their comment threads.

## Problem
Creators struggle to schedule their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- Integrations with Slack, Google, and Stripe
- Guided onboarding with ready-made templates
- Public REST API with scoped API keys
- Email and push notifications

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
