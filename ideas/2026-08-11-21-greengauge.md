# GreenGauge

> helps businesses and organizations measure, track, and reduce their environmental impact and carbon footprint.

## Problem
Designers struggle to optimize their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Email and push notifications
- Guided onboarding with ready-made templates
- Usage analytics and an admin panel
- Real-time updates over WebSockets
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
