# PulseWise

> A mobile app that gamifies news feeds to keep freelancers engaged.

## Problem
Students struggle to organize their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Full-text search with smart filters
- Usage analytics and an admin panel
- Real-time updates over WebSockets
- One-click export to CSV and PDF
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
