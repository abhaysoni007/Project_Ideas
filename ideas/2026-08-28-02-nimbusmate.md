# NimbusMate

> A tool that scans your GitHub repos and auto-generates a portfolio site from your top projects.

## Problem
Remote workers struggle to detect their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Public REST API with scoped API keys
- Real-time updates over WebSockets
- Guided onboarding with ready-made templates
- Usage analytics and an admin panel
- Full-text search with smart filters

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
