# DriftDeck

> A service that turns your bank statements into a plain-English monthly spending story.

## Problem
Freelancers struggle to organize their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Freelancers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Usage analytics and an admin panel
- Email/OAuth sign-in with role-based access control
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- Audit log of every change

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
