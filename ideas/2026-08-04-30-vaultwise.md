# VaultWise

> A data visualization app that uses AI to benchmark news feeds for founders.

## Problem
Freelancers struggle to predict their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Freelancers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Audit log of every change
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- AI-assisted recommendations and summaries
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
