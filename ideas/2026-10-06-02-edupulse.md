# EduPulse
> Empower mid‑level managers with micro‑credentials that showcase real‑world skill mastery

## Problem
Corporate training programs often reward completion with generic certificates that lack real‑world relevance and are hard to showcase. Managers struggle to demonstrate skill gains to stakeholders, leading to stalled career progression and low engagement.

## Target Users
- Mid‑level managers seeking professional development
- HR teams looking to track and recognize employee growth
- Corporate learning and development departments
- Team leads who want to incentivize skill acquisition

## Key Features
- Modular skill paths with real‑world case studies
- Gamified badge earning system tied to performance metrics
- Social sharing of badges on LinkedIn and company intranet
- Analytics dashboard for managers and HR
- API for integrating with existing LMS and HRIS
- Adaptive learning recommendations powered by AI
- Mobile‑friendly responsive UI

## Tech Stack
- **Frontend**
  - React 18 + TypeScript
  - Next.js for server‑side rendering
  - Tailwind CSS for utility‑first styling
  - React Query for data fetching
- **Backend**
  - Node.js (NestJS) + TypeScript
  - GraphQL with Apollo Server
  - JWT + OAuth2 for authentication
- **Database**
  - PostgreSQL 15 (primary data store)
  - Redis 7 (caching and session store)
- **Infra/DevOps**
  - Docker + Docker Compose for local development
  - Kubernetes on Google Kubernetes Engine (GKE)
  - GitHub Actions for CI/CD pipelines
  - Terraform for IaC
  - Prometheus + Grafana for monitoring
- **AI/ML**
  - OpenAI GPT‑4 API for skill recommendation engine
  - Python microservice for NLP badge description generation

## Architecture
EduPulse follows a micro‑service pattern: a Next.js frontend communicates with a NestJS GraphQL API. The API interacts with PostgreSQL for persistence and Redis for caching. AI services run as isolated Python containers, exposed via REST endpoints. The entire stack is containerized, deployed on GKE, and managed with Terraform. Observability is provided by Prometheus metrics and Grafana dashboards.

## Roadmap
- **v1** – Core LMS with badge issuance, admin dashboard, and basic analytics
- **v2** – AI‑driven skill recommendations, API integrations (LMS/HRIS), mobile responsive redesign
- **v3** – Advanced gamification (leaderboards, streaks), real‑time analytics, enterprise SSO, multi‑tenant support
