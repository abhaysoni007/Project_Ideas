# Artify

> Artify is a digital art marketplace for artists, galleries, and collectors, allowing them to buy, sell, and showcase original artwork and prints.

## Problem
Gamers struggle to predict their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- One-click export to CSV and PDF
- Full-text search with smart filters
- Email and push notifications
- Audit log of every change
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
