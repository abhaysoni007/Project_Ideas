# Elevate

> offers a community-driven platform for startups and entrepreneurs to connect with mentors, investors, and resources tailored to their growth stage and industry.

## Problem
Small teams struggle to personalize their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Small teams
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Email/OAuth sign-in with role-based access control
- One-click export to CSV and PDF
- Responsive dashboard with light and dark mode
- Usage analytics and an admin panel
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
