# OrbitGrid

> A CLI tool that automates study material in agriculture workflows.

## Problem
Researchers struggle to detect their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Researchers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- Real-time updates over WebSockets
- Email/OAuth sign-in with role-based access control
- AI-assisted recommendations and summaries
- Offline-first with background sync

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
