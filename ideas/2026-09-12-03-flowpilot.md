# FlowPilot

> A service that turns your bank statements into a plain-English monthly spending story.

## Problem
Gamers struggle to automate their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- Public REST API with scoped API keys
- Guided onboarding with ready-made templates
- Responsive dashboard with light and dark mode
- Audit log of every change
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
