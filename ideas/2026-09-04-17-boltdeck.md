# BoltDeck

> A Pomodoro timer that mutes Slack and sets your calendar to busy automatically.

## Problem
Teachers struggle to audit their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Responsive dashboard with light and dark mode
- Audit log of every change
- Email and push notifications
- Guided onboarding with ready-made templates
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Node.js + Express
- **Database:** SQLite
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Node.js + Express API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
