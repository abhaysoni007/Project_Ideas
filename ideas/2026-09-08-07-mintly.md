# Mintly

> An API service that lets developers add code reviews to any gaming product.

## Problem
Gamers struggle to summarize their sensor data without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Public REST API with scoped API keys
- Full-text search with smart filters
- One-click export to CSV and PDF
- Usage analytics and an admin panel
- Audit log of every change

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
