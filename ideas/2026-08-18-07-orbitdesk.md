# OrbitDesk

> A tool that watches competitor pricing pages and alerts you when prices change.

## Problem
Remote workers struggle to track their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Integrations with Slack, Google, and Stripe
- One-click export to CSV and PDF
- Offline-first with background sync
- AI-assisted recommendations and summaries
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
