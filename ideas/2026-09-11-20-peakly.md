# Peakly

> An AI-free rule-based linter for accessibility issues in HTML emails.

## Problem
Remote workers struggle to detect their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- Public REST API with scoped API keys
- Offline-first with background sync
- Guided onboarding with ready-made templates
- Responsive dashboard with light and dark mode
- Email and push notifications

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
