# Lumina

> enables data scientists and analysts to develop and deploy machine learning models through a cloud-based platform and collaborative workspace

## Problem
Designers struggle to translate their sensor data without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Real-time updates over WebSockets
- Public REST API with scoped API keys
- Audit log of every change
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
