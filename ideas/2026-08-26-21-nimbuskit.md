# NimbusKit

> A tool that watches competitor pricing pages and alerts you when prices change.

## Problem
Freelancers struggle to schedule their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Freelancers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Email and push notifications
- Offline-first with background sync
- One-click export to CSV and PDF
- Guided onboarding with ready-made templates
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
