# PulseBloom

> An app that suggests recipes based on what's about to expire in your fridge.

## Problem
Gamers struggle to optimize their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Team workspaces with granular permissions
- Guided onboarding with ready-made templates
- Integrations with Slack, Google, and Stripe
- Public REST API with scoped API keys
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
