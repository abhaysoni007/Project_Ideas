# SageWorks

> A Slack/Discord bot that helps freelancers predict travel itineraries without leaving chat.

## Problem
Teachers struggle to predict their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Audit log of every change
- Email and push notifications
- Integrations with Slack, Google, and Stripe
- Full-text search with smart filters
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** React Native
- **Backend:** Node.js + Express
- **Database:** MySQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Node.js + Express API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
