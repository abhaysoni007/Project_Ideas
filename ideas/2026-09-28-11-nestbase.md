# NestBase

> A Slack/Discord bot that helps remote workers detect git commits without leaving chat.

## Problem
Freelancers struggle to schedule their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Freelancers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Offline-first with background sync
- AI-assisted recommendations and summaries
- Full-text search with smart filters
- Usage analytics and an admin panel
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** MySQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
