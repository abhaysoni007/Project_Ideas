# PulseKit

> A browser extension that helps designers personalize invoices while they browse.

## Problem
Founders struggle to optimize their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Email and push notifications
- Offline-first with background sync
- Public REST API with scoped API keys
- Responsive dashboard with light and dark mode
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
