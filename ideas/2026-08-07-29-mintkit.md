# MintKit

> A study app that turns your highlighted PDFs into spaced-repetition flashcards.

## Problem
Students struggle to recommend their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- AI-assisted recommendations and summaries
- Full-text search with smart filters
- Email and push notifications
- One-click export to CSV and PDF
- Audit log of every change

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
