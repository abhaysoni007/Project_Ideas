# QuillStack

> A browser extension that helps freelancers detect API logs while they browse.

## Problem
Remote workers struggle to automate their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Email and push notifications
- Offline-first with background sync
- Audit log of every change
- Public REST API with scoped API keys
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
