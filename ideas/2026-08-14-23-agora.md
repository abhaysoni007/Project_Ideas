# Agora

> connects local businesses and communities with customers and tourists through a location-based marketing and discovery platform

## Problem
Designers struggle to automate their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Integrations with Slack, Google, and Stripe
- AI-assisted recommendations and summaries
- Public REST API with scoped API keys
- Email and push notifications
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
