# Bloombox

> enables gardeners and urban farmers to monitor and control their plant growth, soil conditions, and watering schedules through a smart gardening system and mobile app.

## Problem
Open-source maintainers struggle to track their invoices without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Public REST API with scoped API keys
- One-click export to CSV and PDF
- Full-text search with smart filters
- Guided onboarding with ready-made templates
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
