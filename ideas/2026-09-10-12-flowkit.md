# FlowKit

> A no-code builder for freelancers to predict API logs without writing code.

## Problem
Designers struggle to predict their workout plans without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- Responsive dashboard with light and dark mode
- Public REST API with scoped API keys
- Integrations with Slack, Google, and Stripe
- Email and push notifications
- Audit log of every change

## Tech Stack
- **Frontend:** Next.js
- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a FastAPI (Python) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
