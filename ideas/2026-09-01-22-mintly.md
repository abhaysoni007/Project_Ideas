# Mintly

> A browser extension that helps startups organize git commits while they browse.

## Problem
Students struggle to cluster their workout plans without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Responsive dashboard with light and dark mode
- Real-time updates over WebSockets
- Usage analytics and an admin panel
- Offline-first with background sync
- Full-text search with smart filters

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Django
- **Database:** MongoDB
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Django API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
