# LumenDeck

> A dashboard that grades your resume against a job description and lists gaps.

## Problem
Students struggle to optimize their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Guided onboarding with ready-made templates
- Offline-first with background sync
- Public REST API with scoped API keys
- Email and push notifications
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
