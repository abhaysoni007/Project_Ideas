# SnapPath

> A VS Code extension that helps startups optimize git commits inside the editor.

## Problem
Startups struggle to translate their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Team workspaces with granular permissions
- Audit log of every change
- Email/OAuth sign-in with role-based access control
- Offline-first with background sync
- Full-text search with smart filters

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
