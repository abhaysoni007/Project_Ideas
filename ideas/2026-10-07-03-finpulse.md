# FinPulse
> Effortless micro‑investment for gig workers

## Problem  
Gig workers receive income in fragmented payments that rarely sit in a bank account long enough to benefit from compound interest. They lack a low‑friction way to save and invest, and high‑fee robo‑advisors are out of reach. This results in missed opportunities to build sustainable wealth.

## Target Users  
- Freelancers on platforms such as Upwork, Fiverr, and TaskRabbit  
- Rideshare drivers and delivery couriers  
- Independent contractors across creative, tech, and professional services  
- Millennials & Gen Z who prefer app‑centric financial tools  

## Key Features  
- **Automatic Rounding‑Up**: Every gig payment is rounded to the nearest dollar and the difference is invested automatically.  
- **Diversified Portfolio Engine**: Core allocation across equities, bonds, and ESG funds with low management fees.  
- **Real‑Time Earnings Sync**: Connect to Stripe, PayPal, and major gig platforms for instant payment capture.  
- **Low‑Cost Execution**: Use commission‑free brokerage APIs (Alpaca, Interactive Brokers) to keep fees under 0.1 %.  
- **Tax‑Reporting & Compliance**: Quarterly 1099‑K/1099‑NEC generation and IRS‑approved record‑keeping.  
- **AI‑Driven Risk Scoring**: On‑device risk assessment that adapts to income volatility.  
- **Social & Community**: Follow peers, share investment milestones, and join “investment circles” for peer‑to‑peer inspiration.  

## Tech Stack  
- **Frontend**: React Native (Expo) for cross‑platform mobile apps, TypeScript.  
- **Backend**: Node.js with NestJS microservice architecture, TypeScript.  
- **Database**: PostgreSQL for relational data, Redis for caching and rate‑limiting.  
- **Infra/DevOps**: Docker + Kubernetes on GKE, GitHub Actions CI/CD, Terraform for IaC, Cloudflare CDN & WAF.  
- **AI/ML**: Python (scikit‑learn, pandas) for portfolio optimization; TensorFlow Lite for on‑device risk scoring.  
- **Payment & Brokerage**: Stripe Connect for payouts, Alpaca API for commission‑free trading.  

## Architecture  
FinPulse is built as a serverless‑ready microservices stack: the mobile app communicates with a NestJS API Gateway that orchestrates services via a message bus (NATS). Core services include Payment Capture, Rounding Engine, Portfolio Manager, and Tax Reporting. All services use PostgreSQL for persistence and publish events to Kafka for audit and analytics pipelines. Containerized deployments run on GKE with rolling updates managed by ArgoCD.

## Roadmap  
- **v1** – Core investment engine, round‑up logic, Stripe Connect onboarding, basic 1‑asset class portfolio, regulatory compliance, MVP mobile apps.  
- **v2** – Multi‑asset diversification, AI‑based risk scoring, tax‑loss harvesting, multi‑currency support, API for platform partners.  
- **v3** – Community/social investing features, advanced analytics dashboard, native browser extension for web gig platforms, open‑source SDK for third‑party integrations.
