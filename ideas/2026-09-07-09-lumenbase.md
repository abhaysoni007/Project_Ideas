# LumenBase

> A budgeting app for freelancers that sets aside tax money on every invoice paid.

## Problem
Parents struggle to personalize their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Responsive dashboard with light and dark mode
- AI-assisted recommendations and summaries
- Audit log of every change
- Team workspaces with granular permissions
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** React
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
