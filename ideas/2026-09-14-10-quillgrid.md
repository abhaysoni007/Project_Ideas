# QuillGrid

> A VS Code extension that helps founders organize energy usage inside the editor.

## Problem
Startups struggle to audit their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Real-time updates over WebSockets
- Email and push notifications
- Email/OAuth sign-in with role-based access control
- Usage analytics and an admin panel
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
