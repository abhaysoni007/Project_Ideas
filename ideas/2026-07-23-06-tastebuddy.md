# TasteBuddy
> Discover your flavor, locally.
## Problem
The current process of finding restaurants and cafes that cater to individual tastes and dietary requirements can be time-consuming and often relies on word of mouth or generic review platforms. This can lead to disappointing dining experiences and a lack of exploration of local hidden gems. Furthermore, existing review platforms often do not account for the unique flavor profiles and dietary preferences of individual users.

## Target Users
* Foodies looking to explore local cuisine
* Individuals with specific dietary requirements or restrictions (vegan, gluten-free, etc.)
* Travelers seeking authentic local dining experiences
* Restaurant and cafe owners looking to promote their establishments

## Key Features
* User profiling based on flavor preferences and dietary needs
* Personalized restaurant and cafe recommendations
* Review system with flavor profile tagging
* Integration with map services for location-based discovery
* Social features for users to share dining experiences and follow recommendations
* Restaurant and cafe owner dashboard for managing listings and promotions

## Tech Stack
* Frontend:
  + React for building the user interface
  + Redux for state management
* Backend:
  + Node.js with Express for server-side logic
  + GraphQL API for data querying
* Database:
  + MongoDB for storing user and establishment data
* Infra/DevOps:
  + Docker for containerization
  + Kubernetes for orchestration
* AI/ML:
  + TensorFlow for building the recommendation engine

## Architecture
The TasteBuddy application will follow a microservices architecture, with separate services for user management, establishment listings, and recommendation generation. The frontend will communicate with the backend via GraphQL API, and the backend services will interact with the database and AI/ML components as needed. This architecture will allow for scalability, flexibility, and ease of maintenance.

## Roadmap
* v1:
  + Basic user profiling and personalized recommendations
  + Integration with map services for location-based discovery
* v2:
  + Review system with flavor profile tagging
  + Social features for users to share dining experiences
* v3:
  + Advanced recommendation engine using machine learning
  + Establishment owner dashboard for managing listings and promotions
