# GlowForge

> develops a digital publishing and content creation platform for authors, writers, and artists to produce, distribute, and monetize their work, using blockchain technology and AI-powered tools.

## Problem
Students struggle to organize their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Real-time updates over WebSockets
- Email/OAuth sign-in with role-based access control
- Team workspaces with granular permissions
- Email and push notifications
- Offline-first with background sync

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
