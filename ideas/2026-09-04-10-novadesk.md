# NovaDesk

> A dashboard that grades your resume against a job description and lists gaps.

## Problem
Students struggle to recommend their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Offline-first with background sync
- Guided onboarding with ready-made templates
- Public REST API with scoped API keys
- Real-time updates over WebSockets
- Full-text search with smart filters

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
