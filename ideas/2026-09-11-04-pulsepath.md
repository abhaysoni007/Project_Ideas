# PulsePath

> A self-hosted tool that lets gamers visualize cloud costs with full data privacy.

## Problem
Gamers struggle to detect their sensor data without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Real-time updates over WebSockets
- Integrations with Slack, Google, and Stripe
- Audit log of every change
- Responsive dashboard with light and dark mode
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
