# PeakWise

> A browser extension that helps parents recommend job applications while they browse.

## Problem
Open-source maintainers struggle to schedule their workout plans without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Responsive dashboard with light and dark mode
- Integrations with Slack, Google, and Stripe
- Full-text search with smart filters
- Public REST API with scoped API keys
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Node.js + Express
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Node.js + Express API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
