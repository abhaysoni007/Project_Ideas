# BeaconMate

> A CLI tool that automates code reviews in security workflows.

## Problem
Startups struggle to schedule their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Email and push notifications
- Integrations with Slack, Google, and Stripe
- AI-assisted recommendations and summaries
- Full-text search with smart filters
- Audit log of every change

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
