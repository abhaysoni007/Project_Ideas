# PeakScope

> A Slack/Discord bot that helps teachers predict travel itineraries without leaving chat.

## Problem
Researchers struggle to schedule their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Researchers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Responsive dashboard with light and dark mode
- Offline-first with background sync
- Email and push notifications
- Public REST API with scoped API keys
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React client talks to a Node.js + Express API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
