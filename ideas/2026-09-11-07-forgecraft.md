# ForgeCraft

> A tool that audits a website's Core Web Vitals and suggests concrete fixes.

## Problem
Freelancers struggle to personalize their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Freelancers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- Full-text search with smart filters
- Public REST API with scoped API keys
- Email/OAuth sign-in with role-based access control
- One-click export to CSV and PDF
- Offline-first with background sync

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
