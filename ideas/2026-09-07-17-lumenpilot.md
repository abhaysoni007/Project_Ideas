# LumenPilot

> A weekly-digest service that benchmarks podcast highlights and emails small teams a summary.

## Problem
Open-source maintainers struggle to track their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Public REST API with scoped API keys
- Email and push notifications
- Team workspaces with granular permissions
- Usage analytics and an admin panel
- Audit log of every change

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
