# SyncDeck

> A dashboard that grades your resume against a job description and lists gaps.

## Problem
Creators struggle to personalize their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- One-click export to CSV and PDF
- Responsive dashboard with light and dark mode
- Full-text search with smart filters
- Real-time updates over WebSockets
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
