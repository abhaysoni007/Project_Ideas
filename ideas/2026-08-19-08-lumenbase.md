# LumenBase

> A study app that turns your highlighted PDFs into spaced-repetition flashcards.

## Problem
Students struggle to optimize their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Integrations with Slack, Google, and Stripe
- Offline-first with background sync
- AI-assisted recommendations and summaries
- Team workspaces with granular permissions
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
