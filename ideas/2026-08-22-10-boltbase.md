# BoltBase

> A tool that maps your codebase into an interactive dependency graph.

## Problem
Founders struggle to translate their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- Email and push notifications
- Integrations with Slack, Google, and Stripe
- AI-assisted recommendations and summaries
- Team workspaces with granular permissions
- Audit log of every change

## Tech Stack
- **Frontend:** React Native
- **Backend:** Node.js + Express
- **Database:** MySQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Node.js + Express API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
