# Profectus

> provides a project management and productivity tool for remote teams and freelancers, featuring automated task assignment and time tracking

## Problem
Parents struggle to personalize their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- One-click export to CSV and PDF
- AI-assisted recommendations and summaries
- Email and push notifications
- Real-time updates over WebSockets
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
