# JobJourney

> guides job seekers through a personalized career development process, including resume building, interview prep, and networking.

## Problem
Students struggle to recommend their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Email and push notifications
- Real-time updates over WebSockets
- AI-assisted recommendations and summaries
- Team workspaces with granular permissions
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Node.js + Express API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
