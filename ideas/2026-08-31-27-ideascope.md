# IdeaScope

> A CLI tool that automates reading lists in health & fitness workflows.

## Problem
Developers struggle to cluster their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Offline-first with background sync
- Email/OAuth sign-in with role-based access control
- Team workspaces with granular permissions
- Guided onboarding with ready-made templates
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** React Native
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
