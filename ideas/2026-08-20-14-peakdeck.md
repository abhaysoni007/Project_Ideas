# PeakDeck

> An app that converts long YouTube tutorials into step-by-step markdown notes.

## Problem
Designers struggle to cluster their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Usage analytics and an admin panel
- Audit log of every change
- Integrations with Slack, Google, and Stripe
- Responsive dashboard with light and dark mode
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
