# Lumenify

> A habit tracker that pairs you with an accountability buddy who has the same goal.

## Problem
Parents struggle to visualize their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Offline-first with background sync
- Audit log of every change
- AI-assisted recommendations and summaries
- One-click export to CSV and PDF
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Go (Gin)
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Go (Gin) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
