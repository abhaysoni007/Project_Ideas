# LumenLab

> An app that converts long YouTube tutorials into step-by-step markdown notes.

## Problem
Remote workers struggle to optimize their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Full-text search with smart filters
- Team workspaces with granular permissions
- Audit log of every change
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** MySQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
