# NovaDesk
> Real‑time competitor price monitoring, instant alerts, and actionable insights.

## Problem
Retailers and e‑commerce managers struggle to keep track of constantly changing competitor prices. Manual checks are slow and error‑prone, leading to missed opportunities or overpricing.

## Target Users
- E‑commerce store owners  
- Digital marketing managers  
- Competitive intelligence analysts  
- Small‑to‑medium business owners  

## Key Features
- **Web‑scraping scheduler** that visits competitor sites on a configurable cadence  
- **Price‑change detection** with fuzzy matching for dynamic content  
- **Multi‑channel alerts** (email, Slack, SMS, webhook)  
- **Dashboard** displaying historical price trends and volatility heatmaps  
- **API access** for integrating alerts into existing ERP or CRM systems  
- **Role‑based access control** for team collaboration  
- **Compliance checker** to ensure scraping respects robots.txt and terms of service

## Tech Stack
- **Frontend**  
  - React 18 with TypeScript  
  - Tailwind CSS  
  - Vite build tool  
- **Backend**  
  - Node.js 20 (Express)  
  - BullMQ for job queueing  
- **Database**  
  - PostgreSQL 16 (primary data store)  
  - Redis 7 (caching & queue broker)  
- **Infra/DevOps**  
  - Docker & Docker‑Compose for local dev  
  - GitHub Actions CI/CD pipelines  
  - Terraform for provisioning on AWS (EC2, RDS, ElastiCache)  
- **AI/ML**  
  - Python 3.11 scripts (BeautifulSoup + lxml) for scraping  
  - spaCy for natural language processing to detect price phrases  
  - Simple decision tree in JavaScript for alert throttling

## Architecture
NovaDesk employs a micro‑service pattern where a scheduler service triggers scraping jobs, a worker pool processes HTML, extracts prices using NLP, and writes results to PostgreSQL. The frontend communicates via a secure REST/GraphQL API. Redis serves as both a message broker and cache layer. Alerts are routed through a notification service that supports multiple channels, all orchestrated by a central event bus.

## Roadmap
- **v1** – Core scraper, price change detection, email alerts, web dashboard, basic auth.  
- **v2** – Slack & SMS integration, role‑based permissions, API gateway, CI/CD.  
- **v3** – Machine‑learning price prediction, competitor ranking analytics, mobile app, multi‑tenant SaaS deployment.
