# PeakMate

> A Chrome-to-mobile sync app that lets teachers visualize podcast highlights across devices.

## Problem
Remote workers struggle to visualize their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Email and push notifications
- One-click export to CSV and PDF
- Public REST API with scoped API keys
- Audit log of every change
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
