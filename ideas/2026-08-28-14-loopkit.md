# LoopKit

> A dashboard that grades your resume against a job description and lists gaps.

## Problem
Developers struggle to summarize their invoices without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Full-text search with smart filters
- Public REST API with scoped API keys
- Integrations with Slack, Google, and Stripe
- Real-time updates over WebSockets
- Offline-first with background sync

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
