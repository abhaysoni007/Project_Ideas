# Symphony

> Streamlines supply chain management for e-commerce businesses by integrating inventory tracking, shipping logistics, and demand forecasting

## Problem
Remote workers struggle to translate their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Integrations with Slack, Google, and Stripe
- Responsive dashboard with light and dark mode
- Guided onboarding with ready-made templates
- Usage analytics and an admin panel
- Email and push notifications

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
