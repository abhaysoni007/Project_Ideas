# HealTrack  
> **“Real‑time health, real‑time peace of mind.”**

## Problem  
Seniors with chronic conditions often experience sudden health deteriorations that go unnoticed until an emergency arises. Traditional monitoring relies on intermittent check‑ins or bulky hospital equipment, creating delays in response and anxiety for families and providers.

## Target Users  
- Elderly patients (65+) with chronic diseases (e.g., hypertension, diabetes, COPD)  
- Primary caregivers (family members, home health aides)  
- Primary care physicians and home‑health clinics  
- Geriatric specialists and tele‑health platforms

## Key Features  
- **Continuous vital‑sign monitoring** (heart rate, blood pressure, SpO₂, temperature) via a lightweight wristband  
- **AI‑driven anomaly detection** that flags deviations in real time and prioritizes alerts by severity  
- **Secure, HIPAA‑compliant data sync** to a cloud dashboard for caregivers and clinicians  
- **Customizable alert thresholds** and notification channels (push, SMS, email)  
- **Medication reminder and adherence tracking** integrated with the wearable  
- **Battery‑efficient power management** with predictive alerts for low power  
- **Offline mode** that stores data locally and syncs when connectivity is restored

## Tech Stack  
- **Frontend**: React Native (iOS/Android), TypeScript, Redux Toolkit, Expo  
- **Backend**: Node.js (Express) with TypeScript, GraphQL (Apollo Server)  
- **Database**: PostgreSQL (primary), TimescaleDB extension for time‑series data  
- **Infra/DevOps**: Docker, Kubernetes (EKS), Terraform, GitHub Actions CI/CD, Prometheus + Grafana for monitoring  
- **AI/ML**: Python (FastAPI), TensorFlow Lite for on‑device inference, custom anomaly detection models trained on MIMIC‑III dataset, model deployment via SageMaker Edge Manager  

## Architecture  
The system follows a microservice architecture where the wearable device streams encrypted sensor data to an edge gateway (AWS IoT Core). The gateway forwards data to the backend via MQTT, where a GraphQL API aggregates, persists, and serves it to a web dashboard. AI inference runs both on‑device (TensorFlow Lite) for immediate alerts and in the cloud (SageMaker) for batch model updates. All services are containerized and orchestrated on EKS, with Terraform provisioning and GitHub Actions automating the CI/CD pipeline.

## Roadmap  
- **v1**: MVP wearable prototype, basic vitals streaming, on‑device anomaly detection, web dashboard, caregiver notifications  
- **v2**: Cloud‑based ML model updates, physician portal integration (FHIR), medication reminder, battery optimization, regulatory compliance audit  
- **v3**: Expanded sensor suite (ECG, activity), predictive analytics dashboard, integration with major EHR systems, multi‑language support, international regulatory approval
