# Veritas

> assists fact-checkers and journalists in verifying the accuracy of news stories and social media posts through an AI-powered platform

## Problem
Students struggle to benchmark their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Offline-first with background sync
- Real-time updates over WebSockets
- Full-text search with smart filters
- Email and push notifications

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
