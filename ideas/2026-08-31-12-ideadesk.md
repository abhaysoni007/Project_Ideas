# IdeaDesk

> An API service that lets developers add expenses to any agriculture product.

## Problem
Designers struggle to track their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Real-time updates over WebSockets
- Team workspaces with granular permissions
- AI-assisted recommendations and summaries
- Offline-first with background sync
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
