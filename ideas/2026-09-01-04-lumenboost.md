# LumenBoost

> A study app that turns your highlighted PDFs into spaced-repetition flashcards.

## Problem
Designers struggle to audit their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Full-text search with smart filters
- Guided onboarding with ready-made templates
- Team workspaces with granular permissions
- Public REST API with scoped API keys
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** Supabase
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
