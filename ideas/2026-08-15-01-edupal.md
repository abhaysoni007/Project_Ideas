# EduPal
> Empowering inclusive learning, one student at a time
## Problem
Students with disabilities often face significant barriers when navigating online educational platforms, resulting in frustration and decreased academic performance. Existing solutions can be cumbersome, non-intuitive, and lack personalization. This hinders their ability to fully engage with coursework and reach their full potential.
## Target Users
* Students with visual impairments
* Students with hearing impairments
* Students with cognitive or learning disabilities
* Students with motor or dexterity impairments
* Educators and administrators supporting students with disabilities
## Key Features
* Personalized AI-driven learning assistants tailored to individual student needs
* Real-time text-to-speech functionality for visually impaired students
* Closed captions and transcription services for hearing impaired students
* Customizable font sizes, colors, and layouts for improved readability
* Integrated mind mapping and organization tools for students with cognitive disabilities
* Seamless integration with popular Learning Management Systems (LMS)
## Tech Stack
* Frontend:
  + React for building interactive and responsive UI components
  + TypeScript for type safety and maintainability
* Backend:
  + Node.js with Express.js for server-side logic and API management
  + GraphQL for flexible and efficient data querying
* Database:
  + PostgreSQL for storing user data, preferences, and learning history
* Infra/DevOps:
  + Docker for containerization and deployment
  + Kubernetes for orchestration and scaling
* AI/ML:
  + TensorFlow.js for client-side machine learning and AI-driven features
  + Natural Language Processing (NLP) libraries for text analysis and understanding
## Architecture
The EduPal architecture is designed as a microservices-based system, with separate services for authentication, learning assistants, and LMS integration. This allows for greater flexibility, scalability, and maintainability, while ensuring a seamless and intuitive user experience.
## Roadmap

* v2:

  + Broader user testing and feedback collection
* v3:
