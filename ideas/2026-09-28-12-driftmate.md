# DriftMate

> A browser extension that helps remote workers track API logs while they browse.

## Problem
Remote workers struggle to benchmark their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Audit log of every change
- Email and push notifications
- Email/OAuth sign-in with role-based access control
- Real-time updates over WebSockets
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
