# AuroraAI

> provides a predictive maintenance and quality control platform for manufacturers and industrial operators to reduce downtime and increase productivity.

## Problem
Remote workers struggle to translate their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Audit log of every change
- Usage analytics and an admin panel
- One-click export to CSV and PDF
- Email/OAuth sign-in with role-based access control
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
