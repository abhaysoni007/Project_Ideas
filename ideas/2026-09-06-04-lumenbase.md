# LumenBase

> A browser extension that shows the carbon footprint of each website you visit.

## Problem
Developers struggle to benchmark their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Audit log of every change
- Email/OAuth sign-in with role-based access control
- Offline-first with background sync
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React client talks to a Node.js + Express API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
