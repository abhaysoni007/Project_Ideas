# NovaStack

> A mobile app that gamifies customer feedback to keep researchers engaged.

## Problem
Designers struggle to organize their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Email/OAuth sign-in with role-based access control
- Team workspaces with granular permissions
- Usage analytics and an admin panel
- Real-time updates over WebSockets
- Email and push notifications

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React client talks to a Node.js + Express API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
