# MindPal

> provides a mental health and wellness platform for individuals and employers to support employee well-being and stress management through AI-driven chatbots and resources.

## Problem
Remote workers struggle to organize their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Real-time updates over WebSockets
- AI-assisted recommendations and summaries
- Usage analytics and an admin panel
- Public REST API with scoped API keys
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
