# NovaScope

> A extension that summarizes long GitHub issues and their comment threads.

## Problem
Creators struggle to track their travel itineraries without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- Audit log of every change
- Responsive dashboard with light and dark mode
- Real-time updates over WebSockets
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Node.js + Express
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Node.js + Express API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
