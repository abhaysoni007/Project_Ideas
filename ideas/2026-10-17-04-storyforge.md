# StoryForge
> Build worlds, not code.

## Problem
Indie game developers often juggle coding, art, and storytelling, leaving narrative depth under‑developed. Existing tools either lack AI support for rapid ideation or fail to support real‑time collaboration, slowing production cycles.

## Target Users
- Indie game studios looking to accelerate narrative design  
- Solo developers or small teams needing a shared story workspace  
- Narrative designers who want AI‑powered content suggestions  
- Project managers seeking traceable story assets linked to code

## Key Features
- AI‑assisted story generation and dialogue drafting  
- Real‑time collaborative editor with version control history  
- Interactive world‑map builder linking locations, factions, and lore  
- Automatic script formatting for popular game engines (Unity, Godot)  
- Asset‑linking panel to attach art, music, and sound effects  
- Export options to JSON, XML, or engine‑specific formats  
- Integrated task board and milestone tracking

## Tech Stack
- **Frontend**  
  - React 18 + TypeScript  
  - Next.js for SSR and routing  
  - Slate.js for rich text editing  
  - Tailwind CSS for responsive UI  
- **Backend**  
  - NestJS (Node.js) as API gateway & service orchestrator  
  - WebSocket (Socket.IO) for real‑time collaboration  
- **Database**  
  - PostgreSQL for relational data (stories, users, assets)  
  - Redis for caching and pub/sub messaging  
- **Infra/DevOps**  
  - Docker & Docker Compose for local development  
  - Kubernetes on AWS EKS with Helm charts  
  - Terraform for infrastructure as code  
  - GitHub Actions CI/CD pipelines  
  - CloudWatch & Grafana for monitoring  
- **AI/ML**  
  - OpenAI GPT‑4 API for story prompts and dialogue generation  
  - HuggingFace Transformers for fine‑tuned narrative models  
  - LangChain for chaining AI services and context retrieval  

## Architecture
StoryForge follows a microservices architecture: the NestJS API gateway routes HTTP and WebSocket requests to dedicated services (Story Service, Asset Service, Collaboration Service). A separate AI Service consumes prompts via a message queue (Kafka) and returns text embeddings or completions. PostgreSQL stores core data, while Redis handles real‑time edits and caching. The system is containerized and deployed on Kubernetes, with CI/CD pipelines ensuring automated testing and blue‑green releases.

## Roadmap
- **v1** – Core story editor, AI drafting, version control, and export to Unity  
- **v2** – World‑map builder, asset linking, task board, and integration with Godot  
- **v3** – Full real‑time collaboration, fine‑tuned custom narrative models, and marketplace for reusable story modules
