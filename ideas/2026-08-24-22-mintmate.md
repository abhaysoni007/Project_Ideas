# MintMate

> A browser extension that helps teachers cluster expenses while they browse.

## Problem
Open-source maintainers struggle to track their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Public REST API with scoped API keys
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Real-time updates over WebSockets
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** React
- **Backend:** Django
- **Database:** MongoDB
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React client talks to a Django API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
