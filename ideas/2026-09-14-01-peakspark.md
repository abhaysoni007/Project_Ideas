# PeakSpark

> A dashboard that grades your resume against a job description and lists gaps.

## Problem
Remote workers struggle to predict their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- Integrations with Slack, Google, and Stripe
- Team workspaces with granular permissions
- Audit log of every change
- AI-assisted recommendations and summaries
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
