# LingoLink

> facilitates language exchange and practice between native speakers and language learners worldwide.

## Problem
Parents struggle to translate their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- AI-assisted recommendations and summaries
- Usage analytics and an admin panel
- Email and push notifications
- Team workspaces with granular permissions
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
