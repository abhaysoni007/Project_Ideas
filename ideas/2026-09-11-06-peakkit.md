# PeakKit

> A VS Code extension that helps developers summarize screen time inside the editor.

## Problem
Founders struggle to cluster their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Integrations with Slack, Google, and Stripe
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- Full-text search with smart filters
- Email and push notifications

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
