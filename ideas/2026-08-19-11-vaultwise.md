# VaultWise

> A Pomodoro timer that mutes Slack and sets your calendar to busy automatically.

## Problem
Startups struggle to automate their travel itineraries without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Offline-first with background sync
- Responsive dashboard with light and dark mode
- Full-text search with smart filters
- Integrations with Slack, Google, and Stripe
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** React
- **Backend:** FastAPI (Python)
- **Database:** MySQL
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React client talks to a FastAPI (Python) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
