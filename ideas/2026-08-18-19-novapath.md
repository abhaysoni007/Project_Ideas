# NovaPath

> A Slack/Discord bot that helps startups personalize meeting notes without leaving chat.

## Problem
Designers struggle to optimize their invoices without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- Responsive dashboard with light and dark mode
- One-click export to CSV and PDF
- Email and push notifications
- Offline-first with background sync
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** React
- **Backend:** Django
- **Database:** MongoDB
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React client talks to a Django API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
