# Nexa

> creates a decentralized data storage and sharing platform for secure and private file management, collaboration, and content distribution with blockchain-based encryption and access control.

## Problem
Researchers struggle to detect their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Researchers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Email and push notifications
- Full-text search with smart filters
- Real-time updates over WebSockets
- AI-assisted recommendations and summaries
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
