# SyncBoost

> A tool that watches competitor pricing pages and alerts you when prices change.

## Problem
Parents struggle to predict their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- AI-assisted recommendations and summaries
- Public REST API with scoped API keys
- Usage analytics and an admin panel
- Real-time updates over WebSockets
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
