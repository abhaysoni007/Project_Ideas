# VaultWorks

> An app that suggests recipes based on what's about to expire in your fridge.

## Problem
Creators struggle to schedule their invoices without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Audit log of every change
- Email and push notifications
- Team workspaces with granular permissions
- Guided onboarding with ready-made templates
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
