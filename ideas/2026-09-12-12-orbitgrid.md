# OrbitGrid

> A Slack/Discord bot that helps open-source maintainers audit podcast highlights without leaving chat.

## Problem
Designers struggle to visualize their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Audit log of every change
- Email/OAuth sign-in with role-based access control
- Responsive dashboard with light and dark mode
- Usage analytics and an admin panel
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
