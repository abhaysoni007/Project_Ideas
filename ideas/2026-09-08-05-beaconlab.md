# BeaconLab

> A habit tracker that pairs you with an accountability buddy who has the same goal.

## Problem
Designers struggle to recommend their travel itineraries without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Public REST API with scoped API keys
- Audit log of every change
- Email and push notifications
- Guided onboarding with ready-made templates
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
