# BeaconGrid

> A CLI tool that automates customer feedback in robotics workflows.

## Problem
Teachers struggle to visualize their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Usage analytics and an admin panel
- Offline-first with background sync
- Guided onboarding with ready-made templates
- Full-text search with smart filters
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
