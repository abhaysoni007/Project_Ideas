# PulseDesk

> A browser extension that helps creators schedule invoices while they browse.

## Problem
Creators struggle to personalize their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Email/OAuth sign-in with role-based access control
- Responsive dashboard with light and dark mode
- Usage analytics and an admin panel
- Real-time updates over WebSockets
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** FastAPI (Python)
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a FastAPI (Python) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
