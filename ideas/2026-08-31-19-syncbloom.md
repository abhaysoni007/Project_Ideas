# SyncBloom

> A budgeting app for freelancers that sets aside tax money on every invoice paid.

## Problem
Teachers struggle to predict their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Integrations with Slack, Google, and Stripe
- Public REST API with scoped API keys
- Team workspaces with granular permissions
- Usage analytics and an admin panel
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
