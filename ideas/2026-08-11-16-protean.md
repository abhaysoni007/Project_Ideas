# Protean

> creates customizable, 3D-printed prosthetic limbs and assistive devices for people with disabilities.

## Problem
Teachers struggle to optimize their expenses without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Responsive dashboard with light and dark mode
- Email and push notifications
- Guided onboarding with ready-made templates
- Team workspaces with granular permissions
- Offline-first with background sync

## Tech Stack
- **Frontend:** React Native
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
