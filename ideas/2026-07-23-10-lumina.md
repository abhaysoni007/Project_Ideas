# Lumina
> Empowering low-vision individuals to navigate with confidence
## Problem
Low-vision individuals face significant challenges navigating their surroundings, often relying on others for assistance. This can lead to feelings of dependence and isolation, highlighting the need for an innovative solution. Existing tools and technologies often fall short in providing effective and efficient navigation assistance.
## Target Users
* Low-vision individuals with varying degrees of visual impairment
* Caregivers and family members seeking to support loved ones
* Organizations providing assistive technology for the visually impaired
## Key Features
* AI-powered object detection using camera feed analysis
* Real-time navigation assistance with audio and haptic feedback
* Customizable settings for personalized assistance
* Integration with popular accessibility services and tools
* User-friendly interface with simple gesture-based controls
* Regular software updates with new feature additions and improvements
## Tech Stack
* Frontend:
  + React Native for cross-platform mobile app development
  + Expo for streamlined project setup and management
* Backend:
  + Node.js with Express.js for server-side logic and API management
  + GraphQL for efficient data querying and mutation
* Database:
  + MongoDB for storing user data and navigation history
* Infra/DevOps:
  + AWS for cloud infrastructure and scalability
  + Docker for containerization and deployment
* AI/ML:
  + TensorFlow for object detection and machine learning model development
  + Google Cloud Vision API for image analysis and processing
## Architecture
The Lumina app will utilize a microservices architecture, with separate services for object detection, navigation assistance, and user data management. The React Native frontend will interact with the Node.js backend via GraphQL APIs, while the TensorFlow-powered object detection model will be integrated with the Google Cloud Vision API for enhanced image analysis.
## Roadmap
* v1:
  + Initial app release with basic object detection and navigation features
  + Limited user testing and feedback collection
* v2:
  + Enhanced object detection with improved accuracy and speed
  + Introduction of customizable settings and personalized assistance
* v3:
  + Integration with popular wearables and smart home devices for expanded accessibility
  + Advanced navigation features, including route planning and obstacle avoidance
