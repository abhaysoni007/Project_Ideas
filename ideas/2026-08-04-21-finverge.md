# Finverge

> Helps small businesses and entrepreneurs manage their finances by providing AI-driven accounting, invoicing, and expense tracking

## Problem
Teachers struggle to visualize their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Guided onboarding with ready-made templates
- Team workspaces with granular permissions
- AI-assisted recommendations and summaries
- Responsive dashboard with light and dark mode
- Email and push notifications

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Node.js + Express API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
