# ByteWorks

> A CLI that turns terminal session recordings into shareable animated SVGs.

## Problem
Designers struggle to personalize their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Usage analytics and an admin panel
- Guided onboarding with ready-made templates
- Real-time updates over WebSockets
- Public REST API with scoped API keys
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
