# BoltWorks

> An app that converts long YouTube tutorials into step-by-step markdown notes.

## Problem
Remote workers struggle to schedule their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- Audit log of every change
- Email/OAuth sign-in with role-based access control
- Email and push notifications

## Tech Stack
- **Frontend:** React
- **Backend:** Django
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a Django API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
