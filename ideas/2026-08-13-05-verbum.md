# Verbum
> Practice languages with natives, perfected by feedback
## Problem
Language learners often struggle to improve their conversational skills due to lack of practice with native speakers. Existing language learning platforms focus on grammar and vocabulary, neglecting pronunciation and real-life conversations. This hinders learners' ability to communicate effectively in real-world situations.
## Target Users
* Non-native English speakers
* Language exchange enthusiasts
* Students preparing for language proficiency exams
* Travelers and expats
* Business professionals seeking to improve language skills
## Key Features
* Matchmaking with native speakers for conversation practice
* Real-time pronunciation feedback using audio analysis
* Grammar correction and suggestions for improvement
* Topic-based conversations for focused practice
* User profiles and progress tracking
* In-app messaging for scheduling conversations
## Tech Stack
* Frontend:
  + React for building the user interface
  + Redux for state management
* Backend:
  + Node.js with Express.js for handling API requests
  + Passport.js for user authentication
* Database:
  + MongoDB for storing user data and conversation history
* Infra/DevOps:
  + Docker for containerization
  + Kubernetes for orchestration
* AI/ML:
  + Google Cloud Speech-to-Text for audio analysis
  + TensorFlow for building custom pronunciation models
## Architecture
The Verbum platform will consist of a frontend web application, a backend API server, and a database. The frontend will handle user interactions, while the backend will manage API requests, user authentication, and database interactions. The database will store user profiles, conversation history, and feedback data. The AI/ML components will be integrated with the backend to provide real-time feedback and analysis.
## Roadmap
* v1:
  + Basic matchmaking and conversation features
  + Limited pronunciation feedback using pre-built models
* v2:
  + Advanced pronunciation analysis using custom TensorFlow models
  + Grammar correction and suggestions for improvement
  + User profile and progress tracking features
* v3:
  + Integration with popular language learning platforms
  + Expanded topic-based conversations and community features
  + Enhanced user interface and user experience improvements
