# HealthHive

> builds a social support network and community platform for people living with chronic illnesses, providing resources, connections, and encouragement to manage their condition.

## Problem
Founders struggle to personalize their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Guided onboarding with ready-made templates
- Team workspaces with granular permissions
- Usage analytics and an admin panel
- Responsive dashboard with light and dark mode
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
