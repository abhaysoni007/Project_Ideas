# LumenDeck

> A dashboard that grades your resume against a job description and lists gaps.

## Problem
Developers struggle to personalize their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Offline-first with background sync
- Team workspaces with granular permissions
- Full-text search with smart filters
- Public REST API with scoped API keys
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
