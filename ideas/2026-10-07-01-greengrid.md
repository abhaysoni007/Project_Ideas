# GreenGrid

> Connecting smallholder farmers with retailers through transparent, blockchain‑backed traceability

## Problem  
Smallholder farmers often lack direct access to reliable markets, resulting in opaque pricing and limited bargaining power. Retailers struggle to verify product provenance and sustainability claims, hindering responsible sourcing. The absence of a unified, trustable platform perpetuates inefficiencies and environmental risks across the food supply chain.

## Target Users  
- Smallholder farmers in emerging economies  
- Independent retailers and grocery chains  
- Food‑safety regulators and certification bodies  
- Supply‑chain auditors and NGOs  
- End consumers interested in verified sustainable products  

## Key Features  
- **Blockchain‑verified product registry** for immutable provenance records  
- **Smart contract‑driven escrow** to secure payments until delivery confirmation  
- **Real‑time price transparency dashboard** showing market rates and margin breakdowns  
- **AI‑powered demand forecasting** to match supply with retailer needs  
- **Mobile‑first farmer app** for inventory, order updates, and educational resources  
- **Retailer procurement portal** with customizable sourcing criteria and alerts  
- **Audit trail export** for regulatory compliance and third‑party verification  

## Tech Stack  

- **Frontend**  
  - React + TypeScript with Next.js for SSR and routing  
  - Tailwind CSS for rapid UI styling  
  - Redux Toolkit for state management  

- **Backend**  
  - Node.js (v18) + Express + TypeScript  
  - NestJS microservices architecture for scalability  

- **Blockchain**  
  - Hyperledger Fabric v2.5 for permissioned ledger  
  - Chaincode written in Go, deployed via Docker containers  

- **Database**  
  - PostgreSQL 15 for relational data (users, orders, metadata)  
  - Redis 7 for caching and pub/sub event streams  

- **Infra/DevOps**  
  - Docker Compose for local dev, Kubernetes (EKS) for production  
  - Terraform for IaC, GitHub Actions for CI/CD pipelines  
  - Prometheus + Grafana for monitoring, Loki for logging  

- **AI/ML**  
  - Python (pandas, scikit‑learn) for demand‑forecasting models  
  - Dockerized model serving with FastAPI, integrated via gRPC  

## Architecture  
GreenGrid follows a layered microservice architecture. The **frontend** interacts with a **NestJS API gateway** that orchestrates requests to dedicated services: **Farm Management**, **Retail Procurement**, **Marketplace**, and **Blockchain Orchestrator**. The **Blockchain Orchestrator** submits product and transaction data to the Hyperledger Fabric network, ensuring immutability and auditability. A **PostgreSQL** cluster holds relational data while **Redis** manages transient state and event queues. AI models run in isolated containers and expose prediction endpoints to the Marketplace service. All services are containerized, deployed to Kubernetes, and managed via Terraform, with continuous delivery pipelines on GitHub Actions.
