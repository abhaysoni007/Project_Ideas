# BoltPilot

> A CLI tool that automates code reviews in agriculture workflows.

## Problem
Designers struggle to audit their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Public REST API with scoped API keys
- Team workspaces with granular permissions
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** SQLite
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a NestJS API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
