# Vaultly

> A CLI tool that automates recipes in travel workflows.

## Problem
Developers struggle to detect their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Public REST API with scoped API keys
- Offline-first with background sync
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Email and push notifications

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** MongoDB
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
