# VaultSpark

> A Pomodoro timer that mutes Slack and sets your calendar to busy automatically.

## Problem
Open-source maintainers struggle to automate their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- AI-assisted recommendations and summaries
- Responsive dashboard with light and dark mode
- Guided onboarding with ready-made templates
- Usage analytics and an admin panel
- Audit log of every change

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Node.js + Express
- **Database:** MySQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Node.js + Express API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
