# ByteBloom

> A dashboard that turns raw recipes into actionable security insights.

## Problem
Founders struggle to benchmark their invoices without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Usage analytics and an admin panel
- Guided onboarding with ready-made templates
- Public REST API with scoped API keys
- AI-assisted recommendations and summaries
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** React
- **Backend:** FastAPI (Python)
- **Database:** MySQL
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React client talks to a FastAPI (Python) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
