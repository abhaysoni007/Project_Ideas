# ForgeStack

> An AI-free rule-based linter for accessibility issues in HTML emails.

## Problem
Open-source maintainers struggle to detect their workout plans without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Audit log of every change
- Full-text search with smart filters
- Real-time updates over WebSockets
- Guided onboarding with ready-made templates
- Email and push notifications

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
