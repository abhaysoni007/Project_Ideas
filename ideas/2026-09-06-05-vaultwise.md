# VaultWise

> An AI-free rule-based linter for accessibility issues in HTML emails.

## Problem
Founders struggle to schedule their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Full-text search with smart filters
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- Usage analytics and an admin panel
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Django
- **Database:** MongoDB
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Django API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
