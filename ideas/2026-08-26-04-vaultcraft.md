# VaultCraft

> A self-hosted tool that lets job seekers organize podcast highlights with full data privacy.

## Problem
Designers struggle to organize their workout plans without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Guided onboarding with ready-made templates
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Audit log of every change
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** React Native
- **Backend:** Node.js + Express
- **Database:** MySQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Node.js + Express API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
