# FlowLab

> A tool that watches competitor pricing pages and alerts you when prices change.

## Problem
Freelancers struggle to track their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Freelancers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- Full-text search with smart filters
- Offline-first with background sync
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
