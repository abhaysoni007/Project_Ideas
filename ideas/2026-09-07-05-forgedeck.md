# ForgeDeck

> A Slack/Discord bot that helps freelancers optimize meeting notes without leaving chat.

## Problem
Gamers struggle to schedule their sensor data without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Public REST API with scoped API keys
- AI-assisted recommendations and summaries
- Responsive dashboard with light and dark mode
- Audit log of every change
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React client talks to a Node.js + Express API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
