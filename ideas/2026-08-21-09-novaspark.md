# NovaSpark

> A tool that scans your GitHub repos and auto-generates a portfolio site from your top projects.

## Problem
Startups struggle to predict their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Usage analytics and an admin panel
- Public REST API with scoped API keys
- Email/OAuth sign-in with role-based access control
- Offline-first with background sync
- Email and push notifications

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** MongoDB
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
