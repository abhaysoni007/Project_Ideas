# PulseGrid

> A dashboard that turns raw sensor data into actionable developer tools insights.

## Problem
Teachers struggle to personalize their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Real-time updates over WebSockets
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- Full-text search with smart filters
- Audit log of every change

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
