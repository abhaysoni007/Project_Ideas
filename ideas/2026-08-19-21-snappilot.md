# SnapPilot

> A creator economy app that uses AI to schedule screen time for students.

## Problem
Creators struggle to translate their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- Public REST API with scoped API keys
- Audit log of every change
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
