# GreenSlate

> develops a sustainable supply chain management platform for businesses to track and reduce their environmental impact.

## Problem
Remote workers struggle to personalize their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Integrations with Slack, Google, and Stripe
- Full-text search with smart filters
- Offline-first with background sync
- One-click export to CSV and PDF
- Email and push notifications

## Tech Stack
- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
