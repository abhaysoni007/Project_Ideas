# NovaBloom
> Unlock the power of your meetings to fuel your wellness journey
## Problem
Meeting notes often contain valuable health and fitness insights, but manually extracting and analyzing this information can be time-consuming and tedious. This leads to a lack of actionable insights, making it difficult for individuals to make data-driven decisions about their well-being. As a result, opportunities for improvement are missed.
## Target Users
* Health and fitness enthusiasts
* Business professionals with busy schedules
* Individuals with chronic health conditions
* Wellness coaches and personal trainers
* Corporate wellness program administrators
## Key Features
* Automated note-taking and transcription
* Natural Language Processing (NLP) for insight extraction
* Personalized health and fitness recommendations
* Integration with popular wearable devices and health apps
* Customizable dashboards for tracking progress
* Alerts and reminders for upcoming health-related events
## Tech Stack
* Frontend:
  + React for building the user interface
  + Material-UI for styling and layout
* Backend:
  + Node.js with Express.js for handling API requests
  + Python for NLP tasks
* Database:
  + MongoDB for storing user data and meeting notes
* Infra/DevOps:
  + AWS for hosting and scalability
  + Docker for containerization
* AI/ML:
  + spaCy for NLP tasks
  + scikit-learn for machine learning models
## Architecture
The NovaBloom architecture consists of a React frontend, a Node.js and Python backend, and a MongoDB database. The frontend sends API requests to the backend, which processes the requests, performs NLP tasks, and stores data in the database. The backend also integrates with wearable devices and health apps via APIs. The system is hosted on AWS and uses Docker for containerization.
