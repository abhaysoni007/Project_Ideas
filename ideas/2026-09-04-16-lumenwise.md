# LumenWise

> An AI-free rule-based linter for accessibility issues in HTML emails.

## Problem
Freelancers struggle to optimize their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Freelancers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Email/OAuth sign-in with role-based access control
- One-click export to CSV and PDF
- Full-text search with smart filters
- Audit log of every change
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React Native
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
