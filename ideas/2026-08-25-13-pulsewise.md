# PulseWise

> A self-hosted tool that lets students detect workout plans with full data privacy.

## Problem
Startups struggle to personalize their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- Guided onboarding with ready-made templates
- Audit log of every change
- Public REST API with scoped API keys
- Responsive dashboard with light and dark mode
- Full-text search with smart filters

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
