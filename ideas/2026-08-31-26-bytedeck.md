# ByteDeck

> A Slack/Discord bot that helps remote workers translate reading lists without leaving chat.

## Problem
Gamers struggle to cluster their expenses without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- Email/OAuth sign-in with role-based access control
- Integrations with Slack, Google, and Stripe
- Team workspaces with granular permissions
- Offline-first with background sync
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** FastAPI (Python)
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a FastAPI (Python) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
