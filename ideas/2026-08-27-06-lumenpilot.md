# LumenPilot

> An API service that lets developers add news feeds to any legal tech product.

## Problem
Students struggle to track their workout plans without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Integrations with Slack, Google, and Stripe
- Real-time updates over WebSockets
- One-click export to CSV and PDF
- Guided onboarding with ready-made templates
- Offline-first with background sync

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
