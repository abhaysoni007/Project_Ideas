# MintBoost

> A tool that watches competitor pricing pages and alerts you when prices change.

## Problem
Gamers struggle to recommend their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Offline-first with background sync
- Email and push notifications
- Email/OAuth sign-in with role-based access control
- Audit log of every change
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** React
- **Backend:** FastAPI (Python)
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a FastAPI (Python) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
