# EchoBoost

> A study app that turns your highlighted PDFs into spaced-repetition flashcards.

## Problem
Developers struggle to organize their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- One-click export to CSV and PDF
- Full-text search with smart filters
- AI-assisted recommendations and summaries
- Offline-first with background sync

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
