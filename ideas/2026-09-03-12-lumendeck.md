# LumenDeck

> An API service that lets developers add cloud costs to any climate tech product.

## Problem
Designers struggle to benchmark their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- Responsive dashboard with light and dark mode
- Integrations with Slack, Google, and Stripe
- Offline-first with background sync
- One-click export to CSV and PDF
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React Native
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
