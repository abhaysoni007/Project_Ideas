# HabitGuard
> Turn daily health habits into a win‑for‑all corporate game

## Problem
Employees often lack personalized motivation and real‑time feedback to sustain healthy habits, leading to high health costs and low engagement in wellness programs. Wearables provide data, but corporate teams lack a unified platform that turns that data into actionable, gamified journeys.

## Target Users
- Corporate wellness program managers
- HR teams overseeing employee health initiatives
- Health & safety officers
- Individual employees seeking structured habit change

## Key Features
- **Wearable Sync** – Pull step count, sleep, heart‑rate, and activity data from Apple Watch, Fitbit, Garmin, and Android Wear in real time.  
- **Personalized Habit Plans** – AI‑driven recommendation engine tailors daily challenges to each employee’s baseline and goals.  
- **Gamified Progress** – Badges, leaderboards, streaks, and team challenges with points redeemable for corporate rewards.  
- **Real‑time Coaching** – Push notifications and micro‑nudges triggered by biometric thresholds or inactivity.  
- **Analytics Dashboard** – Visualize cohort health metrics, program ROI, and individual engagement in a single view.  
- **Privacy‑First Data Handling** – GDPR/CCPA compliant data storage, role‑based access, and employee consent controls.  
- **Integrations** – REST API for ERP, Slack, Microsoft Teams, and existing HRIS systems.

## Tech Stack
**Frontend**  
- React (TypeScript)  
- Next.js for SSR and API routes  
- Tailwind CSS for rapid UI styling  
- Redux Toolkit for state management  

**Backend**  
- Node.js (TypeScript)  
- Express.js framework  
- NestJS modules for modular architecture  

**Database**  
- PostgreSQL (primary relational data)  
- TimescaleDB extension (time‑series wearable data)  

**Infra/DevOps**  
- Docker containers orchestrated by Kubernetes (Amazon EKS)  
- CI/CD with GitHub Actions → ECR → EKS  
- AWS services: RDS for Postgres, S3 for asset storage, CloudFront for CDN, SNS/SQS for messaging  
- Terraform for IaC  

**AI/ML**  
- Python 3.11 (scikit‑learn, pandas) for habit‑prediction models  
- TensorFlow Lite for on‑device inference (optional)  
- AWS SageMaker for model training, versioning, and deployment  

## Architecture
HabitGuard follows a microservices‑oriented, server‑less friendly architecture. The React/Next.js front‑end consumes a GraphQL gateway that aggregates data from a NestJS service layer. The service layer handles wearable data ingestion via scheduled AWS Lambda functions, stores time‑series in TimescaleDB, and feeds a Python ML service hosted on SageMaker for personalized habit recommendations. All services communicate over HTTPS with mutual TLS, and stateful sessions are maintained via JWT tokens stored in secure HTTP‑only cookies.

## Roadmap
- **v1** – Core wearable integration, baseline habit tracking, basic leaderboard, secure data pipeline.  
- **v2** – Advanced gamification mechanics (team quests, reward catalog), Slack/Teams notifications, analytics dashboard.  
- **v3** – AI‑driven predictive coaching, predictive churn mitigation, custom corporate analytics API, multi‑tenant support.
