# Nestly

> A mobile app that gamifies API logs to keep students engaged.

## Problem
Teachers struggle to automate their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Full-text search with smart filters
- Integrations with Slack, Google, and Stripe
- Real-time updates over WebSockets
- Audit log of every change
- Offline-first with background sync

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Node.js + Express
- **Database:** MySQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Node.js + Express API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
