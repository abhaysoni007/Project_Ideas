# Nexa

> helps businesses optimize their supply chain management with its AI-driven demand forecasting and inventory management tool

## Problem
Developers struggle to cluster their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Real-time updates over WebSockets
- Guided onboarding with ready-made templates
- Email and push notifications
- One-click export to CSV and PDF
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Django
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Django API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
