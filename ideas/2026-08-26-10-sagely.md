# Sagely

> A habit tracker that pairs you with an accountability buddy who has the same goal.

## Problem
Remote workers struggle to track their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Email/OAuth sign-in with role-based access control
- Public REST API with scoped API keys
- Integrations with Slack, Google, and Stripe
- Audit log of every change
- Email and push notifications

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** Supabase
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
