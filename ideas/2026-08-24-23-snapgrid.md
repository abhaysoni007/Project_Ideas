# SnapGrid

> A tool that watches competitor pricing pages and alerts you when prices change.

## Problem
Startups struggle to summarize their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- Email and push notifications
- Usage analytics and an admin panel
- One-click export to CSV and PDF
- Team workspaces with granular permissions
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Go (Gin)
- **Database:** Supabase
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Go (Gin) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
