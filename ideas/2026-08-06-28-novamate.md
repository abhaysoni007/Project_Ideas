# NovaMate

> An AI-free rule-based linter for accessibility issues in HTML emails.

## Problem
Designers struggle to optimize their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Offline-first with background sync
- Guided onboarding with ready-made templates
- Email/OAuth sign-in with role-based access control
- AI-assisted recommendations and summaries
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Go (Gin)
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Go (Gin) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
