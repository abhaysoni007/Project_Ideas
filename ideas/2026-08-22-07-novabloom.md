# NovaBloom

> A tool that audits a website's Core Web Vitals and suggests concrete fixes.

## Problem
Startups struggle to summarize their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Real-time updates over WebSockets
- Email and push notifications
- Audit log of every change
- One-click export to CSV and PDF
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
