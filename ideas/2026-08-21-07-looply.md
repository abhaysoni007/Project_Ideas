# Looply

> An AI-free rule-based linter for accessibility issues in HTML emails.

## Problem
Gamers struggle to summarize their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Team workspaces with granular permissions
- Email/OAuth sign-in with role-based access control
- Full-text search with smart filters
- Email and push notifications
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** MySQL
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
