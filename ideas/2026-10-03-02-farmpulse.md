# FarmPulse
> Harvest smarter, not harder.

## Problem
Small‑scale farmers often lack real‑time, actionable data to manage irrigation, fertilization, and pest control. Relying on guesswork leads to water waste, over‑fertilization, and crop losses, driving up costs and reducing yields.

## Target Users
- Farmers with 1–50 ha of arable land
- Community‑based cooperative groups
- Agricultural extension officers and advisors
- Rural cooperatives and NGOs focused on food security

## Key Features
- **Real‑time sensor network**: Low‑power soil moisture, temperature, and humidity nodes with LoRaWAN connectivity
- **Weather integration**: Pull local forecasts and rainfall alerts from public APIs (e.g., OpenWeatherMap)
- **Predictive irrigation scheduling**: ML models estimate optimal watering times and volumes
- **Fertilizer recommendation engine**: Nutrient‑need mapping based on soil test data and crop type
- **Pest & disease alerts**: Visual recognition of crop symptoms via mobile camera uploads
- **Dashboard & mobile app**: Cross‑platform UI (React Native) for field monitoring and alerts
- **Offline sync**: Local storage and batch upload when connectivity resumes

## Tech Stack
- **Frontend**  
  - React Native (iOS & Android)  
  - Redux Toolkit for state management  
  - TypeScript, ESLint, Prettier
- **Backend**  
  - Node.js 20 (Express.js)

- **Infra/DevOps**

  - Helm charts for deployment  
  - CI/CD with GitHub Actions, Docker, and ArgoCD  
  - Terraform for IaC
- **AI/ML**  
  - Python 3.11 (FastAPI microservices)  
  - PyTorch for predictive models  
  - AWS SageMaker for model training & hosting  
  - OpenCV for image‑based pest detection

## Architecture
FarmPulse follows a modular micro‑service architecture. Edge LoRaWAN gateways forward sensor packets to a cloud ingestion API, which normalizes and stores data in PostgreSQL. The backend GraphQL layer serves the mobile dashboard and orchestrates ML inference services. AI models run as stateless containers on Kubernetes, leveraging GPU nodes for image analysis. Redis caches recent sensor values for low‑latency dashboard updates, while Terraform provisions all infrastructure on DigitalOcean, ensuring rapid scaling and disaster recovery.

## Roadmap
- **v1**: Deploy LoRaWAN gateway, sensor firmware, ingestion API, basic dashboard, and rule‑based irrigation alerts.  
- **v2**: Integrate weather APIs, launch fertilizer recommendation engine, add offline sync, and release iOS/Android beta.  
- **v3**: Deploy full ML pipeline (nutrient, pest, yield prediction), introduce cooperative data sharing, and enable API for third‑party agritech partners.
