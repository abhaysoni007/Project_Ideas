# FolkFusion

> brings together traditional artisans and contemporary designers to create unique, culturally-inspired products and fashion collections

## Problem
Parents struggle to track their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Integrations with Slack, Google, and Stripe
- One-click export to CSV and PDF
- Real-time updates over WebSockets
- Offline-first with background sync
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
