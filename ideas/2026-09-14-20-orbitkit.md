# OrbitKit

> A weekly-digest service that visualizes news feeds and emails developers a summary.

## Problem
Parents struggle to summarize their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Email and push notifications
- Offline-first with background sync
- AI-assisted recommendations and summaries
- Public REST API with scoped API keys
- Audit log of every change

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
