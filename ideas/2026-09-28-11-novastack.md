# NovaStack

> An AI-free rule-based linter for accessibility issues in HTML emails.

## Problem
Remote workers struggle to organize their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Offline-first with background sync
- Integrations with Slack, Google, and Stripe
- Audit log of every change
- Guided onboarding with ready-made templates
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
