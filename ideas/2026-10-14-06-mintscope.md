# MintScope
> Turn fridge clutter into culinary inspiration

## Problem
Every month, households waste 15% of groceries due to lack of awareness about expiration dates. Users struggle to plan meals around items that are close to expiring, leading to food waste and extra cost.

## Target Users
- Home cooks looking to reduce food waste  
- Busy families needing quick meal ideas  
- Eco‑conscious consumers tracking sustainability  
- Kitchen managers in small restaurants  

## Key Features
- Automatic inventory detection via barcode scanner or manual entry  
- Real‑time expiration monitoring and alerts  
- AI‑generated recipes based on available ingredients  
- Shopping list integration with grocery delivery services  
- Meal planning calendar and weekly meal suggestions  
- Nutritional information and dietary filter options  
- Gamified waste reduction leaderboard  

## Tech Stack
- **Frontend**: React Native (iOS & Android), Expo, Tailwind CSS (via nativewind)  
- **Backend**: Node.js with Express, TypeScript  
- **Database**: PostgreSQL (primary), Redis for caching  
- **Infra/DevOps**: Docker, Kubernetes (EKS), Terraform, GitHub Actions CI/CD  
- **AI/ML**: OpenAI GPT‑4 for recipe generation, TensorFlow Lite for on‑device barcode OCR  

## Architecture
MintScope follows a micro‑service architecture with a REST/GraphQL API gateway exposing endpoints for inventory, recipes, and user management. The front‑end consumes the API via a secure JWT flow. Image processing for barcodes runs as a lightweight serverless function on AWS Lambda, while recipe generation is handled by a dedicated AI service communicating with the GPT‑4 model through OpenAI’s API. Data is stored in PostgreSQL, with Redis caching frequent queries to reduce latency.

## Roadmap
- **v1**: Core inventory & expiration tracker, manual item entry, basic recipe list, iOS & Android release  
- **v2**: Barcode scanning, AI recipe generation, grocery list export, web dashboard  
- **v3**: Smart home integration, voice assistant support, analytics dashboard, subscription premium tier
