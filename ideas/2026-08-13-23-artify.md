# Artify

> creates an AI-driven art generation platform for artists, designers, and creative professionals to explore new ideas and collaborate on projects.

## Problem
Developers struggle to personalize their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- Email and push notifications
- Public REST API with scoped API keys
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
