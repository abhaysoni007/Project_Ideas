# ByteWorks

> A weekly-digest service that visualizes API logs and emails teachers a summary.

## Problem
Teachers struggle to summarize their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Responsive dashboard with light and dark mode
- Offline-first with background sync
- AI-assisted recommendations and summaries
- Audit log of every change
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** React Native
- **Backend:** Go (Gin)
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Go (Gin) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
