# TasteBuddy
> Discover your perfect bite, every time
## Problem 
The current process of finding restaurants, cafes, and recipes that cater to specific dietary needs and preferences is tedious and often relies on trial and error, or word of mouth, leading to a lack of trust and inconsistent experiences. This results in a significant amount of time spent researching and a high likelihood of encountering unsatisfactory options. Furthermore, existing solutions often lack the depth and breadth of information needed to make informed decisions.

## Target Users
* Individuals with specific dietary restrictions (e.g., vegan, gluten-free, halal)
* Health-conscious consumers seeking nutritious options
* Foodies interested in exploring new cuisines and recipes
* People managing chronic conditions through diet (e.g., diabetes, celiac disease)
* Travelers looking for dining options that cater to their dietary needs while abroad

## Key Features
* Personalized recommendations based on user input (dietary needs, preferences, and ratings)
* Comprehensive database of restaurants, cafes, and recipes with detailed nutritional information and reviews
* User profiles for saving favorite locations and recipes, as well as tracking dietary progress
* Social sharing features to spread the word about great finds
* Integration with popular health and fitness tracking apps
* Advanced filtering and search functionality to quickly find suitable options

## Tech Stack
#### Frontend
* React for building the user interface
* Redux for state management
* Material-UI for styling and layout
#### Backend
* Node.js with Express as the web framework
* GraphQL API for efficient data querying
#### Database
* MongoDB for storing user data and reviews
* PostgreSQL for the core database of restaurants, cafes, and recipes
#### Infra/DevOps
* Docker for containerization
* Kubernetes for orchestration
* AWS for hosting and scalability
#### AI/ML
* TensorFlow for developing the recommendation engine

## Architecture
The TasteBuddy application will follow a microservices architecture, with separate services for the frontend, backend, database queries, and the AI-powered recommendation engine. This allows for scalability, easier maintenance, and the ability to update individual components without affecting the entire system. The GraphQL API will serve as the gateway for frontend-backend interactions, ensuring a unified and efficient data access layer.

## Roadmap
* v1: Basic functionality with user profiles, restaurant/recipe database, and simple filtering
* v2: Introduction of the AI-driven recommendation engine, social sharing features, and integration with health apps
* v3: Advanced features including personalized nutrition planning, augmented reality dining experiences, and expanded social features for community building and event planning
