# NestWise

> A habit tracker that pairs you with an accountability buddy who has the same goal.

## Problem
Creators struggle to recommend their expenses without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- AI-assisted recommendations and summaries
- Responsive dashboard with light and dark mode
- Integrations with Slack, Google, and Stripe
- Real-time updates over WebSockets
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Go (Gin)
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Go (Gin) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
