# DriftStack

> A dashboard that turns raw recipes into actionable e-commerce insights.

## Problem
Startups struggle to automate their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Email and push notifications
- Responsive dashboard with light and dark mode
- Email/OAuth sign-in with role-based access control
- Team workspaces with granular permissions
- Audit log of every change

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Node.js + Express API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
