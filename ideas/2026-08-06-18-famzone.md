# FamZone

> helps families and caregivers manage the healthcare and well-being of their loved ones through a comprehensive and integrated platform for remote care and support.

## Problem
Designers struggle to translate their sensor data without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Offline-first with background sync
- Public REST API with scoped API keys
- Guided onboarding with ready-made templates
- Full-text search with smart filters
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Node.js + Express
- **Database:** MySQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Node.js + Express API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
