# OrbitHub
> Sync your research insights from Chrome to mobile with instant API log optimization.

## Problem
Researchers often juggle multiple devices, leaving API logs fragmented across Chrome extensions, desktop apps, and mobile browsers. This fragmentation hampers rapid analysis, increases setup time, and introduces errors when switching contexts.

## Target Users
- Academic researchers working with RESTful APIs
- Data scientists analyzing request/response traffic
- Mobile app developers debugging server interactions
- QA engineers monitoring API performance across devices

## Key Features
- One-click Chrome extension to capture and encrypt API logs
- Real‑time sync to an iOS/Android companion app via WebSockets
- AI‑driven log summarization and anomaly detection
- Cross‑device search, filtering, and tagging of API calls
- Secure, role‑based access control with OAuth 2.0
- Export options (JSON, CSV, Markdown) for publication workflows
- Offline mode for mobile devices with auto‑reconnect

## Tech Stack
- **Frontend**
  - Chrome Extension: React + TypeScript + Redux
  - Mobile App: Flutter (Dart) for iOS & Android
- **Backend**
  - Node.js (NestJS) with GraphQL API
  - WebSocket gateway (Socket.io) for live sync
- **Database**
  - PostgreSQL for structured log storage
  - Redis for in‑memory caching of recent logs
- **Infra/DevOps**
  - Docker Compose for local dev, Docker Swarm/Kubernetes for production
  - CI/CD via GitHub Actions, automated tests and linting
  - AWS (ECS/EKS, RDS, S3) for hosting, with CloudWatch for monitoring
- **AI/ML**
  - Python microservice (FastAPI) with Hugging Face transformers for log summarization
  - MLflow for experiment tracking and model versioning

## Architecture
OrbitHub follows a micro‑service pattern with a thin API gateway exposing GraphQL endpoints to the frontend. API logs are captured by the Chrome extension, encrypted client‑side, and pushed to the backend via HTTPS. The backend stores logs in PostgreSQL and publishes updates through a Socket.io WebSocket to subscribed mobile clients. An AI microservice analyzes log streams asynchronously, annotating anomalies and generating natural‑language summaries that are cached in Redis for rapid retrieval.

## Roadmap
- **v1** – Core Chrome extension + mobile app, end‑to‑end sync, basic log storage, UI for viewing logs
- **v2** – AI summarization, anomaly detection, role‑based access control, offline sync
- **v3** – Advanced analytics dashboards, third‑party API integrations, multi‑tenant SaaS deployment, open‑source SDK for custom extensions
