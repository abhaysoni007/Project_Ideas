# EchoWise

> A tool that scans your GitHub repos and auto-generates a portfolio site from your top projects.

## Problem
Founders struggle to summarize their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- One-click export to CSV and PDF
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- Full-text search with smart filters
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Node.js + Express
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Node.js + Express API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
