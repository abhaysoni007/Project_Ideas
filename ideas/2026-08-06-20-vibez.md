# Vibez

> offers a social media and community engagement platform for influencers and content creators to connect with their audiences and build brand awareness.

## Problem
Creators struggle to organize their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Offline-first with background sync
- Integrations with Slack, Google, and Stripe
- Responsive dashboard with light and dark mode
- Real-time updates over WebSockets
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** MongoDB
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
