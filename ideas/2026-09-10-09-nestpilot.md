# NestPilot

> A service that turns your bank statements into a plain-English monthly spending story.

## Problem
Small teams struggle to benchmark their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Small teams
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Integrations with Slack, Google, and Stripe
- Email and push notifications
- Email/OAuth sign-in with role-based access control
- AI-assisted recommendations and summaries
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** React Native
- **Backend:** Node.js + Express
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Node.js + Express API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
