# Proxi
> Connecting you with the people around you
## Problem
The rise of social media has led to increased online interactions, but decreased face-to-face connections with those in our immediate vicinity. This has resulted in a sense of community isolation, despite being physically close to others. Proxi aims to bridge this gap by developing a social networking app that fosters local connections.
## Target Users
* Young adults (18-35) who value community and social interactions
* Individuals who have recently moved to a new city or neighborhood
* People looking to expand their social circle and connect with like-minded individuals
## Key Features
* User profiles with location-based discovery
* Event planning and group chat features for organizing meetups
* Nearby activity feed to stay updated on local happenings
* In-app messaging for easy communication
* Integration with popular calendar apps for scheduling
* User reviews and ratings for events and meetups
## Tech Stack
#### Frontend
* React Native for cross-platform mobile app development
* Expo for streamlined development and testing
#### Backend
* Node.js with Express.js for server-side logic
* GraphQL API for efficient data querying
#### Database
* MongoDB for storing user data and event information
* Redis for caching and improving performance
#### Infra/DevOps
* AWS for cloud infrastructure and scalability
* Docker for containerization and deployment
#### AI/ML
* Google Maps API for location-based services and geolocation
## Architecture
Proxi's architecture will consist of a React Native frontend, a Node.js backend with GraphQL API, and a MongoDB database. The app will utilize AWS for cloud infrastructure, Docker for containerization, and Redis for caching. This architecture will provide a scalable and efficient foundation for the app, allowing for seamless user interactions and a high-quality user experience.
## Roadmap
* v1: Initial release with core features, user profiles, and event planning
* v2: Introduction of in-app messaging, user reviews, and ratings
* v3: Integration with popular calendar apps, expanded event discovery features, and enhanced user experience with AI-powered location-based recommendations
