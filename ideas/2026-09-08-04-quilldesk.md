# QuillDesk

> A e-commerce app that uses AI to detect customer feedback for startups.

## Problem
Founders struggle to detect their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Offline-first with background sync
- Usage analytics and an admin panel
- Audit log of every change
- Guided onboarding with ready-made templates
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
