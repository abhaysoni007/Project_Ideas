# ByteStack

> A self-hosted tool that lets designers schedule travel itineraries with full data privacy.

## Problem
Open-source maintainers struggle to recommend their travel itineraries without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Real-time updates over WebSockets
- Responsive dashboard with light and dark mode
- Offline-first with background sync
- AI-assisted recommendations and summaries
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
