# EduBridge
> Empowering students to bridge the gap between academics and career success
## Problem 
The college and career planning process can be overwhelming for students, with many lacking access to personalized guidance and support. This can lead to poor career choices, decreased job satisfaction, and reduced overall well-being. Existing solutions often provide generic advice, failing to account for individual strengths, interests, and goals.
## Target Users
* High school students (grades 9-12)
* College students (freshmen and sophomores)
* Mentors and Career Advisors from various industries and institutions
## Key Features
* User profiling and matching algorithm to connect students with suitable mentors and Career Advisors
* Secure and private messaging system for students to seek guidance and feedback
* Personalized learning plans and career pathways recommendation
* Integrated event calendar for webinars, workshops, and career fairs
* Progress tracking and analytics for students, mentors, and administrators
* Community forum for discussing topics related to college and career planning
## Tech Stack
* Frontend:
  + ReactJS for building responsive and interactive user interfaces
  + Material-UI for consistent design and styling
* Backend:
  + Node.js with Express.js for building scalable and efficient server-side logic
  + Passport.js for secure authentication and authorization
* Database:
  + MongoDB for storing and managing large amounts of user data and metadata
* Infra/DevOps:
  + AWS for hosting and deploying the application
  + Docker for containerization and orchestration
* AI/ML:
  + TensorFlow.js for building and integrating the user profiling and matching algorithm
## Architecture
The EduBridge application will follow a microservices architecture, with separate services for user management, messaging, and career planning. The frontend will be built using ReactJS, communicating with the backend services via RESTful APIs. The backend services will be built using Node.js and Express.js, with MongoDB as the primary data storage solution. The application will be deployed on AWS, using Docker for containerization and orchestration.
## Roadmap
* v1:
  + Develop and launch the minimum viable product (MVP) with basic features and a small user base
* v2:
  + Integrate the user profiling and matching algorithm using TensorFlow.js
  + Add support for mobile devices and improve overall user experience
* v3:
  + Expand the community forum and add features for discussion and resource sharing
  + Develop and integrate a payment gateway for premium services and career advisor partnerships
