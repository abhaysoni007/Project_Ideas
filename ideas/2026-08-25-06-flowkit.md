# FlowKit

> A tool that audits a website's Core Web Vitals and suggests concrete fixes.

## Problem
Students struggle to detect their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Offline-first with background sync
- AI-assisted recommendations and summaries
- Team workspaces with granular permissions
- Audit log of every change
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
