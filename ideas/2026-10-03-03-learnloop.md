# LearnLoop
> Turn study sessions into winning teams

## Problem  
College students often struggle to find study partners who truly complement their learning styles, leading to ineffective group sessions and wasted time.  
Lifelong learners lack a social, gamified platform that provides instant feedback and collaborative tools tailored to peer-driven success.

## Target Users  
- Undergraduate and graduate students looking for efficient study partners  
- Lifelong learners seeking community-driven motivation  
- Academic advisors wanting to promote collaborative learning  
- Educators wanting to integrate peer feedback into coursework

## Key Features  
- **Smart Matching** – AI‑driven pairing based on strengths, weaknesses, and study habits  
- **Gamified Badges & Leaderboards** – Earn points for collaboration, timely feedback, and session attendance  
- **Real‑time Collaboration Tools** – Shared whiteboard, live chat, document co‑editing, and screen sharing  
- **Instant Feedback Engine** – AI‑powered auto‑grading and natural‑language explanations for submitted work  
- **Session Scheduling & Reminders** – Calendar integration and push notifications to keep groups on track  
- **Progress Analytics Dashboard** – Visualize personal and group performance over time  
- **Secure Peer‑to‑Peer Payment** – Optional micro‑transactions for tutoring or resource sharing

## Tech Stack  
- **Frontend**  
  - React Native (TypeScript)  
  - Redux Toolkit for state management  
  - React Navigation for routing  
- **Backend**  
  - Node.js + Express (TypeScript)  
  - GraphQL (Apollo Server) for flexible client queries  
- **Database**  
  - PostgreSQL (primary relational store)  
  - Prisma ORM for type‑safe database access  
- **Infra/DevOps**  
  - Docker containers deployed on Amazon EKS (Kubernetes)  
  - Terraform for IaC, GitHub Actions for CI/CD pipelines  
  - CloudWatch & Prometheus for monitoring, Loki for log aggregation  
- **AI/ML**  
  - Python service with scikit‑learn for matching algorithm  
  - TensorFlow Lite for on‑device recommendation caching  
  - OpenAI GPT‑4 (or fine‑tuned model) for instant feedback generation  

## Architecture  
LearnLoop follows a modular micro‑service architecture: the mobile client talks to a GraphQL gateway that orchestrates several backend services—matching, collaboration, analytics, and AI feedback. Real‑time collaboration is powered by WebSocket connections managed by a Redis‑based message broker. Data is persisted in PostgreSQL, with Redis caching for latency‑critical lookups. AI services run in separate containers, exposing REST endpoints consumed by the gateway. All services are containerized and deployed via Helm charts on EKS, with CI/CD pipelines ensuring rapid, reliable releases.

## Roadmap  
- **v1** – Core MVP: mobile app, smart matching, basic collaboration tools, and instant feedback engine.  
- **v2** – Gamification suite (badges, leaderboards), analytics dashboard, and web portal.  
- **v3** – Advanced AI features (adaptive learning paths), payment integration, and enterprise API for academic institutions.
