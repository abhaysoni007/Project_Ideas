# IdeaCraft

> A tool that scans your GitHub repos and auto-generates a portfolio site from your top projects.

## Problem
Researchers struggle to optimize their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Researchers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Guided onboarding with ready-made templates
- Audit log of every change
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** MySQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
