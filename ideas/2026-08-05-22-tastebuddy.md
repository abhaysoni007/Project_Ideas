# TasteBuddy
> Discover your flavor, elevated.
## Problem 
The current process of finding restaurants, cuisines, and recipes that cater to individual dietary needs and preferences is time-consuming and often relies on manual research. Users have to sift through numerous online reviews, blogs, and websites to find suitable options. This leads to a lack of personalization and potentially disappointing dining experiences.

## Target Users
* Health-conscious individuals with specific dietary requirements (e.g., vegan, gluten-free, keto)
* People with food allergies or intolerances (e.g., lactose intolerance, nut allergies)
* Adventurous eaters looking to explore new cuisines and flavors
* Busy professionals seeking convenient, personalized meal planning and recommendations

## Key Features
* User profile creation with detailed dietary preference and allergy input
* Personalized restaurant and cuisine recommendations based on user profiles
* Recipe suggestions with ingredient lists, cooking instructions, and nutritional information
* Integration with popular food delivery and reservation services for seamless ordering and booking
* Social features for users to share favorite dishes, restaurants, and recipes
* Regular updates with new restaurants, cuisines, and recipes to keep the platform fresh and engaging

## Tech Stack
* Frontend:
  + React for building the user interface
  + Redux for state management
  + Material-UI for styling and design
* Backend:
  + Node.js with Express.js as the server framework
  + GraphQL API for data querying and manipulation
* Database:
  + MongoDB for storing user profiles, restaurant data, and recipe information
* Infra/DevOps:
  + AWS for hosting and scalability
  + Docker for containerization and deployment
* AI/ML:
  + TensorFlow for building and training recommendation models

## Architecture
The TasteBuddy application will follow a microservices architecture, with separate services for user profile management, restaurant and recipe data retrieval, and recommendation engine processing. The frontend will communicate with the backend via the GraphQL API, and the recommendation engine will utilize machine learning models to provide personalized suggestions.

## Roadmap
* v1:
  + Develop and launch the core platform with basic features and a limited dataset
  + Gather user feedback and iterate on the platform
* v2:
  + Integrate with popular food delivery and reservation services
  + Expand the dataset to include more restaurants, cuisines, and recipes
  + Implement social features for user engagement
* v3:
  + Develop and deploy advanced recommendation models using machine learning algorithms
  + Introduce personalized meal planning and nutrition tracking features
  + Explore partnerships with food establishments and meal kit services for exclusive offerings
