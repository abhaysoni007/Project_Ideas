# HiveMind

> Facilitates collaboration and innovation among remote teams by providing a virtual brainstorming and project management platform

## Problem
Remote workers struggle to schedule their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Email and push notifications
- Integrations with Slack, Google, and Stripe
- Real-time updates over WebSockets
- One-click export to CSV and PDF
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
