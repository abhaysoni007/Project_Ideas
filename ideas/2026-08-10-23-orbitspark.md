# OrbitSpark

> A Chrome-to-mobile sync app that lets teachers automate travel itineraries across devices.

## Problem
Open-source maintainers struggle to summarize their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Full-text search with smart filters
- Email and push notifications
- Email/OAuth sign-in with role-based access control
- Responsive dashboard with light and dark mode
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** React Native
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
