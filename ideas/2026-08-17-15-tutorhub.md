# TutorHub

> provides an online tutoring platform for students to access live and on-demand tutoring sessions, interactive study materials, and progress tracking tools.

## Problem
Startups struggle to translate their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- Audit log of every change
- Offline-first with background sync
- Real-time updates over WebSockets
- Email and push notifications
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
