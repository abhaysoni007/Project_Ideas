# NestLab

> A self-hosted read-later app that strips ads and estimates reading time.

## Problem
Gamers struggle to organize their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Email and push notifications
- Usage analytics and an admin panel
- Guided onboarding with ready-made templates
- Team workspaces with granular permissions
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
