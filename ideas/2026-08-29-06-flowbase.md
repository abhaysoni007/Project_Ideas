# FlowBase

> A dashboard that turns raw job applications into actionable music & audio insights.

## Problem
Small teams struggle to optimize their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Small teams
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Responsive dashboard with light and dark mode
- Usage analytics and an admin panel
- One-click export to CSV and PDF
- Email/OAuth sign-in with role-based access control
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
