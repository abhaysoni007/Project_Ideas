# BoltBase
> **“Sync, Highlight, Succeed – Job‑seeker podcasts on the go.”**

## Problem  
Job seekers often listen to career‑focused podcasts across desktop and mobile but miss key takeaways because their notes and highlights don’t sync. The lack of a cross‑device, AI‑powered highlight system forces them to replay entire episodes, wasting time and diluting the learning experience.

## Target Users  
- Early‑career professionals looking to upskill through podcasts  
- Recruiters and hiring managers who consume industry talks for insights  
- Career coaches who track client progress via podcast content  
- HR teams building internal knowledge bases from podcast discussions  

## Key Features  
- Chrome extension that captures spoken highlights and annotates them with speaker tags  
- Real‑time sync of highlights between Chrome, Android, and iOS via a secure API  
- AI summarization of podcast segments using OpenAI GPT‑4, automatically generating concise bullet points  
- Tagging & search functionality across devices (keywords, speaker, episode title)  
- Offline playback on mobile with locally cached audio and highlights  
- Shareable highlight snippets to LinkedIn or Slack for networking and knowledge sharing  
- Analytics dashboard for users to see listening stats and highlight engagement  

## Tech Stack  
- **Frontend**  
  - Chrome Extension: TypeScript, React, WebExtension APIs  
  - Mobile Apps: React Native (Expo) for Android & iOS  
- **Backend**  
  - Node.js (TypeScript) with NestJS framework, GraphQL API  
  - Authentication: OAuth 2.0 + JWT, Google Sign‑In integration  
- **Database**  
  - PostgreSQL 15 with Prisma ORM, hosted on AWS RDS  
- **Infra/DevOps**  
  - Docker for containerization, Kubernetes (Amazon EKS) for orchestration  
  - CI/CD with GitHub Actions, automated tests & image scanning  
  - Monitoring: Prometheus + Grafana, logging with Loki  
  - Secrets Management: AWS Secrets Manager  
- **AI/ML**  
  - OpenAI GPT‑4 for text summarization and speaker diarization  
  - Whisper API for speech‑to‑text transcription of podcast audio  

## Architecture  
BoltBase follows a modular micro‑service approach: the Chrome extension streams raw audio segments to the backend via WebSockets, where the NestJS service transcribes (Whisper), summarizes (GPT‑4), and stores highlights in PostgreSQL. The mobile apps consume a GraphQL endpoint to fetch synchronized highlights, cache them locally with SQLite, and provide offline playback. All services are containerized and deployed on AWS EKS, with a CI pipeline that enforces security scans, unit tests, and end‑to‑end integration tests before promotion to staging and production.

## Roadmap  
- **v1**: Launch Chrome extension and Android app with basic sync and manual highlight capture.  
- **v2**: Add AI summarization, speaker tagging, and search across devices.  
- **v3**: Introduce iOS support, analytics dashboard, and shareable highlight snippets to professional networks.
