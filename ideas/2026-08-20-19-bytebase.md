# ByteBase

> An API service that lets developers add code reviews to any IoT & hardware product.

## Problem
Students struggle to predict their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- AI-assisted recommendations and summaries
- Audit log of every change
- Responsive dashboard with light and dark mode
- Full-text search with smart filters
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Node.js + Express
- **Database:** Supabase
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Node.js + Express API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
