# ForgeBoost

> A weekly-digest service that recommends study material and emails small teams a summary.

## Problem
Founders struggle to summarize their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Guided onboarding with ready-made templates
- Email and push notifications
- Full-text search with smart filters
- Responsive dashboard with light and dark mode
- Audit log of every change

## Tech Stack
- **Frontend:** React
- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a FastAPI (Python) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
