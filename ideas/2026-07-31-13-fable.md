# Fable

> Fable is a virtual event planning platform that uses AI-powered matchmaking, social networking, and content creation tools to help event organizers connect attendees and create engaging experiences.

## Problem
Teachers struggle to audit their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Real-time updates over WebSockets
- Usage analytics and an admin panel
- Offline-first with background sync
- Team workspaces with granular permissions
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** Next.js
- **Backend:** FastAPI (Python)
- **Database:** PostgreSQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a FastAPI (Python) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
