# Bloomly
> Empowering growth, one skill at a time
## Problem
The current learning and development platforms for employees and businesses are often generic, failing to cater to individual needs and learning styles. This results in a significant gap between the skills employees possess and what their roles demand. Consequently, both employee satisfaction and business performance suffer.
## Target Users
* Employees seeking to upskill or reskill
* Businesses aiming to enhance their workforce's capabilities
* Learning and Development (L&D) professionals designing training programs
## Key Features
* Personalized learning pathways based on user goals and proficiency
* Access to a vast library of courses and resources
* AI-driven skill assessments and recommendations
* Social learning features for community engagement and mentorship
* Integration with popular HR systems for seamless user management
* Mobile optimization for on-the-go learning
## Tech Stack
* Frontend:
  + React for building the user interface
  + Redux for state management
* Backend:
  + Node.js with Express for server-side logic
  + GraphQL for API management
* Database:
  + MongoDB for storing user data and learning content
* Infra/DevOps:
  + AWS for hosting and scalability
  + Docker for containerization
* AI/ML:
  + TensorFlow for building and training AI models
## Architecture
The Bloomly platform will follow a microservices architecture, allowing for the independent development and deployment of its core components. This includes separate services for user management, content delivery, and AI-driven recommendations, all communicating through GraphQL APIs.
## Roadmap
* v1:
  + Initial platform launch with basic features
  + Onboarding of first 100 businesses
* v2:
  + Introduction of AI-driven skill assessments and personalized learning pathways
  + Expansion to 500 businesses and 10,000 users
* v3:
  + Integration with major HR systems and addition of social learning features
  + Scaling to support 5,000 businesses and 100,000 users globally
