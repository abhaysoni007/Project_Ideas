# ForgeLab

> A CLI that detects unused dependencies across a monorepo and opens cleanup PRs.

## Problem
Founders struggle to predict their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Integrations with Slack, Google, and Stripe
- AI-assisted recommendations and summaries
- Real-time updates over WebSockets
- Team workspaces with granular permissions
- Offline-first with background sync

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** FastAPI (Python)
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a FastAPI (Python) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap

- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
