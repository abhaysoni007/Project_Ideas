# ForgeBoost

> A tool that scans your GitHub repos and auto-generates a portfolio site from your top projects.

## Problem
Designers struggle to automate their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Responsive dashboard with light and dark mode
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Team workspaces with granular permissions
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Node.js + Express API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
