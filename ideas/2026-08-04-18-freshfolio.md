# FreshFolio

> Assists artists and creatives in building a professional online presence by providing a customizable portfolio and networking platform

## Problem
Startups struggle to summarize their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- One-click export to CSV and PDF
- Real-time updates over WebSockets
- Audit log of every change
- Integrations with Slack, Google, and Stripe
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
