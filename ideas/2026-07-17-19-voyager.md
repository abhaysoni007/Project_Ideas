# Voyager

> Voyager is a travel planning and booking platform for travelers, allowing them to research destinations, book flights and hotels, and plan personalized itineraries.

## Problem
Startups struggle to summarize their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Public REST API with scoped API keys
- Audit log of every change
- Email and push notifications
- Integrations with Slack, Google, and Stripe
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Node.js + Express
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Node.js + Express API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
