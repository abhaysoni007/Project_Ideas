# PeakKit

> A CLI tool that automates travel itineraries in AI/ML workflows.

## Problem
Parents struggle to visualize their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Public REST API with scoped API keys
- Real-time updates over WebSockets
- Responsive dashboard with light and dark mode
- Full-text search with smart filters
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a FastAPI (Python) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
