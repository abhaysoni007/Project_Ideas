# ForgeDeck

> A tool that maps your codebase into an interactive dependency graph.

## Problem
Developers struggle to optimize their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- Offline-first with background sync
- Public REST API with scoped API keys
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Node.js + Express
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Node.js + Express API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
