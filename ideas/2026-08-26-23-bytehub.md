# ByteHub

> A study app that turns your highlighted PDFs into spaced-repetition flashcards.

## Problem
Developers struggle to schedule their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- AI-assisted recommendations and summaries
- Integrations with Slack, Google, and Stripe
- Public REST API with scoped API keys
- Offline-first with background sync
- Audit log of every change

## Tech Stack
- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
