# Nestly

> A tool that watches competitor pricing pages and alerts you when prices change.

## Problem
Open-source maintainers struggle to detect their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- Real-time updates over WebSockets
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- Email and push notifications

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** Supabase
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
