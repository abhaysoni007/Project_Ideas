# EchoLab

> A tool that watches competitor pricing pages and alerts you when prices change.

## Problem
Teachers struggle to recommend their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- Offline-first with background sync
- Audit log of every change
- AI-assisted recommendations and summaries
- Team workspaces with granular permissions
- Email and push notifications

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Node.js + Express
- **Database:** SQLite
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Node.js + Express API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
