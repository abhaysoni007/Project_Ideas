# Proxima

> develops a cutting-edge project management and collaboration tool for remote teams to streamline workflow, track progress, and enhance communication and productivity.

## Problem
Developers struggle to benchmark their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Public REST API with scoped API keys
- Audit log of every change
- AI-assisted recommendations and summaries
- Usage analytics and an admin panel
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
