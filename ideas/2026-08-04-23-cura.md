# Cura

> Supports healthcare providers in delivering personalized patient care by providing a secure, data-driven platform for medical history and treatment planning

## Problem
Freelancers struggle to cluster their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Freelancers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Email/OAuth sign-in with role-based access control
- Full-text search with smart filters
- Audit log of every change
- Usage analytics and an admin panel
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** React
- **Backend:** FastAPI (Python)
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a FastAPI (Python) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
