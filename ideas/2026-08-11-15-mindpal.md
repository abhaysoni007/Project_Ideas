# MindPal

> offers AI-driven mental health support, mood tracking, and personalized wellness recommendations for individuals and organizations.

## Problem
Creators struggle to schedule their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Usage analytics and an admin panel
- Guided onboarding with ready-made templates
- Responsive dashboard with light and dark mode
- One-click export to CSV and PDF
- Email and push notifications

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** MySQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
