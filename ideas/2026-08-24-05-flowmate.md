# FlowMate

> A VS Code extension that helps creators personalize invoices inside the editor.

## Problem
Startups struggle to organize their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Integrations with Slack, Google, and Stripe
- Offline-first with background sync
- Public REST API with scoped API keys
- One-click export to CSV and PDF
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Node.js + Express
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Node.js + Express API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
