# BoltGrid

> A CLI tool that automates sensor data in fintech workflows.

## Problem
Remote workers struggle to audit their travel itineraries without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Public REST API with scoped API keys
- Real-time updates over WebSockets
- One-click export to CSV and PDF
- Offline-first with background sync
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
