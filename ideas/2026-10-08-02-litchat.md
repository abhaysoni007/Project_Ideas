# LitChat
> Collaborate, annotate, and discover—literature made effortless.

## Problem
Academic teams often juggle multiple PDFs, annotating, highlighting, and discussing key passages manually. Coordinating these annotations across collaborators is error‑prone and time‑consuming, and researchers lack a quick way to surface related literature and summarize findings within the same workflow.

## Target Users
- Graduate students working on joint theses or papers  
- Faculty research groups collaborating across departments  
- Post‑docs and research assistants managing literature reviews  
- Academic teams using reference managers like Zotero or Mendeley  

## Key Features
- Real‑time PDF annotation, highlighting, and threaded discussion  
- AI‑powered summarization of highlighted passages and entire documents  
- Automatic retrieval of related literature via semantic search  
- Version control and change tracking for annotations  
- Exportable discussion threads and summaries in LaTeX/Markdown  
- Seamless integration with Zotero, Mendeley, and Google Scholar APIs  
- Mobile‑friendly interface for on‑the‑go collaboration  

## Tech Stack
- **Frontend**: React, TypeScript, Tailwind CSS, WebSocket (Socket.io)  
- **Backend**: Node.js, Express, TypeScript, GraphQL (Apollo Server)  
- **Database**: PostgreSQL, Prisma ORM  
- **Infra/DevOps**: Docker, Kubernetes (Amazon EKS), Terraform, GitHub Actions CI/CD, CloudWatch for logging  
- **AI/ML**: OpenAI GPT‑4 for summarization, Hugging Face Transformers for embeddings, Pinecone for vector store, LangChain for orchestration  

## Architecture
LitChat is built on a microservice architecture where the frontend communicates with a GraphQL API over HTTPS and a WebSocket channel for live collaboration. PDF processing is handled by a background worker service that extracts text, generates embeddings, and stores them in Pinecone. Annotations and discussion threads are persisted in PostgreSQL, with Prisma handling schema migrations. The AI summarization pipeline is decoupled, invoking OpenAI GPT‑4 via LangChain, and results are cached for repeated access. Deployment is containerized, orchestrated by Kubernetes on EKS, and automated through GitHub Actions pipelines.

## Roadmap
- **v1**: Core PDF annotation, real‑time chat, basic AI summarization, and database persistence.  
- **v2**: Semantic literature linking, advanced analytics dashboard, and integration with Zotero/Mendeley.  
- **v3**: Multi‑language support, mobile web app, and offline annotation mode with local sync.
