# PeakScope

> A Chrome-to-mobile sync app that lets open-source maintainers personalize workout plans across devices.

## Problem
Gamers struggle to detect their invoices without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Full-text search with smart filters
- Email and push notifications
- Email/OAuth sign-in with role-based access control
- Integrations with Slack, Google, and Stripe
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
