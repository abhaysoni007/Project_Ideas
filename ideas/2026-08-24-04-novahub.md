# NovaHub

> A weekly-digest service that summarizes reading lists and emails creators a summary.

## Problem
Designers struggle to personalize their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Email and push notifications
- Responsive dashboard with light and dark mode
- One-click export to CSV and PDF
- Offline-first with background sync
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
