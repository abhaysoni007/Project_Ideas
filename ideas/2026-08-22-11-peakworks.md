# PeakWorks

> A CLI tool that automates news feeds in mental wellness workflows.

## Problem
Designers struggle to track their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- One-click export to CSV and PDF
- Public REST API with scoped API keys
- Audit log of every change
- AI-assisted recommendations and summaries
- Email and push notifications

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
