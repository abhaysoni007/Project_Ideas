# DriftBloom

> A study app that turns your highlighted PDFs into spaced-repetition flashcards.

## Problem
Gamers struggle to audit their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Offline-first with background sync
- Responsive dashboard with light and dark mode
- Full-text search with smart filters
- Email and push notifications
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** FastAPI (Python)
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a FastAPI (Python) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
