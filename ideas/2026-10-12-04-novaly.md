# Novaly
> Focus, no distractions: Automate your Pomodoro, mute Slack, and set calendar to busy.

## Problem (2-3 sentences)
In today’s hyperconnected work environment, interruptions from Slack, email, and calendar notifications constantly break deep work sessions. Manual toggling of focus modes is error‑prone and time‑consuming, leading to fragmented productivity. Users need a seamless way to enforce Pomodoro intervals while silencing distractions and updating their availability automatically.

## Target Users (bulleted)
- Remote and hybrid workers who rely on Slack for communication  
- Agile teams using Pomodoro or time‑boxing techniques  
- Developers, designers, and writers seeking uninterrupted focus blocks  
- Professionals with busy calendars that need real‑time status updates  
- Managers who want to monitor team focus without micromanaging

## Key Features (5-7 bullets)
- **Smart Pomodoro Timer**: 25‑minute work, 5‑minute break cycles with customizable durations  
- **Slack Mute & Unmute**: Automatically muting Slack channels or DMs during work intervals and restoring volume afterward  
- **Calendar Busy Status**: Updates Google Calendar, Outlook, or iCal to “Busy” during Pomodoro sessions and “Available” when breaks end  
- **Cross‑Platform Extension**: Chrome/Edge extension plus optional native app for macOS and Windows  
- **Analytics Dashboard**: Weekly reports on focus time, interruptions, and calendar occupancy  
- **Custom Workflows**: Ability to add additional APIs (e.g., Microsoft Teams, Discord) for muting or status changes  
- **Offline Mode**: Timer and mute logic persist locally and sync once internet is restored

## Architecture (a short paragraph)
Novaly runs as a browser extension that injects a lightweight React UI into the user’s tab. The extension communicates with a lightweight Node.js backend via WebSockets for real‑time control of the Pomodoro timer and mute logic. When a work interval starts, the backend calls the Slack Web API to set channel notification preferences, and uses Google Calendar API or Microsoft Graph to mark the user as “Busy.” User preferences and analytics are stored in PostgreSQL, while Redis caches session state for instant response. Dockerized services are deployed to AWS Fargate behind an Application Load Balancer, with TLS termination and automated scaling. Continuous integration ensures that every commit triggers unit tests, linting, and image building, followed by a blue/green deployment.
