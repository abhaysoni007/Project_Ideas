# SageSpark

> A Chrome-to-mobile sync app that lets teachers cluster customer feedback across devices.

## Problem
Open-source maintainers struggle to audit their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Guided onboarding with ready-made templates
- Full-text search with smart filters
- One-click export to CSV and PDF
- Usage analytics and an admin panel
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
