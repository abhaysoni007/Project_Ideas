# SnapCraft

> A weekly-digest service that translates invoices and emails founders a summary.

## Problem
Startups struggle to personalize their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Guided onboarding with ready-made templates
- Email and push notifications
- Responsive dashboard with light and dark mode
- Full-text search with smart filters
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** MySQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a NestJS API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
