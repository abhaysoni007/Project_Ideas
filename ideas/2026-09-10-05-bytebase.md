# ByteBase

> A dashboard that turns raw git commits into actionable AI/ML insights.

## Problem
Researchers struggle to detect their sensor data without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Researchers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Email/OAuth sign-in with role-based access control
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- Public REST API with scoped API keys
- Full-text search with smart filters

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
