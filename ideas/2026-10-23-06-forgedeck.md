# ForgeDeck
> Turn your highlighted PDFs into a living study deck with spaced‑repetition

## Problem
Students and professionals spend hours reading PDFs but struggle to retain key concepts. Highlighting alone doesn't convert insights into long‑term memory. Existing flashcard tools require manual content creation, wasting valuable study time.

## Target Users
- Graduate students preparing for exams
- Medical and law students who rely heavily on PDF literature
- Professionals studying certifications or continuing education
- Knowledge workers who review research papers regularly

## Key Features
- Automatic extraction of highlighted text and context from PDFs
- Context‑aware flashcard generation using NLP
- Built‑in spaced‑repetition algorithm (Anki‑style) with custom scheduling
- Sync across devices via cloud storage (Google Drive / Dropbox)
- Dark mode, offline mode, and customizable card templates

## Tech Stack
- **Frontend**: React, Next.js, TypeScript, Tailwind CSS
- **Backend**: FastAPI (Python), Dockerized microservices
- **Database**: PostgreSQL with TimescaleDB for usage analytics
- **Infra/DevOps**: Docker Compose, Kubernetes (EKS), GitHub Actions CI/CD, Helm charts
- **AI/ML**: OpenAI embeddings, spaCy for sentence parsing, custom spaced‑repetition scheduler in Python

## Architecture
ForgeDeck is a cloud‑native microservice architecture. The frontend communicates with the backend over HTTPS. The backend hosts two services: a PDF ingestion service that streams highlighted content to a message queue, and a flashcard service that consumes the queue, applies NLP pipelines, and persists cards in PostgreSQL. A separate scheduler service runs nightly to update card due dates. All services are containerized and orchestrated with Kubernetes, with GitHub Actions automating CI/CD pipelines.

## Roadmap
- **v1**: PDF upload, highlight extraction, basic flashcard generation, spaced‑repetition schedule, local sync
- **v2**: Cloud sync (Google Drive/Dropbox), multi‑device support, dark mode, analytics dashboard
- **v3**: AI‑powered summarization, custom learning paths, export/import to Anki, mobile web app
