# Cultivate

> offers a farm-to-table platform for local farmers to sell produce directly to consumers, while providing resources for sustainable agriculture practices.

## Problem
Parents struggle to predict their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Integrations with Slack, Google, and Stripe
- Audit log of every change
- One-click export to CSV and PDF
- Email/OAuth sign-in with role-based access control
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Next.js
- **Backend:** FastAPI (Python)
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a FastAPI (Python) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
