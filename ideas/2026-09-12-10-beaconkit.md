# BeaconKit

> A weekly-digest service that summarizes news feeds and emails designers a summary.

## Problem
Designers struggle to summarize their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- One-click export to CSV and PDF
- Audit log of every change
- Public REST API with scoped API keys
- Offline-first with background sync
- Email and push notifications

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
