# LoopWise

> A no-code builder for designers to recommend code reviews without writing code.

## Problem
Open-source maintainers struggle to summarize their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- AI-assisted recommendations and summaries
- Integrations with Slack, Google, and Stripe
- Guided onboarding with ready-made templates
- Offline-first with background sync
- Email and push notifications

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
