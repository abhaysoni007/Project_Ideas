# NovaHub

> A self-hosted tool that lets open-source maintainers track customer feedback with full data privacy.

## Problem
Researchers struggle to predict their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Researchers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Public REST API with scoped API keys
- Full-text search with smart filters
- Team workspaces with granular permissions
- Guided onboarding with ready-made templates
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
