# SyncGrid

> A no-code builder for teachers to predict reading lists without writing code.

## Problem
Parents struggle to visualize their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- Responsive dashboard with light and dark mode
- Email/OAuth sign-in with role-based access control
- Full-text search with smart filters
- One-click export to CSV and PDF
- Email and push notifications

## Tech Stack
- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** MySQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a NestJS API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
