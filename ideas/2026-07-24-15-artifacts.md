# ArtiFacts

> Enables museums and cultural institutions to create interactive, immersive exhibits using virtual and augmented reality storytelling techniques

## Problem
Freelancers struggle to translate their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Freelancers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Email/OAuth sign-in with role-based access control
- Guided onboarding with ready-made templates
- Real-time updates over WebSockets
- Offline-first with background sync
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
