# Voyager

> Voyager is a travel planning app that uses machine learning to recommend personalized itineraries, book flights and accommodations, and provide real-time travel assistance.

## Problem
Open-source maintainers struggle to track their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Full-text search with smart filters
- Offline-first with background sync
- Team workspaces with granular permissions
- AI-assisted recommendations and summaries
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** React Native
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
