# CodePlay
> *Play. Code. Grow.*

## Problem  
Middle‑school students often struggle to stay engaged with introductory programming because lessons feel abstract and lack real‑world context. Traditional textbooks and static tutorials do not adapt to each learner’s pace, leaving many students either bored or overwhelmed.

## Target Users  
- Middle‑school students (grades 6‑8)  
- Teachers seeking interactive, curriculum‑aligned resources  
- Parents wanting to support their child’s coding journey  

## Key Features  
- Adaptive project challenges that scale difficulty based on student performance  
- Built‑in visual feedback with instant code execution and debugging hints  
- Leaderboard and badge system to motivate healthy competition  
- Drag‑and‑drop coding interface for beginners, with optional text editor mode  
- Parent/teacher portal for progress tracking and personalized assignments  
- Collaborative mode allowing pair‑programming in real time  

## Tech Stack  
- **Frontend**: React (TypeScript), Next.js, Tailwind CSS, Recoil for state management  
- **Backend**: Node.js (Express) with TypeScript, Socket.IO for real‑time collaboration  
- **Database**: PostgreSQL (primary) + Redis for caching and pub/sub  
- **Infra/DevOps**: Docker, Kubernetes (EKS on AWS), GitHub Actions CI/CD, Terraform for IaC  
- **AI/ML**: OpenAI GPT‑4 for adaptive difficulty suggestions and code review hints  

## Architecture  
CodePlay follows a modular, micro‑service style architecture: the frontend serves a Next.js SPA that communicates with the backend over REST and WebSocket APIs. The backend orchestrates challenge generation, user session management, and real‑time collaboration. PostgreSQL stores user data, challenge metadata, and logs, while Redis handles session caching and message brokering. AI services run in a separate container, interfacing via gRPC to provide adaptive difficulty and instant code review.  

## Roadmap  
- **v1**: Core LMS with drag‑and‑drop editor, single‑player adaptive challenges, basic leaderboard  
- **v2**: Real‑time pair‑programming, teacher dashboard, parent portal, AI‑powered code review  
- **v3**: Advanced gamification (quests, achievements), integration with school grading systems, multilingual support
