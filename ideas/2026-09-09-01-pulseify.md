# Pulseify

> A habit tracker that pairs you with an accountability buddy who has the same goal.

## Problem
Open-source maintainers struggle to organize their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Guided onboarding with ready-made templates
- One-click export to CSV and PDF
- AI-assisted recommendations and summaries
- Offline-first with background sync
- Email and push notifications

## Tech Stack
- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
