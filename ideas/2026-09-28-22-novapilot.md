# NovaPilot

> A Slack/Discord bot that helps parents translate cloud costs without leaving chat.

## Problem
Startups struggle to audit their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Full-text search with smart filters
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- Public REST API with scoped API keys
- Offline-first with background sync

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
