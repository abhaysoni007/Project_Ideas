# Snaply

> A CLI that detects unused dependencies across a monorepo and opens cleanup PRs.

## Problem
Open-source maintainers struggle to summarize their travel itineraries without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- One-click export to CSV and PDF
- Audit log of every change
- Full-text search with smart filters
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** MySQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap

- **v2** — Integrations, notifications, and the public API
