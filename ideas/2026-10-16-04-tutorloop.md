# TutorLoop
> Instant AI‑powered tutoring for high school and college students

## Problem  
Students often struggle to find a qualified mentor in the moment they need help, leading to lost learning momentum. Current tutoring platforms are either too generic or require lengthy scheduling, creating friction for learners seeking quick, subject‑specific support.

## Target Users  
- High school students needing help with homework or exam prep  
- College undergraduates tackling complex concepts in STEM, humanities, or languages  
- Parents seeking reliable, on‑demand tutoring options for their children  
- Academic tutors and micro‑experts looking to monetize their knowledge

## Key Features  
- **Real‑time mentor matching** based on subject expertise, availability, and student preferences  
- **AI‑assisted session facilitation** that suggests resources, auto‑generates quizzes, and monitors progress  
- **Secure video/audio chat** with screen‑sharing and collaborative whiteboard  
- **Micro‑payment system** for instant pay‑per‑minute tutoring with escrow protection  
- **Dynamic scheduling** that auto‑confirms or reschedules based on mentor calendar integration  
- **Progress dashboards** for students and mentors, tracking completed sessions and skill gains  
- **Feedback & rating loop** to continuously improve mentor quality and AI suggestions

## Tech Stack  

- **Frontend**  
  - React (TypeScript)  
  - Vite for fast builds  
  - Tailwind CSS for responsive UI  
  - WebRTC (SimpleWebRTC) for real‑time communication  

- **Backend**  
  - Node.js (Express)  
  - NestJS for modular architecture  
  - TypeScript throughout  

- **Database**  
  - PostgreSQL (primary data store)  
  - Redis (caching, session store)  

- **Infra/DevOps**  
  - Docker Compose for local development  
  - Kubernetes (EKS) for production  
  - Terraform for IaC  
  - GitHub Actions for CI/CD pipelines  
  - Cloudflare CDN & SSL termination  

- **AI/ML**  
  - OpenAI GPT‑4 Turbo (chat and content generation)  
  - LangChain for prompt orchestration  
  - LlamaIndex for knowledge base indexing of mentor materials  
  - Azure Cognitive Search for fast retrieval of subject resources  

## Architecture  
TutorLoop follows a micro‑service architecture with a single‑page React client communicating over HTTPS with a NestJS API gateway. The gateway routes requests to dedicated services: `AuthService`, `MatchingService`, `SessionService`, and `AIService`. Data persistence is handled by PostgreSQL, while Redis manages transient session data and caching. Real‑time video/audio flows through a WebRTC mesh orchestrated by a signaling server (Socket.io). AI interactions are abstracted behind an `AIService` that calls OpenAI via LangChain pipelines, allowing easy swapping of models or adding custom prompts. The entire stack is containerized, deployed to EKS, and managed with Terraform, ensuring scalability and resilience.

## Roadmap  
- **v1**: Core MVP – real‑time matching, video chat, AI‑assisted tutoring, basic payment gateway  
- **v2**: Advanced features – subject‑specific knowledge bases, mentor dashboards, analytics, and mobile app (React Native)  
- **v3**: Marketplace expansion – group tutoring, subscription plans, AI tutor bots, and internationalization support
