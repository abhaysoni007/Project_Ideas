# NestBloom

> A browser extension that shows the carbon footprint of each website you visit.

## Problem
Founders struggle to schedule their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- One-click export to CSV and PDF
- Email/OAuth sign-in with role-based access control
- Full-text search with smart filters
- Email and push notifications
- Offline-first with background sync

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** NestJS
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a NestJS API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
