# PeakStack

> A habit tracker that pairs you with an accountability buddy who has the same goal.

## Problem
Remote workers struggle to summarize their invoices without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Real-time updates over WebSockets
- Email/OAuth sign-in with role-based access control
- Offline-first with background sync
- One-click export to CSV and PDF
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
