# MintScope

> A self-hosted read-later app that strips ads and estimates reading time.

## Problem
Freelancers struggle to translate their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Freelancers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Public REST API with scoped API keys
- Audit log of every change
- Real-time updates over WebSockets
- Usage analytics and an admin panel
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
