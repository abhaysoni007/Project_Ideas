# DriftStack

> A tool that audits a website's Core Web Vitals and suggests concrete fixes.

## Problem
Parents struggle to benchmark their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- One-click export to CSV and PDF
- Email and push notifications
- Audit log of every change
- Team workspaces with granular permissions
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
