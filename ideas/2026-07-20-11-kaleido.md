# Kaleido

> creates a 3D design and augmented reality platform for interior designers, architects, and homeowners to visualize and interact with spatial designs in a immersive environment.

## Problem
Remote workers struggle to detect their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Offline-first with background sync
- Team workspaces with granular permissions
- Full-text search with smart filters
- AI-assisted recommendations and summaries
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
