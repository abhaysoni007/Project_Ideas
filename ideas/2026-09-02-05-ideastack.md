# IdeaStack

> A fintech app that uses AI to organize invoices for students.

## Problem
Designers struggle to track their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- Public REST API with scoped API keys
- Email and push notifications
- One-click export to CSV and PDF
- Audit log of every change

## Tech Stack
- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a NestJS API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
