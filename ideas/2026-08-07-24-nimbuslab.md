# NimbusLab

> A mobile app that gamifies job applications to keep job seekers engaged.

## Problem
Remote workers struggle to schedule their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Usage analytics and an admin panel
- Real-time updates over WebSockets
- Guided onboarding with ready-made templates
- Audit log of every change
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
