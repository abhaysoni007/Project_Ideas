# FlowCraft

> A CLI that turns terminal session recordings into shareable animated SVGs.

## Problem
Parents struggle to organize their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- Usage analytics and an admin panel
- Email/OAuth sign-in with role-based access control
- Public REST API with scoped API keys
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
