# EduPilot

> provides a learning management system for schools and educators to track student progress, create personalized lesson plans, and streamline grading.

## Problem
Developers struggle to schedule their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Audit log of every change
- One-click export to CSV and PDF
- AI-assisted recommendations and summaries
- Email and push notifications
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** MySQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
