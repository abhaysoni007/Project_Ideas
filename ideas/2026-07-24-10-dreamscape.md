# DreamScape

> Allows architects and designers to create immersive, interactive 3D models of buildings and spaces using virtual and augmented reality

## Problem
Startups struggle to track their daily habits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Email and push notifications
- Team workspaces with granular permissions
- Real-time updates over WebSockets
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
