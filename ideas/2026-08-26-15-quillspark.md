# QuillSpark

> A CLI tool that automates sensor data in social workflows.

## Problem
Creators struggle to benchmark their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Audit log of every change
- Usage analytics and an admin panel
- Guided onboarding with ready-made templates
- Public REST API with scoped API keys
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
