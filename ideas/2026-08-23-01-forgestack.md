# ForgeStack

> An API service that lets developers add recipes to any data visualization product.

## Problem
Designers struggle to cluster their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Responsive dashboard with light and dark mode
- Real-time updates over WebSockets
- Usage analytics and an admin panel
- Email/OAuth sign-in with role-based access control
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Go (Gin)
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Go (Gin) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
