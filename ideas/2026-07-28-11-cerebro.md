# Cerebro

> assists individuals with cognitive impairments, such as dementia or Alzheimer's, by providing a personalized cognitive training and memory aid platform

## Problem
Gamers struggle to recommend their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Public REST API with scoped API keys
- Real-time updates over WebSockets
- One-click export to CSV and PDF
- Email/OAuth sign-in with role-based access control
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** React Native
- **Backend:** Node.js + Express
- **Database:** SQLite
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Node.js + Express API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
