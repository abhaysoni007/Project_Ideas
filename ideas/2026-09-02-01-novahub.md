# NovaHub

> An API service that lets developers add study material to any data visualization product.

## Problem
Designers struggle to automate their expenses without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Guided onboarding with ready-made templates
- AI-assisted recommendations and summaries
- Team workspaces with granular permissions
- Full-text search with smart filters
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** React
- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a FastAPI (Python) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
