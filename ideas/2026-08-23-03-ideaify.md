# Ideaify

> A dashboard that grades your resume against a job description and lists gaps.

## Problem
Remote workers struggle to summarize their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Usage analytics and an admin panel
- Guided onboarding with ready-made templates
- Responsive dashboard with light and dark mode
- One-click export to CSV and PDF
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
