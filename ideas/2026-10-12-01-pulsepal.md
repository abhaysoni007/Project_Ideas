# PulsePal
> Your heartbeat, in real‑time, with AI‑driven alerts.

## Problem  
Arrhythmias often remain asymptomatic until an emergency occurs, and continuous ECG monitoring is limited by bulky equipment and patient non‑compliance. Clinicians lack actionable, real‑time data to intervene proactively, while patients experience anxiety and uncertainty about their heart health.

## Target Users  
- Patients with known arrhythmia risk or prior cardiac events  
- Cardiologists and electrophysiologists needing continuous patient data  
- Primary care providers monitoring chronic heart conditions  
- Hospital telemetry teams looking to reduce readmissions  

## Key Features  
- Wearable ECG sensor with BLE connectivity  
- Edge AI inference (TensorFlow Lite) for instant anomaly detection  
- Real‑time push alerts to patient and clinician devices via FCM/APNs  
- Secure, HIPAA‑compliant data sync to cloud backend  
- Web‑based clinician dashboard with historical trend visualisation  
- Medication reminders and patient education modules  
- Offline mode with local storage and auto‑upload when connectivity restores  

## Tech Stack  
- **Frontend**: React Native (mobile), React (web)  
- **Backend**: FastAPI (Python) with WebSocket support  
- **Database**: PostgreSQL + TimescaleDB for time‑series ECG data  
- **Infra/DevOps**: Docker, Kubernetes (EKS), Terraform, GitHub Actions CI/CD, Prometheus + Grafana monitoring, CloudWatch logging  
- **AI/ML**: TensorFlow Lite for on‑device inference, PyTorch model training pipeline, ONNX export for cross‑platform deployment  

## Architecture  
ECG data is captured by the PulsePal wearable and transmitted via BLE to the patient’s smartphone, where a React Native app encrypts and streams the data over HTTPS to the FastAPI backend. The backend stores raw traces in TimescaleDB, forwards them to the AI inference service (TensorFlow Lite) for anomaly scoring, and triggers push notifications to the patient and clinician dashboards when thresholds are exceeded. Clinicians review trends in a secure web portal, which also exposes FHIR APIs for EHR integration. All services run in Docker containers orchestrated by Kubernetes, with automated CI/CD pipelines and robust monitoring.

## Roadmap  
- **v1**: Wearable prototype + mobile app + basic AI detection + alerting + clinician web portal  
- **v2**: Expand sensor suite, advanced ML models, EHR (FHIR) integration, HIPAA audit, multi‑device sync  
- **v3**: Predictive analytics, adaptive learning, global rollout, AI model optimisation, compliance with international regulations (EU MDR, ISO 13485)
