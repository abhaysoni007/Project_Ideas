# IdeaKit  
> Turn every meeting into a research goldmine.

## Problem  
Researchers juggle countless meetings but struggle to keep accurate, searchable notes. Manual note‑taking slows down collaboration, and important insights are often lost in transcription noise. The lack of a smart, AI‑powered assistant leads to wasted time and fragmented knowledge bases.

## Target Users  
- Academic researchers and PhD students  
- R&D teams in universities and labs  
- Scientific project managers  
- Collaboration hubs for interdisciplinary research  
- Grant writing consultants  

## Key Features  
- Real‑time AI transcription with speaker diarization  
- Smart summarization highlighting key findings, action items, and references  
- Automatic integration with Google Docs, Notion, and Overleaf  
- Contextual knowledge graph linking papers, datasets, and collaborators  
- Voice‑activated commands to annotate, tag, or flag sections  
- Exportable PDFs, Markdown, and LaTeX files for publication pipelines  
- Privacy‑first design with end‑to‑end encryption and local model fallback  

## Tech Stack  
**Frontend**  
- React 18 + TypeScript + Vite  
- Tailwind CSS & Headless UI  
- Zustand for state management  

**Backend**  
- Node.js 20 (NestJS) with TypeScript  
- REST + GraphQL API  

**Database**

- Redis 7 for caching & pub/sub  
- Supabase Auth for user management  

**Infra/DevOps**  
- Docker Compose + Docker Swarm (dev)  
- GitHub Actions CI/CD  
- Fly.io / Railway for edge deployment  
- Cloudflare Workers for CDN & API routing  
- Terraform for provisioning  

**AI/ML**  
- Whisper (OpenAI) for speech‑to‑text  
- OpenAI GPT‑4o / Claude 3 for summarization & Q&A  
- spaCy for entity extraction  
- Pinecone for vector store & semantic search  
- LangChain for orchestration  

## Architecture  
IdeaKit follows a modular micro‑frontend/micro‑service pattern. The web client streams audio to an Edge worker that forwards data to a dedicated transcription service powered by Whisper. The resulting text is sent to a summarization service (OpenAI GPT‑4o) which enriches it with metadata and a knowledge graph stored in PostgreSQL. Real‑time updates are pushed via WebSocket to the frontend. All services are containerized, version‑controlled, and deployed through Fly.io, with Terraform managing networking and secrets. Vector embeddings for semantic search are stored in Pinecone, accessed via a dedicated API gateway.
