# Idealy

> A extension that summarizes long GitHub issues and their comment threads.

## Problem
Startups struggle to summarize their expenses without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Email/OAuth sign-in with role-based access control
- Public REST API with scoped API keys
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Next.js
- **Backend:** FastAPI (Python)
- **Database:** Supabase
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a FastAPI (Python) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
