# BeaconDeck
> Sync your design workouts from Chrome to mobile—track progress, share plans, and stay in rhythm.

## Problem (2-3 sentences)
Designers often prototype workout plans in Chrome extensions, but there’s no reliable way to keep those plans in sync with their mobile devices. This leads to duplicated effort, lost data, and fragmented user experience across platforms.

## Target Users (bulleted)
- UI/UX designers who iterate on workout plans in Chrome
- Fitness professionals using design tools to create client routines
- Teams collaborating on shared workout libraries
- Mobile users who want instant access to their latest plans

## Key Features (5-7 bullets)
- Chrome extension that captures workout plan data and pushes it to a cloud API  
- iOS & Android mobile app with offline caching and real‑time sync via WebSockets  
- Role‑based sharing: view‑only, edit, or comment permissions  
- Activity log with timestamps, version history, and diff view  
- Push notifications for plan updates, comments, and deadline reminders  
- Analytics dashboard displaying completion rates and engagement  
- Optional AI assistant to auto‑suggest plan improvements based on past usage  

## Tech Stack
- **Frontend**: React + TypeScript for Chrome extension UI, React Native (Expo) for mobile app  
- **Backend**: Node.js (Express) with TypeScript, GraphQL (Apollo Server) for flexible querying  
- **Database**: PostgreSQL on AWS RDS for structured plan data; Redis for caching session tokens  
- **Infra/DevOps**: Docker + Kubernetes on AWS EKS; Terraform for IaC; GitHub Actions CI/CD; CloudWatch for logging  
- **AI/ML**: OpenAI GPT‑4 API for natural language suggestions; TensorFlow Lite for on‑device inference on mobile  

## Architecture (a short paragraph)
BeaconDeck follows a micro‑service pattern where the Chrome extension communicates with a REST/GraphQL gateway that authenticates via OAuth2. The backend services run in containers orchestrated by Kubernetes, exposing a secure API over HTTPS. Mobile apps connect through the same GraphQL endpoint, leveraging WebSocket subscriptions for live updates. Data is persisted in PostgreSQL, with Redis caching for session management and hot queries. CI/CD pipelines automatically build, test, and deploy each component, ensuring zero‑downtime updates.

## Roadmap (v1, v2, v3 bullets)
- **v1**: MVP – Chrome extension, basic plan CRUD, mobile app with offline sync, authentication, and push notifications  
- **v2**: Advanced collaboration – role permissions, comment threads, activity log, version history, and analytics dashboard  
- **v3**: AI enhancements – GPT‑4 powered suggestions, on‑device inference, and integration with wearable fitness APIs
