# ChefAI
> Turn your pantry into gourmet meals, instantly.

## Problem
Busy professionals often lack time to plan meals or search for recipes that fit their available ingredients and dietary restrictions. Manual meal planning leads to repetitive meals, food waste, and unhealthy choices.

## Target Users
- Working professionals aged 25‑45
- Individuals with dietary restrictions (gluten‑free, keto, vegan, etc.)
- Home cooks seeking quick, ingredient‑based meal ideas
- Food enthusiasts who want to reduce food waste

## Key Features
- **Ingredient‑based recipe generation** using AI
- **Dietary restriction filtering** (gluten‑free, vegan, keto, etc.)
- **Pantry inventory sync** via barcode scanning or manual entry
- **Smart grocery list creation** for missing items
- **Meal scheduling** and calendar integration
- **Voice‑command recipe guidance** for hands‑free cooking
- **User‑saved favorites** and custom recipe tweaks

## Tech Stack
- **Frontend**: React, TypeScript, Next.js, Tailwind CSS
- **Backend**: NestJS (Node.js), Express middleware
- **Database**: PostgreSQL (primary), Redis (caching)
- **Infra/DevOps**: Docker, Kubernetes (EKS on AWS), GitHub Actions CI/CD, Terraform
- **AI/ML**: OpenAI GPT‑4 (text generation), OpenAI embeddings, LangChain framework, Python microservice for model orchestration

## Architecture
ChefAI follows a micro‑service architecture: a Next.js front‑end communicates with a NestJS API that orchestrates requests to a dedicated AI micro‑service running GPT‑4 via the OpenAI API. User data, pantry inventories, and recipe metadata reside in PostgreSQL, while Redis handles session caching. Docker containers are deployed to an AWS EKS cluster, automated through GitHub Actions.

## Roadmap
- **v1** – Core pantry sync, AI recipe generation, basic UI, user authentication
- **v2** – Voice‑command integration, offline mode, personalized meal plans, grocery list export
- **v3** – Advanced AI features (taste profile tuning), calendar sync, multi‑device support, AI‑powered nutritional analysis
