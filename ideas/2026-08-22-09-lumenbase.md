# LumenBase

> A CLI that detects unused dependencies across a monorepo and opens cleanup PRs.

## Problem
Startups struggle to predict their expenses without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Integrations with Slack, Google, and Stripe
- Real-time updates over WebSockets
- Usage analytics and an admin panel
- Guided onboarding with ready-made templates
- Audit log of every change

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
