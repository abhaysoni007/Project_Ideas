# FlowBoost

> A dashboard that grades your resume against a job description and lists gaps.

## Problem
Creators struggle to predict their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Integrations with Slack, Google, and Stripe
- Responsive dashboard with light and dark mode
- Audit log of every change
- Public REST API with scoped API keys
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
