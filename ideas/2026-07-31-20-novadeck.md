# NovaDeck

> A tool that scans your GitHub repos and auto-generates a portfolio site from your top projects.

## Problem
Designers struggle to recommend their expenses without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Usage analytics and an admin panel
- Real-time updates over WebSockets
- Public REST API with scoped API keys
- Email and push notifications
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
