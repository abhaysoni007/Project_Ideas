# VoiceVista

> offers a voice-controlled interface for accessing and managing digital information, designed for individuals with disabilities and older adults.

## Problem
Founders struggle to optimize their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Audit log of every change
- One-click export to CSV and PDF
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
