# Loopify

> A tool that scans your GitHub repos and auto-generates a portfolio site from your top projects.

## Problem
Founders struggle to audit their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Email and push notifications
- Public REST API with scoped API keys
- Real-time updates over WebSockets
- Full-text search with smart filters
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** React Native
- **Backend:** Node.js + Express
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Node.js + Express API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
