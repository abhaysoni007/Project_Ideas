# EcoBin  
> Trash that Thinks

## Problem  
Many households struggle to separate recyclables from general waste, leading to contamination of recycling streams and missed environmental benefits.  
Existing smart bins lack accurate material identification and actionable insights, leaving users uncertain about their waste habits.

## Target Users  
- Eco‑conscious homeowners and renters  
- Small apartment dwellers with limited space  
- Community garden managers and co‑op households  
- Local councils looking for pilot sustainability tech  

## Key Features  
- AI‑powered image classification of recyclables at the point of disposal  
- Real‑time waste tracking and smart alerts on a mobile/web dashboard  
- Weekly email and push‑notification waste reports with carbon‑footprint metrics  
- Voice assistant integration (Alexa, Google Assistant) for status queries  
- Energy‑efficient design with solar charging and low‑power sensors  
- Modular hardware that supports future sensor upgrades (e.g., weight, RFID)

## Tech Stack  
- **Frontend**: React Native (mobile), React + TypeScript (web)  
- **Backend**: Python FastAPI (REST & WebSocket endpoints)  
- **Database**: PostgreSQL (transactional data), Redis (caching & pub/sub)  
- **Infra/DevOps**: Docker Compose (local), Amazon EKS (K8s), Terraform, GitHub Actions CI/CD, CloudWatch for monitoring  
- **AI/ML**: TensorFlow Lite on embedded device, PyTorch Lightning for training, AWS SageMaker for model hosting

## Architecture  
The EcoBin system comprises an ESP32‑based enclosure with camera and weight sensor, transmitting images and sensor data over MQTT to an AWS IoT Core endpoint. A FastAPI gateway ingests the payloads, stores metadata in PostgreSQL, and triggers a TensorFlow Lite inference pipeline on the edge device for instant feedback. Weekly analytics are computed in a scheduled Lambda job, which aggregates data, calculates carbon savings, and pushes reports to the React Native app via FCM. All services run in Docker containers orchestrated by EKS, with Terraform provisioning the infra and GitHub Actions handling CI/CD.

## Roadmap  
- **v1**: Sensor integration, edge inference, basic mobile dashboard, weekly email reports  
- **v2**: Cloud‑based model updates, predictive analytics, push notifications, multi‑user support  
- **v3**: Advanced recycling recommendations, community leaderboard, API for third‑party integration, AI‑driven waste scheduling
