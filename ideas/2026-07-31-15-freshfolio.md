# FreshFolio

> FreshFolio is a portfolio management platform that helps creatives showcase their work, connect with potential clients, and manage projects from concept to completion.

## Problem
Designers struggle to cluster their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- AI-assisted recommendations and summaries
- Full-text search with smart filters
- Guided onboarding with ready-made templates
- Usage analytics and an admin panel
- Audit log of every change

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
