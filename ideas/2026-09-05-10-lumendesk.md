# LumenDesk

> An API service that lets developers add expenses to any health & fitness product.

## Problem
Small teams struggle to track their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Small teams
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Integrations with Slack, Google, and Stripe
- Full-text search with smart filters
- Audit log of every change
- Offline-first with background sync
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
