# PeakBoost

> An app that converts long YouTube tutorials into step-by-step markdown notes.

## Problem
Students struggle to translate their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Full-text search with smart filters
- Integrations with Slack, Google, and Stripe
- Public REST API with scoped API keys
- Email and push notifications
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
