# BoltScope
> Stay Informed, Stay Connected.

## Problem
Teams waste time switching between browsers and messaging apps to catch up on industry news. Existing integrations either push too many irrelevant updates or require complex setup, leading to information overload and low adoption.

## Target Users
- Small tech startups (≤10 people)  
- Marketing and product teams using Slack or Discord  
- Remote teams that rely on chat for daily coordination  
- Managers who want a quick pulse on competitor activity

## Key Features
- **Channel‑specific RSS/Atom feed subscription** with custom filters  
- **Smart summarization**: AI‑generated highlights delivered as concise messages  
- **Mention triggers**: keyword alerts that ping team members instantly  
- **One‑click configuration** via an in‑app wizard (no web UI required)  
- **Retention and search**: archived posts searchable within Slack/Discord  
- **Multi‑platform support**: native Slack and Discord bots with unified command set  
- **Analytics dashboard** (web) showing feed engagement metrics

## Tech Stack
- **Frontend**: React + Chakra UI (for optional web dashboard)  
- **Backend**: Node.js + Express, Typescript  
- **Database**: PostgreSQL (via Prisma ORM)  
- **Infra/DevOps**: Docker, GitHub Actions CI/CD, Fly.io for serverless deployment, Cloudflare DNS, TLS via Let's Encrypt  
- **AI/ML**: OpenAI GPT‑4 for summarization, HuggingFace Transformers for keyword extraction

## Architecture
BoltScope runs as a stateless containerized service behind Fly.io. The Slack/Discord bot listens to incoming slash commands and webhooks, passing messages to the Express API, which stores data in PostgreSQL. A background worker (Node worker) polls subscribed feeds, applies a summarization pipeline via OpenAI, and posts concise updates to the appropriate channels. All secrets are managed by Fly.io secrets and GitHub Actions secrets, ensuring secure CI/CD.

## Roadmap
- **v1**: Core Slack bot, RSS feed subscription, basic summarization, web dashboard for analytics  
- **v2**: Discord bot integration, advanced keyword filters, mention‑triggered alerts, UI improvements  
- **v3**: Custom AI summarization model fine‑tuned for industry domains, multi‑team tenant support, mobile notifications, API for third‑party integrations
