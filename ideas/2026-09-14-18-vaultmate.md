# VaultMate

> A mobile app that gamifies job applications to keep remote workers engaged.

## Problem
Teachers struggle to audit their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- AI-assisted recommendations and summaries
- Real-time updates over WebSockets
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
