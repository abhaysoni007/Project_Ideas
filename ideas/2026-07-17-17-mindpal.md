# MindPal

> MindPal is a mental health and wellness platform for individuals, offering therapy sessions, mood tracking, and personalized self-care recommendations.

## Problem
Teachers struggle to schedule their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Team workspaces with granular permissions
- Offline-first with background sync
- Public REST API with scoped API keys
- Guided onboarding with ready-made templates
- Audit log of every change

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Node.js + Express API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
