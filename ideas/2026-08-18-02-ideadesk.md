# IdeaDesk

> A CLI tool that automates code reviews in social workflows.

## Problem
Students struggle to recommend their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Integrations with Slack, Google, and Stripe
- Full-text search with smart filters
- AI-assisted recommendations and summaries
- Usage analytics and an admin panel
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** MySQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
