# ByteWorks

> An AI-free rule-based linter for accessibility issues in HTML emails.

## Problem
Creators struggle to automate their invoices without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Team workspaces with granular permissions
- Email/OAuth sign-in with role-based access control
- Email and push notifications
- Guided onboarding with ready-made templates
- Usage analytics and an admin panel
- Audit log of every change

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Go (Gin)
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Go (Gin) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
