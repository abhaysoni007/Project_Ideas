# DriftPath

> A VS Code extension that helps creators summarize sensor data inside the editor.

## Problem
Creators struggle to predict their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Real-time updates over WebSockets
- Guided onboarding with ready-made templates
- Public REST API with scoped API keys
- Email/OAuth sign-in with role-based access control
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
