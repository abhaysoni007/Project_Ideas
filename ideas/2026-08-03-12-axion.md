# Axion

> develops an AI-powered sales forecasting and pipeline management tool for enterprise sales teams, using machine learning to predict revenue and optimize performance.

## Problem
Researchers struggle to optimize their travel itineraries without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Researchers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Responsive dashboard with light and dark mode
- Public REST API with scoped API keys
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** React
- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a FastAPI (Python) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
