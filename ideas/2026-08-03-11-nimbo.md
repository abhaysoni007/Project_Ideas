# Nimbo

> helps homeowners and property managers track and manage maintenance, repairs, and renovations, using a mobile app to simplify the process.

## Problem
Startups struggle to automate their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Full-text search with smart filters
- One-click export to CSV and PDF
- Real-time updates over WebSockets
- Email/OAuth sign-in with role-based access control
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
