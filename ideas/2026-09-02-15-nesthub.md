# NestHub

> A mobile app that gamifies invoices to keep developers engaged.

## Problem
Students struggle to translate their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- AI-assisted recommendations and summaries
- Email and push notifications
- Full-text search with smart filters
- Offline-first with background sync
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** React
- **Backend:** Django
- **Database:** MongoDB
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a Django API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
