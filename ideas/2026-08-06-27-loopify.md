# Loopify

> An API service that lets developers add job applications to any education product.

## Problem
Startups struggle to visualize their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Audit log of every change
- Responsive dashboard with light and dark mode
- Guided onboarding with ready-made templates
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** FastAPI (Python)
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a FastAPI (Python) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
