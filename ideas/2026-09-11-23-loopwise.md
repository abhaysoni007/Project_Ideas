# LoopWise

> A weekly-digest service that detects git commits and emails remote workers a summary.

## Problem
Founders struggle to optimize their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- One-click export to CSV and PDF
- Public REST API with scoped API keys
- Full-text search with smart filters
- Offline-first with background sync
- Email and push notifications

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
