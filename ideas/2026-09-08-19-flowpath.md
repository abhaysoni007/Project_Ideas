# FlowPath

> A mobile app that gamifies energy usage to keep remote workers engaged.

## Problem
Developers struggle to cluster their meeting notes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Public REST API with scoped API keys
- Full-text search with smart filters
- Team workspaces with granular permissions
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** React Native
- **Backend:** Django
- **Database:** MySQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Django API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
