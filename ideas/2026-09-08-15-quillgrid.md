# QuillGrid

> An app that converts long YouTube tutorials into step-by-step markdown notes.

## Problem
Designers struggle to translate their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Guided onboarding with ready-made templates
- AI-assisted recommendations and summaries
- Offline-first with background sync
- Audit log of every change
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
