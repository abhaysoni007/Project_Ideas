# EchoCraft

> A Pomodoro timer that mutes Slack and sets your calendar to busy automatically.

## Problem
Founders struggle to recommend their workout plans without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Email and push notifications
- Offline-first with background sync
- Team workspaces with granular permissions
- Guided onboarding with ready-made templates
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
