# LumenKit

> A service that turns your bank statements into a plain-English monthly spending story.

## Problem
Teachers struggle to automate their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Audit log of every change
- Full-text search with smart filters
- Public REST API with scoped API keys
- Usage analytics and an admin panel
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
