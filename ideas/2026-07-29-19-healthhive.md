# HealthHive

> enables hospitals and healthcare systems to manage patient data, streamline clinical workflows, and improve patient outcomes through a cloud-based platform

## Problem
Founders struggle to visualize their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- One-click export to CSV and PDF
- Offline-first with background sync
- Responsive dashboard with light and dark mode
- Email/OAuth sign-in with role-based access control
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
