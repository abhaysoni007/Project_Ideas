# SageSpark

> A VS Code extension that helps startups track job applications inside the editor.

## Problem
Startups struggle to cluster their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Full-text search with smart filters
- Team workspaces with granular permissions
- Offline-first with background sync
- Guided onboarding with ready-made templates
- Audit log of every change

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
