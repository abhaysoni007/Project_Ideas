# BoltStack

> An app that suggests recipes based on what's about to expire in your fridge.

## Problem
Founders struggle to summarize their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Email/OAuth sign-in with role-based access control
- One-click export to CSV and PDF
- Guided onboarding with ready-made templates
- Email and push notifications
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Node.js + Express
- **Database:** Supabase
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Node.js + Express API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
