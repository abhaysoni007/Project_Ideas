# ForgeBloom

> A weekly-digest service that detects job applications and emails teachers a summary.

## Problem
Remote workers struggle to detect their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Integrations with Slack, Google, and Stripe
- Real-time updates over WebSockets
- Email/OAuth sign-in with role-based access control
- AI-assisted recommendations and summaries
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
