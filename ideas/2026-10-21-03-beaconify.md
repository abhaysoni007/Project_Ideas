# Beaconify  
> Apply Smarter, Sustain the Planet  

## Problem  
Finding and applying for sustainability roles is time‑consuming and fragmented across multiple job boards and company portals. Candidates often waste hours tailoring resumes, while recruiters face a flood of generic applications.  

## Target Users  
- Sustainability professionals seeking new roles  
- HR recruiters in green tech companies  
- Career coaches focusing on eco‑industry  

## Key Features  
- Scrape job listings from 10+ sustainability boards and company career pages  
- Auto‑populate application forms using a single master CV template  
- AI‑powered cover letter generator tailored to each job description  
- Batch application scheduling with real‑time status tracking  
- Notifications of status updates via email or Slack  
- Analytics dashboard for application success rates and time‑to‑interview  
- Optional integration with LinkedIn and GitHub for profile data  

## Tech Stack  
- **Frontend**: Command‑line interface built with Python 3.12 and Click, enhanced with Rich for pretty terminal output  
- **Backend**: Python services orchestrated by FastAPI (for optional webhooks), leveraging asyncio for concurrency  
- **Database**: SQLite for local persistence of job data, application history, and user preferences  
- **Infra/DevOps**: Docker for reproducible builds, GitHub Actions for CI/CD, PyPI for distribution, and semantic‑versioned releases  
- **AI/ML**: OpenAI GPT‑4 via LangChain for cover letters, spaCy for NLP parsing of resumes and job posts, and a lightweight vector store (FAISS) for semantic similarity search  

## Architecture  
Beaconify follows a modular, service‑oriented architecture. The CLI orchestrates data ingestion modules that scrape or consume job board APIs, a resume and job‑description parser that feeds the AI service layer, and a persistence layer that stores all application state in SQLite. AI content generation is handled by LangChain, which abstracts calls to OpenAI’s GPT‑4 model, and results are returned to the CLI for user review and submission. All components communicate over lightweight HTTP or direct function calls, ensuring low latency and easy extensibility.  

## Roadmap  
- **v1** – Core scraping engine, auto‑fill for three major sustainability boards, local SQLite storage  
- **v2** – AI‑driven cover letter generator, analytics dashboard, batch scheduling, email/Slack notifications  
- **v3** – Enterprise‑grade integrations (LinkedIn, GitHub, ATS APIs), plugin ecosystem, and web UI preview mode
