# PlayPulse  
> **Data‑driven playbooks for indie game success**

## Problem  
Indie devs lack a single, actionable view of how players engage and monetize. Without real‑time dashboards, teams iterate on guesswork, missing revenue opportunities and critical player pain points.

## Target Users  
- Indie game designers & product owners  
- Small studio analytics teams  
- Community managers & marketing leads  
- Monetization strategists  
- Data‑first founders

## Key Features  
- Live engagement heatmaps and funnel analytics  
- In‑app revenue, ARPDAU, and lifetime value dashboards  
- Real‑time cohort segmentation & push‑notification triggers  
- Custom alerting for spikes, dips, and revenue thresholds  
- Automated data pipelines from Unity/Unreal SDKs  
- Exportable reports (PDF, CSV) & API access  
- One‑click insights powered by ML‑based trend detection

## Tech Stack  
**Frontend**  
- React 18 + Next.js  
- TypeScript  
- Tailwind CSS  
- Recharts / D3 for visualizations  

**Backend**  
- NestJS (Node.js, TypeScript)  
- GraphQL (Apollo) for flexible queries  

**Database**  
- PostgreSQL 15 (primary relational store)  
- TimescaleDB extension for time‑series analytics  

**Infra/DevOps**  
- Docker + Docker Compose (local)  
- Kubernetes on AWS EKS  
- Terraform for IaC  
- GitHub Actions CI/CD  
- Prometheus + Grafana for monitoring  

**AI/ML**  
- Python 3.11 microservice using FastAPI  
- Scikit‑learn & Prophet for churn & revenue forecasts  
- Optional SageMaker endpoint for advanced models  

## Architecture  
PlayPulse follows a modular micro‑service architecture. An **Ingestion Service** collects event streams from game SDKs via a secure REST gateway, normalizes data, and writes to a Kafka topic. The **Analytics Service** consumes Kafka, aggregates metrics into TimescaleDB, and exposes a GraphQL API. The **Dashboard Service** (Next.js) queries the API to render interactive visualizations, while the **ML Service** periodically trains predictive models and surfaces insights through the API. All services run in containers orchestrated by Kubernetes on EKS, with Terraform provisioning the cluster and networking. Continuous integration pipelines build, test, and deploy each service via GitHub Actions, ensuring rapid feature delivery.

## Roadmap  
- **v1** – Core dashboard, real‑time engagement & monetization metrics, basic SDK integration, and self‑hosted deployment.  
- **v2** – Cohort analysis, custom alerting, ML‑driven trend detection, and exportable reports.  
- **v3** – Marketplace integration, API gateway for third‑party tools, multi‑tenant SaaS offering, and automated data warehouse provisioning.
