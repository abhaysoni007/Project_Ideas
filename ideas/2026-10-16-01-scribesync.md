# ScribeSync
> **“Turn paper piles into collaborative knowledge maps, powered by AI.”**

## Problem (2-3 sentences)
Academic teams waste hours manually collecting, summarizing, and citing literature. Current tools fragment tasks—citation managers, search engines, and note apps—making collaboration slow and error‑prone. Researchers need a unified platform that automates review workflows and guarantees citation accuracy.

## Target Users (bulleted)
- Professors coordinating multi‑author research projects  
- Graduate students conducting systematic literature reviews  
- Research groups in interdisciplinary labs  
- Librarians and research coordinators managing institutional knowledge bases  

## Key Features (5-7 bullets)
- **Smart literature ingestion**: batch PDF upload, DOI lookup, and automatic metadata extraction.  
- **AI‑summarization & keyword extraction** for each paper, with editable summaries.  
- **Real‑time collaborative annotations** and discussion threads per document.  
- **Citation generation** in multiple styles (APA, Chicago, IEEE) with instant Crossref validation.  
- **Dynamic knowledge graph** visualizing paper relationships, topics, and citation networks.  
- **Version control & change tracking** for review drafts and annotations.  
- **API & Zotero integration** for seamless import/export and workflow automation.

## Tech Stack
- **Frontend**: React 18 + TypeScript, Vite, TanStack Query, Tailwind CSS, Recharts for graphing.  
- **Backend**: Node.js 20 + NestJS, TypeScript, GraphQL, Apollo Server.  
- **Database**: PostgreSQL 15 (relational), Redis 7 (caching), Pinecone (vector store for embeddings).  
- **Infra/DevOps**: Docker, Kubernetes (EKS), Helm charts, GitHub Actions CI/CD, Terraform for IaC.  
- **AI/ML**: OpenAI GPT‑4 for summarization, embeddings via OpenAI or Cohere, Claude 3 for alternative inference, LangChain for orchestration, Crossref API for citation validation.  

## Architecture (a short paragraph)
ScribeSync follows a micro‑service architecture: the front‑end communicates with a NestJS GraphQL gateway that orchestrates services for document ingestion, AI processing, and collaboration. PDFs are stored in an S3 bucket, metadata in PostgreSQL, and embeddings in Pinecone. Redis caches frequent queries, while a background job queue (BullMQ) handles long‑running summarization tasks. The AI services are containerized and deployed on EKS, with autoscaling based on request volume. Continuous integration pipelines deploy to a staging environment for automated testing before merging to production.

## Roadmap (v1, v2, v3 bullets)
- **v1 – Core Review Platform**: PDF ingestion, metadata extraction, basic AI summarization, citation generator, real‑time annotations, basic knowledge graph, and basic CI/CD.  
- **v2 – Advanced Collaboration & Analytics**: Versioned document editing, full knowledge‑graph analytics, export to LaTeX/BibTeX, OAuth2 SSO with institutional providers, and performance optimizations.  
- **v3 – Enterprise & AI Ops**: Role‑based access control, audit logging, AI‑driven search suggestions, integration with institutional repositories, and a marketplace for plug‑in extensions.
