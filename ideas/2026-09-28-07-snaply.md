# Snaply

> A tool that scans your GitHub repos and auto-generates a portfolio site from your top projects.

## Problem
Gamers struggle to summarize their workout plans without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- One-click export to CSV and PDF
- Email and push notifications
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** SvelteKit
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A SvelteKit client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
