# LumenHub

> A tool that audits a website's Core Web Vitals and suggests concrete fixes.

## Problem
Students struggle to audit their sensor data without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Public REST API with scoped API keys
- Usage analytics and an admin panel
- Responsive dashboard with light and dark mode
- Full-text search with smart filters
- AI-assisted recommendations and summaries

## Tech Stack
- **Frontend:** React Native
- **Backend:** Node.js + Express
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Node.js + Express API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
