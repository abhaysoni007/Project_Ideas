# VaultBase
> Know your cloud spend, instantly.

## Problem
Small teams often lack clear visibility into their cloud expenditures, forcing them to manually scrape billing dashboards or write custom scripts. This leads to delayed insights, costly surprises, and wasted engineering effort. A no‑code solution that surfaces costs in real time would save time and prevent budget overruns.

## Target Users
- Small dev teams (≤10 people) looking for cost transparency  
- Startup product managers who need quick budget insights  
- DevOps and SRE leads responsible for cloud cost control  
- Cloud cost analysts in mid‑sized organizations  
- Finance officers seeking simplified spend reports

## Key Features
- Drag‑and‑drop cost query builder with pre‑defined templates  
- Real‑time cost dashboards and visual analytics  
- Automated alerts for cost thresholds and anomalies  
- Native integrations with AWS, Azure, GCP, and OCI  
- Multi‑cloud cost aggregation and reconciliation  
- Exportable reports (CSV, PDF, PowerPoint)  
- Role‑based access control and audit logs

## Tech Stack
- **Frontend**  
  - React (TypeScript, Vite)  
  - Tailwind CSS for rapid UI styling  
  - Apollo Client for GraphQL queries  
- **Backend**  
  - Node.js with NestJS framework  
  - GraphQL API layer (Apollo Server)  
  - Prisma ORM for database interactions  
- **Database**  
  - PostgreSQL (managed via Fly.io or AWS RDS)  
- **Infra/DevOps**  
  - Docker containers, orchestrated on Kubernetes (EKS)  
  - Terraform for IaC and multi‑cloud provisioning  
  - GitHub Actions CI/CD pipeline  
  - Prometheus + Grafana for monitoring  
- **AI/ML** (optional)  
  - Python microservice (FastAPI) for cost forecasting  
  - Scikit‑learn / TensorFlow for anomaly detection  

## Architecture
VaultBase exposes a single‑page React application that communicates with a GraphQL API built on NestJS. The API aggregates cost data from cloud provider SDKs (AWS Cost Explorer, Azure Cost Management, GCP Billing API) through scheduled serverless functions, stores raw metrics in PostgreSQL, and caches computed aggregates in Redis. Dashboards retrieve pre‑aggregated data via GraphQL, while alerts are triggered by a scheduled job that compares current spend against user‑defined thresholds. The entire stack is containerized, deployed to a managed Kubernetes cluster, and provisioned with Terraform for repeatable, multi‑cloud infrastructure.

## Roadmap
- **v1** – Core UI, single‑cloud cost ingestion, real‑time dashboards, basic alerting  
- **v2** – Multi‑cloud support, role‑based permissions, AI‑powered cost forecasting, exportable reports  
- **v3** – Plugin ecosystem, automation rules (e.g., auto‑shutdown of idle resources), marketplace integration, advanced reporting and budgeting tools
