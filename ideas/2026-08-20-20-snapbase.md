# SnapBase

> A dashboard that turns raw energy usage into actionable robotics insights.

## Problem
Developers struggle to summarize their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Developers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Team workspaces with granular permissions
- Integrations with Slack, Google, and Stripe
- Guided onboarding with ready-made templates
- Audit log of every change
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Next.js
- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a FastAPI (Python) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
