# HiveHub

> Facilitates collaboration and project management among remote teams by integrating communication, task assignment, and time tracking tools

## Problem
Open-source maintainers struggle to visualize their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Guided onboarding with ready-made templates
- Email and push notifications
- Usage analytics and an admin panel
- AI-assisted recommendations and summaries
- Public REST API with scoped API keys
- Offline-first with background sync

## Tech Stack
- **Frontend:** React Native
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
