# QuillBoost

> A self-hosted tool that lets founders cluster podcast highlights with full data privacy.

## Problem
Small teams struggle to track their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Small teams
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- Audit log of every change
- Team workspaces with granular permissions
- One-click export to CSV and PDF
- Full-text search with smart filters
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
