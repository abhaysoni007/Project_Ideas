# CueHub

> helps event planners and organizers manage their operations and logistics through a comprehensive platform for venue sourcing and event management.

## Problem
Startups struggle to benchmark their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Email and push notifications
- One-click export to CSV and PDF
- Team workspaces with granular permissions
- Guided onboarding with ready-made templates
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
