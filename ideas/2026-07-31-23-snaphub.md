# SnapHub

> An API service that lets developers add recipes to any robotics product.

## Problem
Gamers struggle to optimize their podcast highlights without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Public REST API with scoped API keys
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Usage analytics and an admin panel
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
