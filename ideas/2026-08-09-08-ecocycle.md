# EcoCycle

> assists businesses in reducing waste and improving sustainability by providing data-driven insights and recommendations on recycling and resource management

## Problem
Designers struggle to track their job applications without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Email and push notifications
- Responsive dashboard with light and dark mode
- Integrations with Slack, Google, and Stripe
- Email/OAuth sign-in with role-based access control
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Go (Gin)
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Go (Gin) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
