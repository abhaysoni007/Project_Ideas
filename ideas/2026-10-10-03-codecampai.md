# CodeCampAI
> Build micro‑courses from interviews in seconds.

## Problem  
Early‑career developers struggle to turn dense interview content into bite‑size, interactive lessons.  
Creating quality micro‑courses manually is time‑consuming and error‑prone, leaving bootcamps and recruiters with limited, static resources.

## Target Users  
- Junior developers seeking interview prep  
- Bootcamp instructors needing ready‑made material  
- Recruiters wanting interactive training modules  
- Career‑coaching platforms looking to add AI‑powered content

## Key Features  
- AI‑driven summarization of interview questions and answers  
- Interactive learning paths with branching quizzes  
- Real‑time progress tracking and skill dashboards  
- Community discussion forums tied to each micro‑course  
- Exportable micro‑course bundles (PDF, HTML, LMS‑ready)  
- Analytics dashboard for instructors and admins  
- API for integrating courses into existing LMSs

## Tech Stack  

**Frontend**  
- React 18 + TypeScript  
- Next.js 14 (SSR + SSG)  
- Tailwind CSS + Headless UI  
- Zustand for lightweight state management  

**Backend**  
- NestJS (Node.js, TypeScript)  
- GraphQL (Apollo Server)  
- JWT + OAuth2 for auth  

**Database**  
- PostgreSQL 16 (primary relational store)  
- Redis 7 (caching & pub/sub)  

**Infra/DevOps**  
- Docker Compose + Kubernetes (EKS)  
- Terraform for IaC on AWS  
- GitHub Actions CI/CD pipeline  
- CloudWatch + Prometheus + Grafana for monitoring  

**AI/ML**  
- OpenAI GPT‑4 Turbo for summarization & generation  
- LangChain (Node.js) for prompt orchestration  
- Pinecone for vector embeddings & semantic search  
- RAG pipeline for dynamic Q&A retrieval  

## Architecture  
CodeCampAI follows a modular micro‑service architecture. The core GraphQL API orchestrates requests to the AI service layer, which in turn calls OpenAI via LangChain, stores embeddings in Pinecone, and writes results to PostgreSQL. The frontend is a statically‑served Next.js app that consumes the GraphQL API, while background workers (NestJS workers) handle long‑running AI jobs. All services are containerized, deployed to EKS, and managed with Terraform, ensuring scalability and resilience.
