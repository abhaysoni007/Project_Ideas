# OrbitPath

> An AI-free rule-based linter for accessibility issues in HTML emails.

## Problem
Students struggle to track their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Students
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Full-text search with smart filters
- One-click export to CSV and PDF
- Email/OAuth sign-in with role-based access control
- Team workspaces with granular permissions
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
