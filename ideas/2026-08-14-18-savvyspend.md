# SavvySpend

> helps individuals and families manage their finances and make smarter purchasing decisions through a budgeting and expense tracking app

## Problem
Creators struggle to translate their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Creators
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Audit log of every change
- Email and push notifications
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- One-click export to CSV and PDF

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** Supabase
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
