# QuillBase

> A CLI tool that automates reading lists in agriculture workflows.

## Problem
Founders struggle to audit their cloud costs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Founders
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Usage analytics and an admin panel
- Email/OAuth sign-in with role-based access control
- Email and push notifications
- Integrations with Slack, Google, and Stripe
- Offline-first with background sync
- Audit log of every change

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
