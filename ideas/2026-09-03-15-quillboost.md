# QuillBoost

> A browser extension that helps developers automate workout plans while they browse.

## Problem
Gamers struggle to audit their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Usage analytics and an admin panel
- Email and push notifications
- Guided onboarding with ready-made templates
- One-click export to CSV and PDF
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Flutter
- **Backend:** Node.js + Express
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a Node.js + Express API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
