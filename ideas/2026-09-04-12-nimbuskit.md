# NimbusKit

> A browser extension that shows the carbon footprint of each website you visit.

## Problem
Parents struggle to detect their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- One-click export to CSV and PDF
- Full-text search with smart filters
- Offline-first with background sync
- Public REST API with scoped API keys
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** React
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
