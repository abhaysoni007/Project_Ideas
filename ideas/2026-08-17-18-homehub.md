# HomeHub

> helps homeowners manage their property maintenance, repair, and renovation projects through a mobile app that connects them with local contractors and service providers.

## Problem
Gamers struggle to audit their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Email and push notifications
- Guided onboarding with ready-made templates
- Public REST API with scoped API keys
- Full-text search with smart filters
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** MySQL
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
