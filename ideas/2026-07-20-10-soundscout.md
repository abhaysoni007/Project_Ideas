# SoundScout

> provides an immersive audio description platform for blind and low-vision individuals to enhance their experience of movies, TV shows, and live events with interactive audio commentary.

## Problem
Small teams struggle to detect their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Small teams
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- Responsive dashboard with light and dark mode
- Team workspaces with granular permissions
- Full-text search with smart filters
- Email and push notifications
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** React
- **Backend:** Django
- **Database:** MySQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React client talks to a Django API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
