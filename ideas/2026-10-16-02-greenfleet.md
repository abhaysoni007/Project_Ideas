# GreenFleet
> Zero‑Emissions Last‑Mile Delivery for Urban Retail

## Problem
Urban logistics suffer from traffic congestion, high emissions, and delivery delays. Traditional truck fleets struggle to navigate narrow streets, causing costly idle times and limited capacity for high‑frequency e‑commerce deliveries.

## Target Users
- E‑commerce platforms seeking fast, eco‑friendly fulfillment in city centers  
- Grocery chains needing reliable same‑day delivery to densely populated neighborhoods  
- Urban logistics managers looking to reduce carbon footprints and operational costs

## Key Features
- Autonomous electric cargo drones with up to 25 kg payload  
- Real‑time flight planning and dynamic rerouting to avoid traffic and no‑fly zones  
- Secure, tamper‑evident delivery lockers integrated with retail checkout systems  
- Predictive maintenance powered by on‑board sensor analytics  
- API‑first interface for retailer order integration and real‑time tracking  
- Regulatory compliance module for airspace permissions and safety certification  
- Dashboard for fleet status, energy consumption, and delivery metrics

## Tech Stack
- **Frontend:** React + TypeScript + Tailwind CSS  
- **Backend:** NestJS (Node.js) + TypeScript  
- **Database:** PostgreSQL + TimescaleDB for time‑series flight data  
- **Infra/DevOps:** Docker, Kubernetes (EKS), Terraform, GitHub Actions, Prometheus/Grafana, AWS S3 for object storage  
- **AI/ML:** Python + PyTorch for path optimization, OpenCV for obstacle detection, TensorFlow Lite on drones for edge inference  

## Architecture
GreenFleet comprises a cloud‑based fleet management service that orchestrates a swarm of autonomous electric cargo drones. The service exposes REST/GraphQL APIs for retailer order ingestion, which are translated into flight missions using a real‑time scheduler. Drones run edge‑AI inference for obstacle avoidance and use secure communication (TLS 1.3, MQTT) to relay telemetry to the cloud. All flight data is stored in a hybrid PostgreSQL/TimescaleDB cluster for analytics, while Docker/Kubernetes manages microservices for scheduling, billing, and monitoring. Terraform scripts provision a highly available AWS infrastructure, and GitHub Actions automate CI/CD pipelines.

## Roadmap
- **v1:** Prototype drone platform, API integration with a pilot retailer, pilot delivery routes, regulatory clearance in a single city zone.  
- **v2:** Expand fleet to 100 drones, introduce AI‑based path planning, add locker integration, and launch a merchant dashboard.  
- **v3:** Scale to multiple metropolitan areas, implement predictive maintenance, open the API to third‑party logistics partners, and achieve ISO 14001 environmental certification.
