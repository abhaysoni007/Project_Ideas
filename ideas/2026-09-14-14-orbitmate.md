# OrbitMate

> A browser extension that helps developers summarize sensor data while they browse.

## Problem
Open-source maintainers struggle to detect their recipes without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Audit log of every change
- Email/OAuth sign-in with role-based access control
- Team workspaces with granular permissions
- Full-text search with smart filters
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Flutter
- **Backend:** FastAPI (Python)
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a FastAPI (Python) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
