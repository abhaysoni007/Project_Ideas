# Spectra

> creates a digital platform for artists, designers, and creatives to showcase and sell their work, using blockchain technology and social media marketing.

## Problem
Remote workers struggle to cluster their invoices without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Remote workers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Offline-first with background sync
- One-click export to CSV and PDF
- Usage analytics and an admin panel
- Full-text search with smart filters
- Guided onboarding with ready-made templates
- Email and push notifications

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Django
- **Database:** Supabase
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Django API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
