# MicroBond
> “Invest your spare change in a smarter way”

## Problem (2-3 sentences)
Many novices find investing intimidating and time‑consuming, yet they often have small, unused funds from everyday purchases. Without a simple, automatic mechanism to pool these funds, they miss out on steady, low‑risk growth opportunities.

## Target Users (bulleted)
- 18–35 year‑old tech‑savvy individuals new to investing  
- Budget‑conscious users who want to grow savings without active management  
- Mobile‑first users preferring a frictionless banking experience  
- People interested in socially responsible, low‑risk municipal bond exposure  

## Key Features (5-7 bullets)
- **Automatic round‑up**: rounds every card transaction up to the nearest dollar and transfers the spare change to a bond portfolio.  
- **Diversified municipal bond basket**: pre‑selected, risk‑balanced U.S. municipal bonds with low default risk.  
- **Tax‑advantaged account options**: Rollover into IRA or Roth IRA with automated contribution limits.  
- **Real‑time portfolio monitoring**: live bond yields, maturity dates, and reinvestment options.  
- **Push notifications**: transaction confirmations, portfolio updates, and educational tips.  
- **Secure API‑first architecture**: PCI‑DSS compliant card handling, two‑factor authentication, and role‑based access.  
- **Analytics dashboard**: visualize growth, compare against benchmarks, and track ESG metrics.  

## Tech Stack (bullets grouped as Frontend, Backend, Database, Infra/DevOps, and AI/ML if relevant)
- **Frontend**  
  - React Native (iOS & Android)  
  - Redux Toolkit for state management  
  - Styled‑Components for theming  
- **Backend**  
  - Node.js (Express) with TypeScript  
  - Auth0 for authentication & authorization  
  - Stripe Connect for card tokenization & payment processing  
- **Database**  
  - PostgreSQL (primary data)  
  - Redis (caching, rate‑limit)  
- **Infra/DevOps**  
  - Docker & Docker Compose for local dev  
  - AWS ECS Fargate for container orchestration  
  - Terraform for IaC  
  - GitHub Actions CI/CD pipelines  
  - CloudWatch & Datadog for monitoring & alerts  
- **AI/ML** (optional, future)  
  - Python (FastAPI) for ML model serving (e.g., bond risk scoring)  
  - SageMaker for model training pipelines  

## Architecture (a short paragraph)
MicroBond follows a micro‑service architecture with a mobile front‑end communicating over REST/GraphQL to stateless Node.js services. The core “Round‑Up Engine” processes inbound payment events, calculates spare change, and updates user portfolios stored in PostgreSQL. Bond data is ingested from a secure external feed (e.g., Bloomberg) and cached in Redis. All services are containerized and deployed to AWS ECS Fargate, with Terraform managing the infrastructure. Security is enforced through Auth0 JWT tokens and PCI‑DSS compliant Stripe Connect for card handling.

## Roadmap (v1, v2, v3 bullets)
- **v1** – Core round‑up logic, municipal bond basket, mobile app MVP, secure card onboarding, and basic portfolio dashboard.  
- **v2** – Tax‑advantaged account integration (IRA/Roth IRA), automated reinvestment, push notifications, and analytics dashboard.  
- **v3** – AI‑driven bond recommendation engine, multi‑currency support, web portal, and expanded ESG reporting.
