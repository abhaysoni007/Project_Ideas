# SoundScout
> Empowering visually impaired individuals to navigate their surroundings with ease and confidence
## Problem 
The lack of accessible navigation systems hinders visually impaired individuals from fully exploring and interacting with their environment, leading to feelings of isolation and dependence on others. Current solutions often rely on limited audio cues or require extensive training to use. This results in a significant barrier to independent mobility and social participation.
## Target Users 
* Visually impaired individuals with varying degrees of vision loss
* Individuals with multiple disabilities, including visual and hearing impairments
* Caregivers and assistants supporting visually impaired individuals
## Key Features 
* 3D audio mapping and navigation
* Real-time object detection and labeling
* Customizable audio cues and alerts
* Integration with popular smart home devices
* User-friendly interface for easy navigation and settings adjustment
* Community-sharing features for user-generated audio maps
## Tech Stack 
* Frontend: 
  + React Native for cross-platform mobile app development
  + Expo for streamlined development and deployment
* Backend: 
  + Node.js with Express.js for server-side logic and API management
  + GraphQL for efficient data querying and mutation
* Database: 
  + PostgreSQL for storing user data, audio maps, and object labels
  + Redis for caching and optimizing data retrieval
* Infra/DevOps: 
  + AWS for scalable infrastructure and services
  + Docker for containerization and deployment
* AI/ML: 
  + TensorFlow for object detection and machine learning tasks
  + Google Cloud Vision API for image recognition and labeling
## Architecture 
The SoundScout system consists of a mobile application, a backend server, and a database. The mobile app utilizes React Native and Expo to provide a seamless user experience, while the backend server handles API requests, data storage, and machine learning tasks using Node.js, Express.js, and TensorFlow. The database stores user data, audio maps, and object labels, and is optimized for performance using Redis caching.
