# ForgeSpark

> A self-hosted tool that lets startups cluster code reviews with full data privacy.

## Problem
Designers struggle to translate their code reviews without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Offline-first with background sync
- Usage analytics and an admin panel
- Responsive dashboard with light and dark mode
- Real-time updates over WebSockets
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** Supabase
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
