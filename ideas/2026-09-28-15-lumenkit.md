# LumenKit

> A local-first note app where every note is a git commit you can diff over time.

## Problem
Researchers struggle to cluster their customer feedback without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Researchers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Responsive dashboard with light and dark mode
- Public REST API with scoped API keys
- Guided onboarding with ready-made templates
- Team workspaces with granular permissions
- Real-time updates over WebSockets
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** React
- **Backend:** Django
- **Database:** PostgreSQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React client talks to a Django API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
