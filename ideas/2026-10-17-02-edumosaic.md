# EduMosaic
> Learn, Connect, Master

## Problem (2-3 sentences)
Students often struggle to find personalized, bite‑size learning resources that match their preferred learning styles and schedules.  
Mentors and peer tutors are difficult to locate and engage with, leading to gaps in support and motivation.  
Existing marketplaces lack adaptive recommendation systems that continuously refine content based on performance and feedback.

## Target Users (bulleted)
- High‑school and college students seeking supplemental learning.  
- Lifelong learners and professionals looking for skill‑upgrading micro‑tutorials.  
- Peer mentors and tutors wanting flexible, structured engagement.  
- Educational institutions aiming to augment classroom instruction with micro‑learning.

## Key Features (5-7 bullets)
- Adaptive micro‑tutorial recommendation engine that tailors content to learning style and progress.  
- Real‑time mentor pairing and chat with video support.  
- Gamified progress tracking and badge system to boost motivation.  
- Community forums and peer review for collaborative learning.  
- Performance analytics dashboard for students and mentors.  
- Seamless integration with LMS and calendar apps for scheduling.  
- AI‑powered auto‑summaries and question generation for rapid revision.

## Tech Stack (bullets grouped as Frontend, Backend, Database, Infra/DevOps, and AI/ML if relevant)
- **Frontend**  
  - React 18 with Next.js (SSR/SSG)  
  - TypeScript, Tailwind CSS, Zustand for state management  
  - Chakra‑UI for accessible components  
- **Backend**  
  - Node.js 20, NestJS framework  
  - GraphQL (Apollo Server) for API, REST fallback for legacy services  
  - WebSocket (Socket.IO) for real‑time mentor chat  
- **Database**  
  - PostgreSQL 15 (relational data)  
  - Redis 7 (caching, pub/sub, session store)  
  - Supabase (auth, storage, edge functions)  
- **Infra/DevOps**  
  - Docker, Docker‑Compose for local dev, k8s for production  
  - AWS (EKS, RDS, S3, CloudFront, Route 53)  
  - GitHub Actions for CI/CD, automated linting, unit tests, image scanning  
  - Terraform for IaC, GitOps for cluster management  
- **AI/ML**  
  - OpenAI GPT‑4 for content summarization, question generation, and adaptive recommendations  
  - TensorFlow Lite models for on‑device skill assessment (optional mobile SDK)  
  - Data‑pipeline with Apache Airflow for model retraining and feature engineering  

## Architecture (a short paragraph)
EduMosaic employs a modular micro‑services architecture with an API gateway (NGINX) routing GraphQL and WebSocket traffic to the NestJS backend.  
The recommendation service runs as a separate container, ingesting student performance and content metadata from PostgreSQL, and exposes an inference endpoint powered by a fine‑tuned GPT‑4 model.  
Real‑time mentor chat is handled via Socket.IO on a dedicated Redis pub/sub layer, ensuring low‑latency communication.  
All services are containerized and orchestrated on AWS EKS, with automated scaling based on CPU and request metrics.  
Data is persisted in a managed PostgreSQL cluster, while caching and session state live in Redis; media assets reside in S3 buckets served through CloudFront for global CDN delivery.

## Roadmap (v1, v2, v3 bullets)
- **v1** – MVP: Core adaptive tutorial recommendation, mentor pairing UI, basic analytics dashboard, and basic authentication.  
- **v2** – Gamification layer (badges, streaks), real‑time video chat, community forums, and AI‑powered auto‑summary of tutorials.  
- **v3** – Advanced AI recommendation engine with continuous learning, multi‑language support, LMS integration, and mobile app (React Native) with offline capabilities.
