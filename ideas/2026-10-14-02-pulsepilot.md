# PulsePilot
> Generate test data in a single command, instantly.

## Problem
Developers and QA teams often spend hours writing scripts to seed databases with realistic data.  
Existing solutions are either too generic, lack schema awareness, or require complex setup.

## Target Users
- Backend developers needing quick test data
- QA engineers preparing test environments
- DevOps engineers automating CI/CD pipelines
- Data engineers prototyping data models
- Product owners validating feature demos

## Key Features
- One‑command generation with `pulsepilot generate <schema>`
- Automatic schema introspection for PostgreSQL, MySQL, and SQLite
- Customizable data distributions (uniform, normal, custom JSON)
- Built‑in data masking for sensitive fields
- Multiple export formats: SQL, CSV, JSON, XML
- Parallel generation engine for large tables
- Extensible plug‑in system for custom generators

## Tech Stack
- **Frontend**: Vue.js 3 with Vite, Tailwind CSS
- **Backend**: Go 1.22 with Gin framework
- **Database**: PostgreSQL 15 (primary), MySQL 8 (secondary support)
- **Infra/DevOps**: Docker Compose, GitHub Actions CI, Terraform for AWS RDS
- **AI/ML**: Optional GPT‑4 prompt module for natural‑language data generation

## Architecture
PulsePilot follows a micro‑service style with a thin CLI front‑end that communicates with a Go‑based engine. The engine performs schema introspection via the database driver, then orchestrates data generators (built‑in or AI‑powered) to produce rows in parallel. Generated data is streamed to the chosen output format and can be piped directly into migrations or database seed scripts.

## Roadmap
- **v1**: Core CLI, schema introspection, basic generator, SQL/CSV export
- **v2**: Data masking, AI‑powered natural language generation, Docker container, CI/CD integration
- **v3**: Web UI dashboard, plug‑in architecture, multi‑database support, performance benchmarking tools
