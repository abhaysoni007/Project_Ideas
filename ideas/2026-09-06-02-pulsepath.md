# PulsePath

> A VS Code extension that helps freelancers organize podcast highlights inside the editor.

## Problem
Designers struggle to track their workout plans without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email/OAuth sign-in with role-based access control
- Public REST API with scoped API keys
- Responsive dashboard with light and dark mode
- Audit log of every change
- Guided onboarding with ready-made templates
- Email and push notifications

## Tech Stack
- **Frontend:** React
- **Backend:** Go (Gin)
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a Go (Gin) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
