# QuillBoost

> A VS Code extension that helps remote workers recommend news feeds inside the editor.

## Problem
Gamers struggle to personalize their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Public REST API with scoped API keys
- Email and push notifications
- Team workspaces with granular permissions
- One-click export to CSV and PDF
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Go (Gin)
- **Database:** SQLite
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Go (Gin) API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
