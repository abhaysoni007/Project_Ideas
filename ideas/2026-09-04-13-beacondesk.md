# BeaconDesk

> A tool that maps your codebase into an interactive dependency graph.

## Problem
Startups struggle to audit their API logs without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Responsive dashboard with light and dark mode
- Offline-first with background sync
- Real-time updates over WebSockets
- Team workspaces with granular permissions
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** Vue 3
- **Backend:** Go (Gin)
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Vue 3 client talks to a Go (Gin) API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
