# VaultBloom

> A service that turns your bank statements into a plain-English monthly spending story.

## Problem
Researchers struggle to detect their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Researchers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- One-click export to CSV and PDF
- Email and push notifications
- Full-text search with smart filters
- Public REST API with scoped API keys
- Email/OAuth sign-in with role-based access control

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
