# EchoSpark

> A CLI that detects unused dependencies across a monorepo and opens cleanup PRs.

## Problem
Startups struggle to translate their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- Audit log of every change
- Integrations with Slack, Google, and Stripe
- Guided onboarding with ready-made templates
- Full-text search with smart filters
- Responsive dashboard with light and dark mode

## Tech Stack
- **Frontend:** Flutter
- **Backend:** NestJS
- **Database:** SQLite
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Flutter client talks to a NestJS API over REST. Data lives in SQLite. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap

- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
