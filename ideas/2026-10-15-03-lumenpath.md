# LumenPath
> The API that turns creator‑product feedback into actionable data.

## Problem
Creators and marketplaces struggle to collect, standardize, and act on user feedback from disparate channels (in‑app, social, email). Without a unified view, insights are lost and product iterations are slow.

## Target Users
- Indie developers building creator‑centric platforms  
- Subscription‑based content creators needing real‑time sentiment data  
- Growth & product teams at creator economy startups  
- Analytics teams looking to enrich dashboards with raw feedback streams  

## Key Features
- **Universal Feedback Ingestion** – REST and Webhook endpoints for text, images, and emoji feedback.  
- **Schema‑free storage** – Preserve raw payloads while auto‑generating a typed schema on demand.  
- **Real‑time Sentiment & Category Analysis** – Powered by OpenAI embeddings and custom classifiers.  
- **Contextual Tagging & Prioritization** – Auto‑tag by topic, urgency, and creator role.  
- **Webhook & SDKs for downstream systems** – Send enriched feedback to Slack, HubSpot, or a custom dashboard.  
- **Rate limiting & retry logic** – Ensure reliable delivery even under peak traffic.  
- **Audit Trail & GDPR compliance** – Full request/response logging with data‑retention controls.  

## Tech Stack
- **Frontend**:  
  - React (Next.js) for the admin console and documentation portal  
  - Tailwind CSS for rapid UI styling  
- **Backend**:  
  - Node.js (TypeScript) with Express and NestJS for modular API design  
  - OpenAPI (Swagger) for self‑documenting endpoints  
- **Database**:  
  - PostgreSQL (primary relational store)  
  - TimescaleDB extension for time‑series analytics  
  - Redis for caching and rate‑limit state  
- **Infra/DevOps**:  
  - Docker & Docker Compose for local dev  
  - Kubernetes on GKE for production scaling  
  - Helm charts for reproducible deployments  
  - GitHub Actions for CI/CD, automated testing, and image building  
  - Terraform for IaC (VPC, IAM, GCS buckets)  
- **AI/ML**:  
  - OpenAI GPT‑4 for sentiment & topic extraction  
  - Custom TensorFlow model (TensorFlow.js in Node) for image-based feedback classification  
  - Azure Cognitive Services for optional OCR on image uploads  

## Architecture
LumenPath follows a micro‑service pattern where the **Feedback Ingestion Service** receives HTTP/Webhook calls, validates payloads, and persists them to PostgreSQL. A background worker (Node + BullMQ) pulls new records, runs OpenAI sentiment analysis, enriches the data with tags, and publishes the result to a Kafka topic. Downstream consumers (e.g., Slack notifier, analytics dashboards) subscribe to Kafka or expose a GraphQL endpoint for on‑demand queries. All services communicate over gRPC or REST within a VPC, and TLS termination is handled at the Ingress controller.  

## Roadmap
- **v1** – Core ingestion API, sentiment analysis, and a minimal web dashboard for viewing feedback.  
- **v2** – Webhook/SDK integrations, batch export to CSV/BigQuery, and GDPR data‑retention controls.  
- **v3** – Real‑time analytics pipeline, predictive churn scoring, and a fully‑fledged SaaS portal with billing.
