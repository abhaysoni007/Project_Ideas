# MintStack

> A dashboard that turns raw workout plans into actionable productivity insights.

## Problem
Gamers struggle to visualize their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Email/OAuth sign-in with role-based access control
- Team workspaces with granular permissions
- Responsive dashboard with light and dark mode
- Audit log of every change
- Email and push notifications

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
