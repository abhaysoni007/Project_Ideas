# Novaify

> A self-hosted tool that lets parents schedule cloud costs with full data privacy.

## Problem
Startups struggle to organize their screen time without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Integrations with Slack, Google, and Stripe
- Responsive dashboard with light and dark mode
- Full-text search with smart filters
- Team workspaces with granular permissions
- Public REST API with scoped API keys

## Tech Stack
- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a NestJS API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
