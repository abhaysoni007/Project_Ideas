# Quillify

> An app that converts long YouTube tutorials into step-by-step markdown notes.

## Problem
Open-source maintainers struggle to schedule their energy usage without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- AI-assisted recommendations and summaries
- Guided onboarding with ready-made templates
- Public REST API with scoped API keys
- Audit log of every change
- One-click export to CSV and PDF
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** MySQL
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
