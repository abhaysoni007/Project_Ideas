# IdeaHub  
> **“Turn long GitHub threads into instant insights.”**

## Problem  
GitHub issues and their comment threads often span dozens of pages, making it hard for contributors to quickly understand context and next steps. Manual reading is time‑consuming, especially for large repositories with rapid activity. This slows decision making and increases onboarding friction for new contributors.

## Target Users  
- Open‑source maintainers who need to triage large discussions  
- Project managers monitoring issue progress across teams  
- New contributors seeking a quick grasp of existing conversations  
- CI/CD pipelines that need to auto‑summarize PR discussions for alerts  
- Documentation writers who want concise issue summaries for changelogs

## Key Features  
- **Auto‑summary** of issue bodies and comment threads using contextual embeddings  
- **Real‑time updates** with WebSocket push when new comments arrive  
- **Contextual highlighting** of action items, blockers, and decisions  
- **Browser extension** that injects summaries directly into GitHub issue pages  
- **Exportable summaries** (Markdown, PDF, JSON) for external docs or notifications  
- **Customizable summarization depth** (short, medium, detailed)  
- **Language‑agnostic support** for English, Spanish, and French (extensible)

## Tech Stack  
- **Frontend**: React 18 + TypeScript, Tailwind CSS, Vite  
- **Browser Extension**: Manifest V3, WebExtension API, React hooks for content script  
- **Backend**: Node.js 20 + Express, TypeScript, OpenAI GPT‑4o API (or Claude) for summarization  
- **Database**: PostgreSQL 15 (PostGIS optional) for caching summaries, user prefs  
- **Infra/DevOps**: Docker Compose, GitHub Actions CI/CD, Fly.io or Render for hosting, Cloudflare Workers for edge caching  
- **AI/ML**: OpenAI embeddings for semantic search, LangChain for prompt orchestration, optional fine‑tuning on issue corpora

## Architecture  
IdeaHub comprises a lightweight browser extension that injects a React component into GitHub issue pages. The extension captures issue and comment IDs, sends them to a Node/Express API which queries the OpenAI API to generate a summary. Summaries are cached in PostgreSQL keyed by issue ID and last‑modified timestamp to reduce API calls. Real‑time updates are handled via a WebSocket endpoint that pushes new summaries when a comment is posted. Export routes provide downloadable formats, and a simple dashboard (optional) allows users to manage preferences.

## Roadmap  
- **v1**: Basic extension with one‑sentence summary, caching, and export to Markdown.  
- **v2**: Multi‑level summarization, real‑time WebSocket updates, user preference UI.  
- **v3**: Advanced analytics dashboard, multi‑language support, fine‑tuned summarization model, CI/CD integration hooks.
