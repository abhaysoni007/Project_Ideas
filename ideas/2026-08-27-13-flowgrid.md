# FlowGrid

> A CLI tool that automates news feeds in gaming workflows.

## Problem
Open-source maintainers struggle to recommend their invoices without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Team workspaces with granular permissions
- Usage analytics and an admin panel
- Offline-first with background sync
- Public REST API with scoped API keys
- Full-text search with smart filters

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** MySQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in MySQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
