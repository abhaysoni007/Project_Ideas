# PeakGrid

> A creator economy app that uses AI to visualize reading lists for developers.

## Problem
Teachers struggle to schedule their git commits without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Teachers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Integrations with Slack, Google, and Stripe
- Guided onboarding with ready-made templates
- Audit log of every change
- Email/OAuth sign-in with role-based access control
- One-click export to CSV and PDF
- Team workspaces with granular permissions

## Tech Stack
- **Frontend:** React
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** GCP Cloud Run, GitHub Actions CI/CD

## Architecture
A React client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via GCP Cloud Run.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
