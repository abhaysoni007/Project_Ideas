# SkillSwap

> enables professionals to swap skills, expertise, and knowledge with peers in their industry or niche.

## Problem
Parents struggle to detect their travel itineraries without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Parents
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Real-time updates over WebSockets
- Audit log of every change
- Integrations with Slack, Google, and Stripe
- Usage analytics and an admin panel
- Email and push notifications

## Tech Stack
- **Frontend:** React Native
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Infra/DevOps:** Railway, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Go (Gin) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Railway.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
