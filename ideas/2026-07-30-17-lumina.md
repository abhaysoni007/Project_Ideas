# Lumina

> enables homeowners to monitor and control their lighting systems remotely, optimizing energy efficiency and ambiance through smart home integration.

## Problem
Small teams struggle to summarize their news feeds without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Small teams
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Email and push notifications
- Public REST API with scoped API keys
- One-click export to CSV and PDF
- Audit log of every change
- Usage analytics and an admin panel
- Guided onboarding with ready-made templates

## Tech Stack
- **Frontend:** React
- **Backend:** FastAPI (Python)
- **Database:** PostgreSQL
- **Infra/DevOps:** Docker + AWS ECS, GitHub Actions CI/CD

## Architecture
A React client talks to a FastAPI (Python) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Docker + AWS ECS.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
