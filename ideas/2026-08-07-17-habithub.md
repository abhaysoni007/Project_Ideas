# HabitHub

> creates a habit-forming app that uses behavioral psychology and AI-driven insights to help users build positive habits and break negative ones.

## Problem
Startups struggle to organize their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Startups
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Real-time updates over WebSockets
- AI-assisted recommendations and summaries
- Email/OAuth sign-in with role-based access control
- Full-text search with smart filters
- Guided onboarding with ready-made templates
- Usage analytics and an admin panel

## Tech Stack
- **Frontend:** Next.js
- **Backend:** Go (Gin)
- **Database:** Supabase
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a Go (Gin) API over REST. Data lives in Supabase. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
