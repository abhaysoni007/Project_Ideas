# SnapLab

> A tool that maps your codebase into an interactive dependency graph.

## Problem
Gamers struggle to detect their expenses without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Gamers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Public REST API with scoped API keys
- Usage analytics and an admin panel
- Integrations with Slack, Google, and Stripe
- Offline-first with background sync
- Email/OAuth sign-in with role-based access control
- Email and push notifications

## Tech Stack
- **Frontend:** React Native
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A React Native client talks to a Node.js + Express API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
