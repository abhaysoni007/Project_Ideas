# NovaScope

> A Pomodoro timer that mutes Slack and sets your calendar to busy automatically.

## Problem
Small teams struggle to automate their expenses without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Small teams
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Full-text search with smart filters
- Public REST API with scoped API keys
- Usage analytics and an admin panel
- Email/OAuth sign-in with role-based access control
- Integrations with Slack, Google, and Stripe

## Tech Stack
- **Frontend:** React Native
- **Backend:** FastAPI (Python)
- **Database:** PostgreSQL
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React Native client talks to a FastAPI (Python) API over REST. Data lives in PostgreSQL. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
