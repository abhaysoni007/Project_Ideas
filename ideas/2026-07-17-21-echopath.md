# EchoPath

> A CLI tool that automates API logs in robotics workflows.

## Problem
Designers struggle to benchmark their reading lists without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Designers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- One-click export to CSV and PDF
- Integrations with Slack, Google, and Stripe
- Audit log of every change
- Email/OAuth sign-in with role-based access control
- Responsive dashboard with light and dark mode
- Email and push notifications

## Tech Stack
- **Frontend:** React Native
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Fly.io, GitHub Actions CI/CD

## Architecture
A React Native client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Fly.io.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
