# ByteScope
> Turn your highlights into mastery

## Problem  
Students and professionals spend hours manually converting PDF highlights into study cards, often losing context or missing key concepts. Existing tools either require tedious copy‑paste or lack integration with spaced‑repetition systems, making consistent review difficult.

## Target Users  
- Undergraduate and graduate students  
- Researchers compiling literature reviews  
- Knowledge workers preparing for certifications  
- Lifelong learners using PDF courses  
- Educators creating supplemental study materials

## Key Features  
- PDF import with native highlight detection (PDF‑spec, annotations)  
- OCR & semantic extraction to auto‑generate concise Q/A flashcards  
- Integrated spaced‑repetition engine compatible with Anki format  
- Custom tagging, deck organization, and sharing between users  
- Progress analytics: time spent, mastery curves, quiz performance  
- Offline mode with local storage and sync when online  
- Cross‑platform sync (iOS, Android, Web) via secure API

## Tech Stack  
**Frontend**  
- React (Web) + TypeScript  
- React Native (iOS & Android)  
- Redux Toolkit for state management  

**Backend**  
- Node.js with Express (TypeScript)  
- Fastify alternative for performance‑critical endpoints  

**Database**  
- PostgreSQL (primary data store)  
- Redis (caching, session storage, rate limiting)  

**Infra/DevOps**  
- Docker Compose for local dev, Docker Swarm/Kubernetes for production  
- Terraform for IaC on AWS (EKS, RDS, S3)  
- GitHub Actions for CI/CD, automated tests, and container publishing  

**AI/ML**  
- AWS Textract or Tesseract OCR for text extraction  
- OpenAI GPT‑4 for summarization and Q/A generation  
- Sentence‑BERT embeddings for semantic search within decks  

## Architecture  
ByteScope follows a modular microservice architecture: the **API Gateway** (NGINX) routes to stateless **API services** that expose CRUD operations for users, PDFs, and decks. A **Worker Queue** (RabbitMQ) handles heavy tasks such as OCR, summarization, and flashcard creation. Data resides in **PostgreSQL** while **Redis** accelerates cache‑friendly queries and session handling. Persistent files (PDFs, exported decks) are stored in **Amazon S3**. The mobile/web clients consume the REST API and sync state via websockets for real‑time collaboration.

- PDF upload & highlight detection

- Cross‑device persistent sync (cloud sync, multi‑platform).
