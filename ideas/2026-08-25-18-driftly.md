# Driftly

> A budgeting app for freelancers that sets aside tax money on every invoice paid.

## Problem
Open-source maintainers struggle to predict their study material without switching between too many disconnected tools. Existing options are either too generic or too expensive for their needs.

## Target Users
- Open-source maintainers
- Small teams and startups
- Anyone who needs a focused, no-friction tool

## Key Features
- Full-text search with smart filters
- Guided onboarding with ready-made templates
- Usage analytics and an admin panel
- Email/OAuth sign-in with role-based access control
- Public REST API with scoped API keys
- Real-time updates over WebSockets

## Tech Stack
- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** MongoDB
- **Infra/DevOps:** Vercel, GitHub Actions CI/CD

## Architecture
A Next.js client talks to a NestJS API over REST. Data lives in MongoDB. Background jobs handle async work, and the whole stack is containerized and deployed via Vercel.

## Roadmap
- **v1** — Core flow, auth, and the dashboard
- **v2** — Integrations, notifications, and the public API
- **v3** — Team features, analytics, and mobile support
